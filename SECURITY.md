# Security Policy

:warning: SECURITY TRAINING MATERIAL :warning:

This repository contains intentionally vulnerable code for educational purposes.
DO NOT use in production. DO NOT report vulnerabilities to security programs.

## About this repository

This repository (`IBM/japan-technology`) is a collection of IBM-related Japanese technical documents, such as Code Patterns, Learning Paths, and Tutorials. Some of the sample code is intentionally vulnerable and is used as security training material.

## Out of scope: intentionally vulnerable training code

The following directories contain code with intentional security vulnerabilities for training purposes. Findings in this code are **not** security issues and should **not** be reported.

- `ibm-bob/bob-a-thon/basic/intermediate/sdlc-showcase/Project2_SDLC_tasks/`
- `ibm-bob/bob-a-thon/basic/intermediate/security-analysis_code-fixs/`

## Reporting a vulnerability

If you find a real security issue in any other part of this repository, please report it privately.

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected file, and the steps to reproduce.

Please do not open a public issue or pull request for a vulnerability.
