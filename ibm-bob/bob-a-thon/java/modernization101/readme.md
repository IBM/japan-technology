# Javaアプリの最新化

このフォルダーには、古いJavaの技術で作られた Java Servlet + JSP + JDBCによるWebアプリが格納されています。
次のような演習にお使いください。

* アプリのリバース・エンジニアリング
* アプリの移行計画の作成
* 移行計画に基づいたアプリの最新化


## アプリのリバース・エンジニアリング

* 手順1: [ClassicJava201.zip](ClassicJava201.zip)をダウンロードし、ローカル・コンピューター上に展開する（任意のフォルダー）
* 手順2: IBM Bob IDEを開き、展開済みのフォルダーを開く
* 手順3: Bobのチャットで、Agentモードにする
* 手順4: 次のプロンプトを実行する

```

```

* 手順5: フォルダー内のファイルが読み込まれ、AGENTS.md が作られたことを確認する
* 手順6: AGENTS.mdをIBM Bob IDEで開いて、中身を確認する

## ご注意
この演習で利用するアプリは学習用途であり、意図的に技術的な負債を含んでいます。

* Internet Explorerへの依存
* DB 認証情報ハードコード
* XSS 脆弱性
* コネクションプールなし
* SQL 例外の握り潰し
* Scriptlet スタイル JSP
* パフォーマンス改善を考慮していない
