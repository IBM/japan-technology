# Javaアプリの最新化

このフォルダーには、古いJavaの技術で作られた Java Servlet + JSP + JDBCによるWebアプリが格納されています。
次のような演習にお使いください。

* アプリのリバース・エンジニアリング
* アプリの移行計画の作成
* 移行計画に基づいたアプリの最新化

## アプリのアーキテクチャーを分析する体験

* 手順1: [ClassicJava201-handson.zip](ClassicJava201-handson.zip)をダウンロードし、ローカル・コンピューター上に展開する（任意のフォルダー）
* 手順2: IBM Bob IDEを開き、展開済みのフォルダーを開き、そのフォルダーを「信頼する」に設定する
* 手順3: Bobのチャットで、Agentモードにする
* 手順4: 次のプロンプトを実行する

```
/init
```

* 手順5: フォルダー内のファイルが読み込まれ、AGENTS.md が作られたことを確認する
* 手順6: AGENTS.mdをIBM Bob IDEで開いて、中身を確認する
* 手順7: 次のプロンプトを実行する

```
このプロジェクトのアーキテクチャーを分析して。Mermaid形式の図を用いて、わかりやすく解説して
```

## アプリのリバース・エンジニアリングを体験

* 手順1: Bob IDEのエクスプローラーで展開済みのフォルダー内にある docs/handson/handson-reverse-engineering.html を右クリックして、統合ブラウザーで開く
* 手順2: 開いたページの目次を確認する
* 手順3: Step 1からStep 9まで順に実行する


## ご注意
この演習で利用するアプリは学習用途であり、意図的に技術的な負債を含んでいます。

* Internet Explorerへの依存
* DB 認証情報ハードコード
* XSS 脆弱性
* コネクションプールなし
* SQL 例外の握り潰し
* Scriptlet スタイル JSP
* パフォーマンス改善を考慮していない
