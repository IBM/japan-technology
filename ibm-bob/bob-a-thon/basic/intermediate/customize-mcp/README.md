# Project 6: MCPサーバーの利用

## 概要

Bobに**リモートMCPサーバー**と**ローカルMCPサーバー**を追加し、Web検索やGitなどの外部ツールを利用できるようにする。

## 目的

* BobにMCPサーバーを接続する方法を理解する
* BobからMCPサーバーのツールを呼び出す方法を確認する
* リモートMCPとローカルMCPの追加方法を体験する
* 想定所要時間: 1〜2時間

## 状況の想定

Bob単体では利用できないWeb検索やGitなどの機能を、MCPサーバーを追加することで利用する。

## 本ハンズオンを開始する前に

* Bobを利用できる環境を準備する
* リモートMCPサーバーを利用する場合は、必要なサービスへのサインアップを行う
* 本ハンズオンでは、リモートMCPサーバーの例として **Tavily** を利用する


## 手順

### Part 1：リモートMCPサーバーを追加する

#### 1. BobがWeb検索できるか確認する

Bobに以下のように質問する。

```text
Web検索はできますか？
```

Web検索機能が利用できるか確認する。

#### 2. Web検索ツールの追加方法をBobに聞く

Bobに以下のように質問する。

```text
Web検索を行うためのツールを追加する方法を教えてください。
```

Bobから提案された方法を確認する。

#### 3. 利用するMCPサーバーを選択する

Bobから提案された方法の中から、利用するMCPサーバーを選択する。

本ハンズオンでは、例として **Tavily Remote MCP Server** を利用する。



#### 4. リモートMCPサーバーを設定する

利用するMCPサーバーのドキュメントを確認し、記載されている手順に従ってBobにサーバーを設定する。

ドキュメントのリンク：https://bob.ibm.com/docs/ide/configuration/mcp/understanding-mcp

#### 5. Web検索を実行する

設定が完了したら、BobにWeb検索を依頼する。

```text
最新のAI関連ニュースをWeb検索してください。
```

MCPサーバーの検索ツールが呼び出され、検索結果が取得できることを確認する。

#### 6. 接続できない場合

MCPサーバーに接続できない場合は、以下を確認する。

* **MCPJam** など別のツールからMCPサーバーへ接続し、接続自体に問題がないか確認する

参考リンク：https://www.mcpjam.com/

### Part 2：ローカルMCPサーバーを追加する

#### 1. Bob Marketplaceを開く

BobのMarketplace（画像の赤枠部分）から利用可能なMCPサーバーを確認する。

<img width="332" height="529" alt="bob_marketplace" src="https://github.com/user-attachments/assets/c4c9af07-32d9-4223-9815-6c01a3ef895a" />


#### 2. MCPサーバーを追加する

Marketplaceから利用したいMCPサーバーを選択して追加する。

本ハンズオンでは、例として **Git関連のMCPサーバー**を利用する。



#### 3. MCPツールをBobから実行する

追加したMCPサーバーが提供するツールの1つを、Bobから実行するよう指示する。

```text
追加したGit MCPサーバーのツールを使ってください。
```

#### 4. 実行結果を確認する

BobがMCPサーバーのツールを呼び出し、正常に結果を取得できることを確認する。



## 完了条件

以下が確認できればハンズオン完了です！

* リモートMCPサーバーをBobに追加できた
* BobからWeb検索ツールを実行できた
* ローカルMCPサーバーをBobに追加できた
* BobからローカルMCPサーバーのツールを実行できた
