### トラブルシューティング
- ！！"orchestrate: command not found"
    - SDKがインストールされていないか、PATHが通っていない可能性があります。
    以下をPATHに追加(必要な場合)
    ```
    pip install --user ibm-watsonx-orchestrate # ~/.local/bin
    ```
- ！！"Authentication failed"
    - 認証情報を確認してください。認証は2時間で期限切れになります、再度アクティベートが必要です。
    ```
    #環境一覧の確認
    orchestrate env list
    #再アクティベート
    orchestrate env activate <name>
    ```
- ！！Bobが応答しない
    - Bob IDEを再起動し、Bobアウトプットパネルでエラーを確認してください。IBMidでのログイン状態も確認してください。
