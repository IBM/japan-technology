# 共通準備(Bob の準備と作業フォルダ)

シナリオ1(ブラウザ)、Node.js コマンドライン版、E2E テスト入門のどの演習でも、最初にここを済ませます。パターン1(1 時間コース)の人は、[事前課題](pre-assignment.md)の中でここを済ませます。

## 1. Bob のインストールとサインイン

1. [Bob の公式インストール手順](https://bob.ibm.com/docs/ide/getting-started/install)に従って、Bob をインストールします。
2. Bob を起動し、ブラウザで表示される画面から **IBMid** でサインインします。IBMid がない場合の作成方法は、上記の手順書にリンクがあります。
3. サインインが終わったら Bob に戻ります。

## 2. ネットワークに制限がある場合

会社のネットワークなどで Bob に接続できない場合は、[Bob の公式ドキュメント(ファイアウォール設定)](https://bob.ibm.com/docs/ide/troubleshooting/ts-firewall-rules)を確認して、ネットワーク管理者または IT 担当者に相談してください。

## 3. 作業フォルダを作って Bob で開く

作業フォルダは、この演習のファイルをすべて入れる、空のフォルダです。場所と名前は自由です(例:デスクトップの `bob-todo`)。

| OS | 操作 |
|---|---|
| Windows | エクスプローラーで場所を開き、右クリック → 新規作成 → フォルダー。名前を `bob-todo` にする |
| macOS | Finder で場所を開き、右クリック → 新規フォルダ。名前を `bob-todo` にする |

次に、作ったフォルダを Bob で開きます。

- Bob のメニューから **[ファイル] > [フォルダーを開く...]** を選び、`bob-todo` を選びます。
- 「フォルダ内のファイルの作成者を信頼しますか」のような確認が出たら、自分で作った空のフォルダなので、信頼する側を選びます。
- 「親フォルダーに Git リポジトリが見つかりました。リポジトリを開きますか?」のような通知が出たら、**行わない** を選びます(この演習では Git を使いません)。
- シナリオ1 を終えてから Node.js コマンドライン版(guide2)に進む人は、同じフォルダを使い回さず、**別の空のフォルダ**(例:`bob-todo-node`)を作って開き直してください。E2E テスト入門(guide-e2e)は、シナリオ1 の作業フォルダ(`index.html` と `todo-logic.js` がある状態)を**そのまま使います**。

## 4. Bob のチャットを開いて Agent モードにする

1. チャットが見えていない場合は、次のショートカットで開きます。

   | OS | 操作 |
   |---|---|
   | Windows | `Ctrl + Alt + B` |
   | macOS | `Option + Command + B` |

2. チャット入力欄の左下、**＋** の右隣にある **モード名のボタン**(初期状態は **Agent ▾** と表示)を押すと、「モード」として **Agent / Plan / Ask** が並びます。**Agent** を選びます(初期状態で Agent が選ばれていることが多いです)。左端の **＋** はファイルを添付するボタンなので、押さなくて構いません。モードは `Command + .`(Windows は `Ctrl + .`)で Agent → Plan → Ask の順に切り替えることもできます(入力欄にカーソルがある状態で押します)。詳しくは [Bob の公式ドキュメント(モード)](https://bob.ibm.com/docs/ide/features/modes)を見てください。

   > **Insiders 版(2.3.0-insider)を使う方へ**(受講者は GA 版を使います。Insiders 版は IBM 社員向けの先行版です):Insiders 2.3.0 では、入力欄の左下に **モード名のボタンが表示されず、＋ と 権限 の 2 つだけ**になっています(2026-10-26、macOS で確認)。初期状態は Agent モードなので、そのまま使えば演習は進められます。**権限** ボタンを押すと開く一覧の **Mode** は、モードの切り替えを Bob に自動承認させるかどうかの項目で、モードそのものを選ぶ場所ではありません。
3. 自動承認の既定値を、Bob の設定で次のように変えます。チャット右上の歯車(**Bob設定**)を押すと、設定がエディターのタブとして開きます。左側の一覧から **チャット** を選び、**ツール** の「自動承認のオン/オフ」で、**読み取り(Read)だけをオン**にし、**編集(Edit)と実行(Execute)、MCP をオフ**にします。残りの項目(モード、サブタスク、サブエージェント、スキル、やるべきこと)は、そのままで構いません。保存ボタンはなく、切り替えた時点で反映されます。これで、ファイルの作成・変更やコマンドの実行は、そのつど Bob が確認を求めるようになります。

   - 入力欄の左下にある **権限**(Permissions)ボタンを押すと、いまのタスクに適用されている自動承認の一覧(読み取り / 編集 / 実行 / MCP / スキル / やるべきこと / サブタスク / サブエージェント / モード と、一番下に全体の「自動承認」スイッチ)が見られます。ここでの変更は**そのタスクだけ**に効くので、全体の既定値は上の Bob設定で変えてください。
   - 既定のままだと 編集(Edit)や 実行(Execute)がオンになっていることがあります。編集がオンだと、Bob が作ったファイルの中身を見ずに書き込まれてしまうので、必ずオフにしてください。

> Bob が確認を求めてきたときは、内容を読んでから承認してください。承認のボタンは **一度だけ承認**(この1回だけ許可)、**拒否**、そして3つ目の「このタスクの間は同じ種類の操作を許可する」ボタンの3つです。3つ目のボタンの表示は操作によって変わり、ファイルの作成・変更では **タスクのeditツールを承認**、コマンドの実行では **タスクに対して承認** と出ます。シナリオ1 と Node.js コマンドライン版では、原則として**一度だけ承認**を使います。
>
> E2E テスト入門だけは例外で、Bob が同じ道具(`agent-browser`)のコマンドを 10 回以上実行するため、最初の承認のときに「コマンドをグローバル許可/拒否リストに追加」と「タスクに対して承認」を組み合わせて、まとめて許可します(手順は [guide-e2e](e2e/guide-e2e.md) のステップ4)。「タスクに対して承認」の効果はそのタスクの間だけですが、グローバル許可リストへの追加は Bob 全体の設定に残るので、演習の最後に外します。

## 5. バグ入りファイルの差し替え

演習の途中（手順書の指示があったタイミング）で、zip を展開した `bobathon-todo` フォルダの中にあるバグ入りのファイルを、作業フォルダに上書きコピーします。

### zip の入手

下の URL をブラウザで開き、ページ右上の **Download raw file**(下向き矢印のボタン)を押して `bobathon-todo.zip` をダウンロードし、展開(解凍)してください。展開すると `bobathon-todo` フォルダができます。演習の前に済ませておくと安心です。

[https://github.com/IBM/japan-technology/blob/main/ibm-bob/bob-a-thon/javascript/devtest101/bobathon-todo.zip](https://github.com/IBM/japan-technology/blob/main/ibm-bob/bob-a-thon/javascript/devtest101/bobathon-todo.zip)

| OS | 展開の操作 |
|---|---|
| Windows | zip ファイルを右クリック → 「すべて展開」 |
| macOS | zip ファイルをダブルクリック |

### 差し替えるファイル

| シナリオ | コピー元 | コピー先(作業フォルダ) |
|---|---|---|
| シナリオ1 | `bobathon-todo/scenario1-browser/bug/todo-logic.js` | `todo-logic.js` |
| Node.js コマンドライン版(guide2) | `bobathon-todo/scenario2-nodejs/bug/todo.js` | `todo.js` |
| E2E テスト入門(guide-e2e) | `bobathon-todo/scenario1-browser/bug/todo-logic.js`(シナリオ1 と同じ) | `todo-logic.js` |

### コピーの手順

| OS | 操作 |
|---|---|
| Windows | エクスプローラーでコピー元のファイルを選択 → コピー → 作業フォルダに貼り付け(上書き) |
| macOS | Finder でコピー元のファイルを選択 → コピー → 作業フォルダに貼り付け(上書き確認が出たら「置き換える」) |

### 確認

- コピー後、作業フォルダのファイル名が `todo-logic.js`（または `todo.js`）のままであることを確認します。
- 迷ったら、講師に声をかけてください。

## 6. 統合ブラウザー(Bob の中でページを見る)

Bob には、エディターのタブとして Web ページを表示する **統合ブラウザー** があります。この演習では、`file://` のファイルも `http://localhost:3000/` のページも、ここで確認できます(OS のブラウザを使っても構いません)。

- ファイルを開く: Bob のエクスプローラー(左側)で `index.html` などを右クリック → **統合ブラウザーで開く**
- URL を開く: コマンドパレット(Windows は `Ctrl + Shift + P`、macOS は `Command + Shift + P`)を開き、`Open Integrated Browser` と入力して **ブラウザー: 統合ブラウザーを開く** を選び、アドレス欄に URL を入力して Enter(コマンド名は日本語でも英語でも検索できます。日本語の入力がうまく出ないときは英語で入力してください)
- 再読み込みは、アドレス欄の左にある **再読み込みボタン**(← → の右隣にある小さな円形の矢印)を押します(`Ctrl + R` / `Ctrl + Shift + R` は効きません)。ボタンが小さいので、押したあとに結果が変わっていなければ、もう一度押してください。
- ページの文字をコピーしたいとき(シナリオ1 のステップ8)は、ドラッグで選んでから `Ctrl + C`(macOS は `Command + C`)を押します。うまくコピーできないときは、無理にコピーせず、画面を見ながら必要な部分(テスト名、期待値、実際の値)を手で入力しても構いません。
