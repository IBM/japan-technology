# パターン2:標準コース(シナリオ1・2 + オプションで E2E)

Bob に ToDo アプリを作らせ、ブラウザだけのユニットテスト(シナリオ1)と、Node.js でのテスト実行(シナリオ2)を体験します。時間と環境に余裕がある人は、オプションとして E2E テスト入門に進みます。

## 当日の進め方

| 内容 | 手順書 | 所要の目安 |
|---|---|---|
| 共通準備(Bob、作業フォルダ、Agent モード、自動承認) | [common-setup](common-setup.md) | 10 分(インストール済みの場合) |
| シナリオ1:ブラウザだけで ToDo アプリを作る(ステップ1〜9) | [guide1](scenario1-browser/guide1.md) | 40〜60 分 |
| シナリオ2:Node.js で ToDo アプリを作る(ステップ1〜10) | [guide2](scenario2-nodejs/guide2.md) | 30〜40 分 |
| オプション:E2E テスト入門(インストール込み、ステップ1〜8) | [guide-e2e](e2e/guide-e2e.md)(パターン2の欄を読む) | 30〜45 分(インストール 10〜15 分 + 演習 17〜30 分) |

> 所要は作成者の実機確認(シナリオ1 本編 19 分、シナリオ2 本編 13 分、E2E のインストール約 5 分 + ステップ1〜8 で 8〜10 分)をもとにした見込みで、受講者は 2〜3 倍と想定しています。受講者での計測はまだ行っていません。

## オプションに進む条件

- シナリオ2の事前準備 2〜3(Node.js の版)を満たしている
- 約 200 MB のダウンロードができるネットワークにいる
- ターミナルの操作(コマンドを打つ、2 本目を開く)に抵抗がない

オプションでは、[事前課題](pre-assignment.md)の 4〜5(agent-browser の導入とスキル登録)をその場で行ってから、[guide-e2e](e2e/guide-e2e.md)のステップ1〜8 を各自で進めます(バグ差し替えも各自)。

## 講師の準備

- バグ入りファイルは `scenario1-browser/bug/todo-logic.js`(シナリオ1と E2E で共通)、`scenario2-nodejs/bug/todo.js`(シナリオ2)。
- オプションに進む人には、E2E のステップ4 で「許可リストに追加(✓ が緑になるのを確認)＋ タスクに対して承認」を使うこと、許可リストは Bob 全体の設定なのでステップ8 で外すこと、指示文は手順書のものをそのまま貼ること(`'@e3'` のクォートと「reload は開始前に 1 回だけ」の行が抜けると失敗や途中の reload が起きる)を伝える。
- E2E では Bob の揺れとして、server.js の書き直し(承認 2 回)や途中のやり直しが起きることがある。いずれも Bob が自分で回復して報告するので、そのまま待ってよいと伝える。
- スキルのグローバル登録は Bob を起動し直すまで Bob設定 > スキル に出ない。オプションに進む人には登録後に Bob を起動し直させる。
