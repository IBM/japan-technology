# IBM Bob ハンズオン — ゼロからアプリを作り切る「開発・テスト完全攻略」（割り勘アプリ編）

IBM Bob と Web ブラウザーだけで、割り勘アプリをゼロから作り、自動テストで確かめ、仕様変更に耐えるところまでを 55 分で体験するハンズオンです。
**コードは 1 行も書きません。** 参加者が決めるのは「どう動いてほしいか」と「期待する答え」だけ。コードにするのは IBM Bob、確かめるのは自動テストです。

| | |
|---|---|
| 対象 | プログラミング経験は問いません |
| 時間 | 55 分（オンライン） |
| 必要なもの | IBM Bob（インストール・サインイン済み）、Windows または Mac |
| 使うファイル | このページの `warikan-starter.zip` だけ。インターネット接続は Bob の利用にのみ必要です |

## 参加者の準備（当日までに）

1. [warikan-starter.zip](https://github.com/IBM/japan-technology/raw/main/ibm-bob/bob-a-thon/javascript/warikan/warikan-starter.zip) をダウンロードし、デスクトップなど分かりやすい場所に展開します（Windows: 右クリック →「すべて展開」／ Mac: ダブルクリック）。
2. IBM Bob を起動し、**［ファイル］→［フォルダーを開く］** で展開した `warikan-starter` フォルダーを開きます（「信頼する」を選びます）。
3. Bob のエクスプローラーで `guide.html` を右クリック → **「統合ブラウザーで開く」**。これが受講者ガイドです。当日はこのガイドに沿って進めます。

当日の手順はすべて `guide.html` に書いてあります。Bob に送る文はコピーボタンで貼り付けられます。

## 今日やること

1. 仕様書を Bob に渡してアプリを作る
2. 「正しい答え」を先に決めてテストにし、赤 → 緑 を見る
3. 仕様変更を「先にテスト」で入れる
4. 自分たちでルールを 1 つ足す（仕様の穴を決める）
5. 壊れたコードをテストだけで見破る
6. できたコードを Bob に説明させる（リバース・エンジニアリング）

## 配布フォルダーの中身（`starter/` = zip の中身）

| ファイル | 役割 |
|---|---|
| `guide.html` | **受講者ガイド**（最初に開く） |
| `cases.html` | テストケース記入表。数字を入れると Bob に送る文ができる |
| `spec.md` | 割り勘アプリの仕様書 v1 |
| `spec-change.md` / `spec-change-2.md` | 仕様変更票（講師の合図まで開かない） |
| `cases.md` | テストケース記入表の Markdown 版（Markdown を書ける人向け・任意） |
| `AGENTS.md` | Bob への約束事（触らない） |
| `index.html` / `logic.js` / `tests.js` | Bob が中身を作るファイル |
| `test.html` / `harness.js` | ブラウザーで動くテストランナー（開くだけ・触らない） |

`starter/` はこの zip を展開したものと同じ内容です。個別のファイルを見たいときに参照してください。
