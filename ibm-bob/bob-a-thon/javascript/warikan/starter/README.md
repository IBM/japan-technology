# 受講者ガイドは guide.html です

このフォルダーの `guide.html` をブラウザー（Chrome / Edge / Safari）で開いてください。
手順、Bob に送る文（コピーボタン付き）、困ったときの対処がすべて載っています。

| ファイル | なに？ |
|---|---|
| `guide.html` | **受講者ガイド**（最初に開く） |
| `spec.md` | 割り勘アプリの仕様書（ステップ1で Bob に渡す） |
| `cases.html` | テストケース記入表（ブラウザーで開いて入力すると Bob に送る文ができる） |
| `cases.md` | 同じ表の文字版（Markdown を直接書ける人向け。使わなくてOK） |
| `spec-change.md` / `spec-change-2.md` | 仕様変更票（講師の合図まで開かない） |
| `index.html` / `logic.js` / `tests.js` | Bob が中身を作るファイル |
| `test.html` | テストを実行して ○× を表示するページ（開くだけ） |
| `harness.js` / `AGENTS.md` | 裏方。触らなくてOK |
