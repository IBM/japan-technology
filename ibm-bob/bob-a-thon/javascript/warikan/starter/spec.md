# 割り勘アプリ 仕様書（バージョン1）

## 目的
飲み会や食事会の会計を、1人あたりいくらになるか すぐに計算できる Web アプリ。
ブラウザーで `index.html` を開くだけで使える。

## 画面
1. 「合計金額（円）」を入力する欄
2. 「人数」を入力する欄
3. 「計算する」ボタン
4. 結果の表示欄 —「1人あたり ○○円」と大きく表示する

入力欄には、はじめから例として 合計金額 12345、人数 5 が入っていること（すぐ試せるように）。

## 計算のルール
- 1人あたりの金額 ＝ 合計金額 ÷ 人数
- 割り切れないとき（1円未満の端数が出るとき）の扱いは、**このバージョンでは決めない**。計算結果をそのまま表示してよい
- 合計金額や人数が入力されていない、数字でない、マイナス、人数が 0 のときは、計算せずに「合計金額は0以上の整数で入力してください」「人数は1以上の整数で入力してください」のような日本語のメッセージを表示する

## つくり方の決まり（Bob 向け）
- 計算は `logic.js` の `calcSplit()` に書き、画面（`index.html`）はそれを呼んで表示するだけにする
- 詳しくは `AGENTS.md` を参照
