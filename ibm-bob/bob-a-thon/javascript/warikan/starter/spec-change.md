# 仕様変更票 No.1 — 幹事ルールの追加

（ステップ3で使います。講師の合図があるまで Bob には渡さないでください）

## 背景
実際の飲み会では「1人 3,334円ずつ」のような細かい金額を集めるのは面倒。
一般の参加者からはキリのよい金額を集め、端数は幹事が引き受けたい。

## 追加する機能
1. 「端数処理の単位」を選べるようにする: 1円 / 10円 / 100円 / 500円 / 1000円（はじめは 100円）
2. 「幹事が端数を引き受ける」のチェックボックスを追加する

## 計算のルール（幹事が端数を引き受けるにチェックしたとき）
- 幹事以外の1人あたり ＝ 合計金額 ÷ 人数 を、選んだ単位で**切り捨て**
- 幹事の支払い ＝ 合計金額 − 幹事以外の1人あたり × （人数 − 1）
- 幹事の支払いは必ず、幹事以外の1人あたり以上になる（幹事が損をする側）
- 例: 12,345円・5人・100円単位 → 幹事以外 2,400円 × 4人 ＝ 9,600円、幹事 2,745円

## 計算のルール（チェックしないとき）
- 今までどおり全員同額。ただし端数は選んだ単位で**切り上げ**、余りを表示する
- 例: 10,000円・3人・1円単位 → 1人 3,334円、余り 2円

## 変わらないこと
- 今まで作ったテストは、すべてそのまま通ること（既存の動きを壊さない）
