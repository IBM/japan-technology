# 仕様変更票 No.2 — 自分のルールを足す（ステップ5）

3 つの候補から **1 つ選んで** 追加します。どれも途中に「決まっていないこと」が 1 つ残してあります。
それをチームで決めてから、cases.md の表C に期待値を書き、先にテスト → あとで実装、の順で進めてください。

## 候補 A: クーポン値引き
- 画面に「クーポン値引き（円）」の入力欄を追加する（はじめは 0）
- 合計金額からクーポンを**先に引いて**から、今までどおり割る
- 例: 10,000円・クーポン 1,000円・3人・1円単位・幹事なし → 9,000円を3人 → 1人 3,000円、余り 0円
- 例: 12,345円・クーポン 345円・5人・100円単位・幹事あり → 12,000円 → 幹事以外 2,400円、幹事 2,400円
- **決めること**: クーポンが合計金額より大きいときはどうする？（エラーにする／0円として扱う／…）

## 候補 B: 最低支払額
- 画面に「1人の最低支払額（円）」の入力欄を追加する（はじめは 0 ＝ 無効）
- 幹事ありのとき、幹事以外の1人あたりが最低支払額より小さければ、最低支払額まで引き上げる。そのぶん幹事の支払いは減る
- 例: 300円・4人・100円単位・幹事あり・最低 100円 → 幹事以外 100円 × 3人、幹事 0円
- 例: 12,345円・5人・100円単位・幹事あり・最低 1,000円 → 変わらず 幹事以外 2,400円、幹事 2,745円（もともと最低額を超えている）
- **決めること**: 最低支払額 × (人数 − 1) が合計金額を超えるときはどうする？（エラーにする／幹事がマイナス＝受け取る／…）

## 候補 C: 学生は半額
- 画面に「うち学生の人数」の入力欄を追加する（はじめは 0）
- 幹事ありのとき、学生は一般の**半額**にする。一般の1人あたりは「合計 ÷（人数 − 学生 ÷ 2）」を単位で切り捨て。学生はその半分（これも単位で切り捨て）。端数はすべて幹事（幹事は一般側）
- 例: 10,000円・4人・うち学生 2人・100円単位・幹事あり → 10,000 ÷ 3 = 3,333.3… → 一般 3,300円、学生 1,600円（3,300 ÷ 2 = 1,650 → 100円単位で切り捨て 1,600）→ 幹事 = 10,000 − 3,300 × 1 − 1,600 × 2 = 3,500円
- **決めること**: 学生の人数が「人数 − 1」以上（幹事以外が全員学生、または人数より多い）のときはどうする？
