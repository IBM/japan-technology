watsonx.dataのコスト管理

RU課金の仕組みとコスト抑制方法
最終更新: 2026/8/6

watsonx.dataの課金はResource Unit(RU)ベースの従量制です。本章では、課金の仕組みとランレートの確認方法、およびコストを抑制するための一時停止(Pause)の操作を説明します。

【重要】RU消費はゼロにはなりません watsonx.dataでは、メタデータの管理やアクセス・コントロールを担うサポート・サービス(アカウントあたり3.00RU/h)が常時稼働しており、停止させることはできません。そのため、すべてのエンジンやサービスをPause状態にしても、インスタンスが存在する限りRUの消費(課金)は継続します。長期間利用しない場合は、インスタンスの削除もご検討ください。

RU課金の仕組みとランレートの確認

RUの課金はリスト価格で1RU=1USD、秒単位の計測(最低1分)による従量制です。エンジンを使用しない時間帯は、後述のPause機能でRU消費を抑制できます。
現在のランレートと消費実績は、watsonx.dataコンソールのナビゲーションメニューにある「Resource usage」ページから確認できます(環境により表示・配置が異なる場合があります)。

下記は、本ガイドの手順(クイックスタート+Milvus追加)を実施した環境でのResource usageページの表示例です。Presto(Starter) 2RU/h、Spark 2.24RU/h、Milvus(starter) 1.25RU/h、Support services 3RU/hの合計で、Total run rateは8.49RU/hとなっています。全コンポーネント稼働時のコスト目安としてご参照ください。

参考：IBM watsonx.data Pricing（英語）

エンジン・サービスの一時停止(Pause)と再開(Resume)

エンジンやサービスを一時停止し、RU使用量を削減する方法を以下に示します。

watsonx.dataのInfrastructure manager画面で、エンジンやサービスのアイコンをマウスオーバーすると、「Pause」ボタンが表示されます。これをクリックすると、サービスを一時停止することができます。

確認ダイアログが表示されたら、「Pause」を押下します。

停止されている状態でアイコンをマウスオーバーすると「Pausing」と表示されます。

再度起動したい場合は、「Resume」ボタンから再開できます。

停止や起動が完了するまでには、少し時間がかかる場合があります。このような場合、左側のマークが点滅し、マウスオーバーすると「Resuming」などと表示されます。
