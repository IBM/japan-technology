ファイルの管理

ファイルの管理
最終更新: 2026/8/2

本ガイドは、2024年10月18日に公開された Using Files in Planning Analytics as a Service（英語） の内容を基にしています。
PAoC 版ガイドの「ファイル転送の設定」に相当するページです。PAaaS には FTP/FTPeS のようなファイル転送の仕組みはなく、代わりに Web UI のファイルマネージャーとデータベースストレージを使用します。
UI・手順は変更される可能性があるため、IBM の最新ドキュメントを必ずご確認ください。

概要

PAaaS でフラットファイルを利用する主な方法は次の2つです。

  • ファイルマネージャー（File Manager）：Planning Analytics のデータベースストレージへのファイルのアップロードを含むファイル管理。特定のファイルから次元やキューブへデータを取り込みたい場合などに便利です。
  • TI プロセスでのアップロード：TurboIntegrator（TI）プロセスからファイルを利用します。モデラーはプロセス編集時にファイルをアップロードでき、アナリスト向けにはアップロード用のアクションボタンを用意できます。

📝 補足：IBM Docs には「Planning Analytics Workspace 2.0.95 の File manager 拡張機能（ファイル移動等）は PAW on Cloud / Local のみで提供され、PAaaS および TM1 Database 12 接続時には提供されない」旨の記載があります。PAW 2.0.x 系の新機能情報を参照する際は、PAaaS への適用可否にご注意ください。

このほか、ODBC テキストドライバー＋ODBC Data Connector を使って PAaaS の外部に置いたテキストファイルを利用する方法もあります（ODBC Data Connector の構成 を参照）。

参考動画：File Management in PAaaS（YouTube・英語）（音声は英語ですが、YouTube の字幕自動翻訳機能で日本語字幕を表示できます。再生画面の「設定 ⚙ → 字幕 → 自動翻訳 → 日本語」を選択してください）

ファイルマネージャーでのアップロード手順（概要）

  1. Planning Analytics ホーム画面で Data and Models を選択します。

  1. Create → New workbench を選択します。

  1. データベースツリーで対象データベースを選択し、コンテキストメニュー（3点リーダー）からファイルマネージャーを開きます。

  1. アップロードアイコンを選択し、ファイルをドラッグ＆ドロップ（または参照で選択）して Upload します。青いチェックマークが表示されればアップロード完了です。

  1. アップロード済みファイルに対して、ダウンロード／プレビュー／削除が行えます。フォルダーを作成してファイルを整理することもできます。

TI プロセスでのファイル利用（概要）

ロールによって手順が異なります。

モデラー／管理者：TI プロセスの作成

  1. Data and Models → New workbench → データベースツリーで対象データベースを展開します。
  2. Processes を右クリック → Create process でプロセスを作成します。
  3. Data source で「File」を選択し、Select file からファイルマネージャー上のファイルを選択します（データソースにはキューブやデータベース接続などの選択肢もあります）。

4. スクリプトに取り込みロジック（次元・キューブへのロード等）を記述し、保存します。 5. パラメータータブに変数を定義し、スクリプトと組み合わせることで、実行時にアップロードされたファイルを受け取る構成にできます。

アナリスト：アクションボタンによるアップロード

  1. モデラー／管理者が、ブックにアクションボタンウィジェットを配置します。
  2. ボタンのプロパティで Run Process を有効化し、対象データベースとプロセスを選択のうえ、「Allow file upload」にチェックを入れて保存します。

  1. アナリストがボタンをクリックすると、ファイルアップロードのプロンプトが表示され、アップロードとプロセス実行（データロード等）が行われます。

REST API によるファイル管理

Planning Analytics Workspace の REST API を使ってファイルの転送・管理を自動化することもできます。
