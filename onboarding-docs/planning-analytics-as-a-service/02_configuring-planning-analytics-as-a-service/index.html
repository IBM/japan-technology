Planning Analytics as a Service

構成（Configuration）

構成（Configuration）
最終更新: 2026/8/2

本ガイドは、2024年10月21日に公開された Configure Planning Analytics as a Service（英語） を参照して作成されています。
しかし、Planning Analytics as a Service 環境は随時更新されています。そのため、ユーザーインターフェース、設定プロセス、接続手順などが本ガイドと一致しない可能性があります。
手順や画面が本ガイドと一致しない場合は、IBM の最新ドキュメントや公式ガイドラインを必ず参照し、最新版に沿った対応を行ってください。

概要

Planning Analytics as a Service の構成は、主にサポート・認証の整備とデータ連携・クライアントの接続性に焦点を当てた複数のステップから構成されます。
以下のフロー図は、実施すべき主な構成作業を高レベルで示したものです。

各ステップの詳細

それぞれのステップについて、以下のリンクから詳細をご確認ください。

1. IBM サポートのセットアップ

IBM サポートとの連携、および PAaaS のサポートコンテンツハブ（PAaaS 101）の活用をセットアップします。

サポート設定の詳細を見る

2. 認証と IBMid の整備

ログイン認証（IBMid / MCSP）と、プログラムアクセス用の API キーを整備します。

認証と IBMid の詳細を見る

3. ファイルの管理

ファイルマネージャーおよび TI プロセスによるファイルの取り扱いを確認します。

ファイルの管理の詳細を見る

4. ODBC Data Connector の構成（必要な場合）

リレーショナルデータベースと連携する場合は、Planning Analytics ODBC Data Connector を構成します。

ODBC Data Connector の詳細を見る

5. Planning Analytics for Excel（PAfE）の設定

Excel クライアントを配布・設定します。必須バージョン要件にご注意ください。

PAfE 設定の詳細を見る

6. その他のコンポーネント

Spreadsheet Services（Websheet）、Plans & Applications などのコンポーネントを確認します。

その他のコンポーネントの詳細を見る

7. PA Agent（旧 PA Assistant）のセットアップ

自然言語で操作・分析・タスク実行を行う AI エージェントの提供形態と留意点を確認します。

PA Agent の詳細を見る

8. Planning Analytics as a Service 管理概要

環境・データベース・ユーザー・バックアップの管理設計を行います。

管理概要の詳細を見る
