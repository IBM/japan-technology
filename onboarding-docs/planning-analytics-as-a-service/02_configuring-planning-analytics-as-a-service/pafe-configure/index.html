Planning Analytics for Excel（PAfE）の設定ガイド

Planning Analytics for Excel（PAfE）の設定ガイド
最終更新: 2026/8/2

PAfE のバージョン要件は TM1 Database 側の更新に伴い引き上げられることがあります。配布前に必ず最新のリリースノート（PAfE の新機能・日本語）をご確認ください。

⚠️ 必須バージョン要件（重要）

IBM 公式ドキュメントに以下が明記されています。

PAaaS を TM1 Database Version 12.5 以降で使用する場合、Planning Analytics for Microsoft Excel をバージョン 2.1.14 以降に更新する必要があります。

出典：What's new in Planning Analytics for Microsoft Excel 2.1.20（IBM Docs）

バージョン番号体系の注意（重要）

2025年10月以降、PAaaS（Planning Analytics SaaS）で配布される Workspace / PAfE は 3.1 系の番号を採用しています（2.0.107 が 2.0 系最後のリリースで、次が 3.1.2。Certified Containers と番号を統一）。一方、2.1 系は PA on Cloud / Local 向けの番号体系です（同時期に 2.1.15 へ移行）。

  • PAaaS の PAW 管理画面（Excel and Customizations）からダウンロードできるのは 3.1 系の最新数バージョンです（例：2025年12月時点では 3.1.4 / 3.1.3 / 3.1.2）。
  • 上記の「2.1.14 以降」の要件は 2.1 系・2.0.x 系クライアントを使用する場合の下限であり、3.1 系の PAfE はすべてこの要件を満たします。
  • 実務上は、PAW 管理からダウンロードできる最新版（3.1 系）の利用を推奨します。直近の 2.0.x 系クライアントも Workspace 3.1.2 以降で引き続き動作します。

出典：Change to version numbers in Planning Analytics SaaS（IBM Community・英語）

参考：オンボーディング記事シリーズの Configure Planning Analytics for Excel（英語）（PAoC / PAaaS 共通）に、ダウンロード・起動・接続・アップグレード・削除・バージョン確認までの手順がまとまっています。

入手方法

  • PAW の管理タイル → Excel and Customizations から最新版を直接ダウンロードできます（出典：PAaaS Administration Overview（IBM Community・英語）。IBM Fix Central からも入手可）。

セットアップ手順（概要）

  1. ダウンロードした zip を展開します。PAfE は .xll 形式のため、インストーラーは不要です。
  2. Excel のアドインとして .xll を読み込みます（ダブルクリック、または Excel のオプション → アドイン → 参照）。
  3. 前提となる Microsoft .NET Framework の有無を確認します。
  4. PAfE のオプションで接続 URL（Data Center URL / TenantId ベース）を登録します。
  5. IBMid でサインインして接続を確認します。

Tips

  • 接続 URL の確認方法：Planning Analytics Workspace に接続した状態のブラウザーのアドレスバー、または招待メールに記載の URL を使用します。
  • 単一セッションでの起動：サードパーティ製の Excel アドインと競合する場合は、.xll をその都度開く単一セッション起動が有効です。
  • Excel のビット数（32/64bit）に一致する .xll を使用してください。

対応環境の確認

サポート対象の Excel / OS バージョンは SPCR（Software Product Compatibility Reports）で確認してください（サポートについて の PAaaS 101 からリンクがあります）。
