サポートについて

サポートについて
最終更新: 2026/8/6

サポートへの問い合わせフローや必要な情報（Must Gather）は変更される場合があります。最新の情報は下記 PAaaS 101 ページおよび IBM サポートポータルをご確認ください。

問い合わせ窓口

技術的な問い合わせは、IBM サポートポータルからケースを起票してください。

参考：PAaaS オンボーディング記事シリーズの IBM Planning Analytics as a Service Support（英語） にサポート連携のセットアップ手順がまとまっています。

サポートコンテンツハブ（PAaaS 101）

IBM Planning Analytics as a Service 101（英語） は、PAaaS の製品ナレッジとドキュメントを集約したサポートコンテンツハブです。以下への導線がまとまっています。

  • Must Gather：問題判別のために収集すべき情報の一覧（Planning Analytics Engine / Workspace / for Excel / Websheet Services / Database Migration Utility / ODBC Data Connector の 6 種）。ケース起票時に添付します。
  • 環境ステータスページ：環境の稼働状況の確認とインシデント通知の購読（直接 URL：SaaS Console ステータスページ）。
  • メンテナンス通知：環境メンテナンスに関する通知の確認・購読。
  • Security Bulletins：セキュリティ脆弱性情報。
  • My Notifications：IBM ソフトウェアサポートの重要更新の購読設定。
  • サポート対象環境（Supported Environments）：サポート対象の OS・関連ソフトウェア・ハイパーバイザー・ハードウェア要件の確認（SPCR）。

その他の有用なリソース

  • Planning Analytics as a Service Getting Started Checklist（IBM Community・英語）：IBM Customer Success チームによるオンボーディング手順のチェックリスト。
  • Planning Analytics ロードマップ（英語）：今後の機能計画。
  • IBM Ideas ポータル（英語）：機能拡張リクエストの起票・投票。
  • PAaaS 101 には、上記に加えて Technote 検索への導線もあります。

リリース情報

公式ドキュメントの新機能情報（日本語）：

  • 新機能の紹介（Introduction）
  • Planning Analytics Workspace の新機能
  • Planning Analytics for Microsoft Excel の新機能
  • Planning Analytics Agent の新機能
  • PAaaS は継続的に（おおむね月次で）アップデートされ、リリースノートが公開されます（例：3.1.5＝2026年2月、3.1.6＝3月、3.1.7＝4月。3.1.5 の新機能（英語））。
  • 全リリース横断で新機能を検索・ソートできる Planning Analytics Workspace 新機能サマリーテーブル（IBM Support・英語） が便利です。
  • 番号体系：3.1 系＝PAaaS（SaaS）/ Certified Containers、2.1 系＝PA on Cloud / Local です（2025年10月に 2.0.x から移行）。
  • TM1 Database 12 の Fix List（例：TM1 12.5.9（英語））は、PAaaS を含む TM1 12 採用オファリング共通で公開されます。
