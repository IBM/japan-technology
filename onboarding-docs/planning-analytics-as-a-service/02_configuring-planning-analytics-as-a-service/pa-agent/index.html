PA Agent（旧 PA Assistant）のセットアップ

PA Agent（旧 PA Assistant）のセットアップ
最終更新: 2026/8/2

PA Agent は機能拡張・名称変更が特に活発な領域です。本ページの内容は執筆時点の公開情報（2026年7月まで）に基づきます。
手順や画面が本ガイドと一致しない場合は、IBM の最新ドキュメントや公式ガイドラインを必ず参照し、最新版に沿った対応を行ってください。

概要

Planning Analytics Agent（旧称：Planning Analytics AI assistant / PA Assistant）は、管理者およびユーザーが自然言語でプランニングコンテンツを操作できる対話型インターフェースです。

出典：Planning Analytics Agent（IBM Docs）

📝 名称変更について：IBM は Planning Analytics Assistant を Planning Analytics Agent へ改称しています。これは単なる名称変更ではなく、「質問に答えるアシスタント」から「タスクの実行・ワークフローの起動まで担うエージェント」への機能面の進化を反映したものです。過去の資料・ブログでは Assistant 表記が残っている場合があります。

2 つの利用体験（Managed / Custom）

  • Managed Experience（IBM 管理型）：ログインしてすぐに使える方式。Chart Insights、Variance Analysis（差異分析）、Explain Cell、PA Agent チャットなどの AI 機能が組み込みで提供され、モデル・インフラ・更新は IBM が管理します。AI の専門知識は不要です。
  • Custom Experience（カスタム）：PA Agent アドオンに含まれる MCP（Model Context Protocol）ツールを使い、自社の Planning Analytics データ・ワークフロー・ビジネスロジックと深く統合したカスタム AI エージェントを構築する方式。お客様ご自身の watsonx Orchestrate / watsonx.ai などのプラットフォームと統合できます。

「まず Managed で開始し、必要に応じて Custom へ拡張する」段階的な導入パスが公式に示されています。

出典：A New AI Foundation for the IBM Planning Analytics Agent（IBM Community・英語）（2026年7月）／Leverage Agentic AI with the Planning Analytics Assistant and watsonx Orchestrate!（IBM Community・英語）（2025年7月）

AI 基盤・提供リージョン・対応言語（2026年7月時点）

PAW 3.1.10（PAaaS では提供済み）で、IBM 管理型 AI のモデル基盤が IBM Granite 4（watsonx.ai）から GPT OSS 120B（Amazon Bedrock） へ移行しました。お客様側の設定変更は不要で、AI 応答の品質向上・リージョン拡大・対応言語拡大が図られています。

⚠️ 日本のお客様への注意：PAaaS 環境自体のリージョンとは別に、IBM 管理型 AI（PA Agent）の提供拠点は上記 3 リージョンです（2026年7月時点で日本の記載はありません）。AI 処理のデータ所在地に要件があるお客様は、最新の提供状況を IBM にご確認ください。

日本語対応：今回の基盤移行により、日本語は Agent チャット・AI 機能（Chart Insights / Explain Cell 等）の両方でサポート対象になりました。ほかに英語・フランス語・ドイツ語・イタリア語・スペイン語・ブラジルポルトガル語・簡体字/繁体字中国語などがチャット/機能の両対応です（言語ごとの対応可否の一覧は上記出典の表を参照）。

展開状況：PAaaS（AWS / Azure）は PAW 3.1.10 で提供済み。PA on Cloud は PAW 2.1.23 で近日提供、オンプレミスは将来リリース予定です。

MCP サーバーツール（カスタムエージェント連携）

PA Agent の MCP サーバーツールを使うと、watsonx Orchestrate をはじめ MCP に対応する任意のエージェント基盤から、ガバナンスの効いた形で Planning Analytics のデータ・機能を呼び出せます。

4 つのツールカテゴリー：

カテゴリー用途
Modeling Agentモデルの作成・保守・進化のエージェント化（自然言語によるモデル設計支援）
Analysis AgentTM1 データの記述的・予測的・処方的分析
Workflow AgentApplications / Plans への提出・レビュー・承認プロセスのエージェント参加
Reporting Agentステークホルダー向けのエンタープライズレポート作成

接続と認証：

  • OAuth 認証の導入により、MCP ツールは PAaaS だけでなく Local / on Cloud / Certified Containers を含む全デプロイ形態で利用可能になりました（PAW 3.1.7 / 2.1.20 以降）。
  • ユニバーサル MCP エンドポイント（PAW 3.1.9 / 2.1.22 以降）：接続設定は次の単一エンドポイントに統一されました。

https://<PAW_HOST>/api/<PAW_TENANT_ID>/v0/agentic-ai/ibm-pa-tools/mcp

  • ライセンス要件：MCP ツールの利用には PA Agent（Assistant）のライセンス（アドオン）が必要です。サードパーティ製プラットフォームから呼び出す場合も同様です。

出典：Introducing IBM Planning Analytics Assistant MCP Server Tools for Every Deployment Model（IBM Community・英語）（2026年4月）／Introducing the Universal MCP Endpoint for PA Agent MCP Tools!（IBM Community・英語）（2026年6月）

IBM Bob との連携（モデル開発の加速）

IBM Bob（AI 開発パートナー）は、PA Agent MCP サーバーを介して Planning Analytics のモデル・ビジネスロジック・プロセス・管理機能と安全に連携します。

管理者・TM1 開発者・ソリューションアーキテクトは、自然言語での対話を通じて以下を加速できます。

  • モデルの設計・開発（要件からの構造定義）
  • ドキュメントの生成・最新化
  • 既存環境の分析とパフォーマンスボトルネックの特定・最適化
  • 管理作業の簡素化と継続的なガバナンス支援

出典：Accelerate Planning Analytics Development, Optimization & Innovation with IBM Planning Analytics and IBM Bob（IBM Community・英語）（2026年6月）

セットアップ時の留意点

  • 統合方式の変更：watsonx Orchestrate 連携は、従来の「API URL・API キー・プロジェクト ID を直接指定する構成」がサポート対象外となり、エージェントベースの統合が標準になりました。旧方式で書かれた手順資料にはご注意ください。あわせて、MCP 接続は前述のユニバーサルエンドポイントへの移行が推奨されています。 出典：What's coming next in IBM Planning Analytics Workspace 2.1.22（IBM Support・英語）（2026年6月）
  • 利用可否の確認：機能はリリースごとに拡張されています。お使いの環境での利用可否・有効化手順は、PA Agent の新機能（IBM Docs・日本語）と公式ドキュメントでご確認ください。
