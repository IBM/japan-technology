利用方法

ContentIQ でエージェントにナレッジを付与する

IBM パートナー製品 symplistic.ContentIQ を使って、watsonx Orchestrate エージェントに文書・Web・クラウド・ストレージのナレッジを付与する
最終更新: 2026/9/9

概要

symplistic.ContentIQ は、IBM パートナーの symplistic.ai が提供する RAG 型のナレッジ・プラットフォームです。Web サイト、文書ファイル、SharePoint / OneDrive / Box などのクラウド・ストレージからコンテンツを取り込み、watsonx Orchestrate のエージェントに出典引用付きの根拠回答を提供します。

watsonx Orchestrate の標準ナレッジ機能（ファイル・アップロード、外部ベクトル DB 接続）に対し、ContentIQ は以下の点で補完的に機能します。

  • クラウド・ストレージからのスケジュール差分再取り込みと、取り込み状況の監視
  • 日本語コンテンツへの日本語埋め込みの自動適用（v1.2.1 以降）
  • チャンク単位の編集・バージョン履歴によるナレッジ品質の運用的な改善
  • 回答品質（Hallucination Rate、Citation Accuracy 等）の常時計測
  • 白ラベル Widget や Microsoft Entra SSO 付き外部チャットとしての展開

ContentIQ は IBM 製品ではなく、IBM Cloud カタログに掲載された Third Party サービスです。製品の機能・手順・サポートについては symplistic.ai の公式ドキュメント（英語） を一次情報としてご参照ください。

利用が向いているケース

  • 規約、マニュアル、FAQ など、更新頻度の高い文書群を継続的にエージェントへ反映したい
  • 取り込み後にナレッジの内容（チャンク）を確認・修正したい
  • 回答の出典引用を運用上の要件として重視している
  • 社外向けポータルや Web サイトにエージェントを Widget として埋め込みたい

少量で更新頻度の低い文書であれば、標準のナレッジ機能で十分な場合があります。

前提条件

  • watsonx Orchestrate インスタンス（インスタンスの作成 参照）と API キー・API URL
  • ContentIQ アカウント（symplistic.ai から発行）
  • ナレッジを付与する対象の watsonx Orchestrate エージェント（Agent Builder の使い方 参照）

手順の概要

詳細な手順は symplistic.ContentIQ オンボーディングガイド に記載しています。ここでは全体の流れのみを示します。

  1. watsonx Orchestrate で API キーを取得する
    Settings の API details から API URL の確認と API キーの生成を行います。
  2. ContentIQ に watsonx Orchestrate の接続情報を登録する
    ContentIQ の Settings に API キーと API URL を保存します。
  3. コンテンツを取り込む
    Connections から Website / Document Upload / OneDrive 等のソースを選び、Agent Type で Use Existing Agent を選択して対象エージェントを指定します。取り込みが完了すると、watsonx Orchestrate のエージェントに ContentIQ の検索ツール（symplisticai_tool_rag_contentiq_…）が追加されます。Knowledge ではなく ツールとして付与される点に注意してください。
  4. エージェントの指示を設定する
    エージェントの指示に、ContentIQ のツールを呼び出して回答する旨を明記します。指示がない場合、エージェントはツールを使わず一般知識で回答することがあります。
  5. 取り込み状況と回答を確認する
    ContentIQ の Ingest Analytics で取り込み結果を確認し、watsonx Orchestrate のプレビューでツールが呼び出されて回答が生成されることを検証します。
  6. エージェントを展開する
    watsonx Orchestrate 側のチャネル、または ContentIQ の Widget / Headless API から利用します。
