利用方法

Hello World エージェントの開発

ADK を使った最初のエージェント開発チュートリアル
最終更新: 2026/9/29

ADK のセットアップが完了したら、最初のエージェントを開発します。ここでは、チャットで「Greeting」と入力するとツールを実行して「Hello World」を返すエージェントを作成します。

詳細は ADK チュートリアル をご覧ください。

プロジェクト構成

ADK プロジェクトは、エージェント定義・ツール・ナレッジなどをフォルダで整理します。

adk-project/
├── agents/
├── tools/
├── knowledge/
└── flows/

以下のコマンドでフォルダ構成を作成します：

mkdir -p adk-project/{agents,tools,knowledge,flows}

エージェントの開発

ツールファイルを作成する

adk-project/tools/greetings.py を作成し、以下のコードを記述します。

# greetings.py
from ibm_watsonx_orchestrate.agent_builder.tools import tool

@tool
def greeting() -> str:
    """
    Greeting for everyone
    """
    greeting = "Hello World"
    return greeting

@tool デコレーターを付けた関数が、エージェントから呼び出せるツールになります。

エージェント定義ファイルを作成する

adk-project/agents/hello-world-agent.yaml を作成し、以下の内容を記述します。

spec_version: v1
kind: native
name: greeter
description: An agent that greets you using the output from its tool
instructions: Always run the tool "Greeting" when the user types Greeting in the chat.
llm: groq/openai/gpt-oss-120b
style: react_core
collaborators: []
tools:
  - greeting
フィールド説明
nameエージェント名
instructionsLLM への動作指示
llm使用するモデル
tools使用するツール名のリスト

ツールをインポートする

adk-project/ の親ディレクトリで以下を実行します。

orchestrate tools import -k python -f adk-project/tools/greetings.py

エージェントをインポートする

orchestrate agents import -f adk-project/agents/hello-world-agent.yaml

成功すると以下のメッセージが表示されます：

[INFO] - Agent 'greeter' imported successfully

エージェントのテスト

watsonx Orchestrate の Agent Builder を開き、インポートした greeter エージェントを選択します。チャット欄に「Greeting」と入力すると、ツールが実行されて「Hello World」が返されます。

次のステップ

エージェントの開発に慣れたら、IBM Bob を使った ADK 開発も参照してください。Bob と watsonx Orchestrateを組み合わせることで、コード作成支援を受けながら開発できます。
