IBM Bob を使った ADK 開発

IBM Bob と watsonx Orchestrate ADK を組み合わせた Python ツール・エージェント開発
最終更新: 2026/9/29

IBM Bob とは

IBM Bob は、AI を活用したソフトウェア開発パートナーです。チャット形式でやり取りし、自然言語での指示をもとにコードの生成・修正・ファイル操作・コマンド実行などを行えます。MCP（Model Context Protocol）を通じて外部ツールと連携することも可能です。

詳細は IBM Bob をご覧ください。

IBM Bob と watsonx Orchestrate を組み合わせると、Bob への会話だけでツールの実装からエージェントの登録までを行えます。

前提条件

  • IBM Bob：インストールされていること。まだの場合は IBM Bob 無料トライアル に登録してご利用ください
  • watsonx Orchestrate ADK：セットアップが完了していること。環境をお持ちでない場合は、ADK のセットアップを参照してください

Qiita 記事

具体的な手順は以下の記事で紹介しています。

IBM Bob × watsonx Orchestrate：Python ツールと通貨変換エージェントを会話だけで構築する（Qiita）

記事では、Bob に日本語でメッセージを送るだけで、以下の作業を完結させる手順を紹介しています：

  • プロジェクトディレクトリの作成と仮想環境のセットアップ
  • @tool デコレーターを使った Python ツールの実装（通貨変換ツール 2 本）
  • pytest による自動テストの作成と実行
  • orchestrate tools import によるツールの登録
  • エージェント定義 YAML の生成と orchestrate agents import による登録
