初期設定

ADK のセットアップ

watsonx Orchestrate ADK のインストールと環境設定
最終更新: 2026/9/29

ADK とは

ADK（Agent Development Kit）は、watsonx Orchestrate のエージェントとツールをコードで作成・テスト・デプロイするための CLI ツールおよび Python モジュール群です。IBM Cloud・AWS・オンプレミスなど、すべての watsonx Orchestrate 環境に対応しています。

ADK を使うと、以下が可能になります：

  • YAML または JSON ファイルでエージェントを定義し、エージェントの設計を完全にコントロールできる
  • Python でカスタムツールを作成し、エージェントの機能を拡張できる
  • CLI の数コマンドでエージェントのライフサイクル（作成・更新・削除）を管理できる
  • 作成したエージェントとツールは、すべての watsonx Orchestrate 環境で再利用できる

詳細は ADK ガイド をご覧ください。

ADK ガイドは現時点では英語のみ提供されています。ブラウザーの翻訳機能（Chrome の場合はページ右クリック →「日本語に翻訳」）を使うと日本語で参照できます。

主要コンポーネント

ADK を使った開発では、以下の2つが基本的な構成要素です。

コンポーネント説明
Agent（エージェント）ツールや他のエージェントを使ってタスクを計画・実行する AI エージェント。実行結果を振り返りながら出力を改善し、定義した目標に沿って動作する
Tool（ツール）エージェントが呼び出す関数。外部 API の呼び出しや Python スクリプトの実行など、特定のアクションを担う

開発の全体像

ローカルで定義した Tool と Agent を ADK CLI で watsonx Orchestrate にインポートし、ユーザーがチャット UI または API 経由で利用します。

詳細は ADK ガイド をご覧ください。

前提条件

ADK を利用するには、以下が必要です：

  • Python 3.11 以上：ターミナルで python --version を実行してバージョンを確認できます。3.11 未満の場合は python.org からインストールしてください。pip は Python に付属しています
  • watsonx Orchestrate アカウント：既存のアカウントがあればそのまま使用できます。環境をお持ちでない方は、30日間無料トライアルから申し込めます
本ガイドでは、IBM Cloud 上の watsonx Orchestrate 環境に対して、macOS での ADK セットアップ方法を紹介します。他のシステムでのセットアップ手順については、ADK ガイドをご参照ください。

ADK のインストール

本ガイドでは、仮想環境（venv）を使用して ADK をインストールします。仮想環境を使うと、プロジェクトごとにパッケージを独立して管理でき、エージェントやツールを他のメンバーと共有する際にも環境の再現が容易になります。

仮想環境を作成する

python -m venv .venv

仮想環境を有効化する

source ./.venv/bin/activate

プロンプトの先頭に (.venv) が表示されれば、有効化できています。

ADK をインストールする

pip install ibm-watsonx-orchestrate

インストールを確認する

orchestrate --version

バージョン番号が表示されれば、インストール完了です。

ADK をアップグレードする場合

pip install --upgrade ibm-watsonx-orchestrate

watsonx Orchestrate への接続設定

ADK から watsonx Orchestrate に接続するには、サービスインスタンス URL と API キー が必要です。取得方法は認証情報の取得を参照してください。

環境を登録する

取得したサービスインスタンス URL を使用して環境を登録します。

orchestrate env add -n <環境名> -u <サービスインスタンスURL>
オプション説明
-n環境の名前（任意の文字列）
-uサービスインスタンス URL
--type認証タイプを明示する場合に指定。IBM Cloud は ibm_iam、AWS は mcsp、オンプレミスは cpd（通常は URL から自動推定されるため省略可）
--activate登録と同時に有効化する場合に指定

環境を有効化する

orchestrate env activate <環境名>

実行すると API キーの入力を求められます。取得した API キーを入力してください。

Please enter WXO API key:
リモート環境への認証は2時間で失効します。失効後は再度 orchestrate env activate を実行してください。
orchestrate --help で利用可能なコマンドの一覧を確認できます。

ADK のセットアップが完了したら、Hello World エージェントの開発に進んでください。
