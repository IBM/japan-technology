製品別ガイドへの導線 | IBM Maximo Application Suite オンボーディング

ご利用の Function に合わせたオンボーディングガイドをご確認ください。

MAS はご利用の Function によって利用開始後の手順が大きく異なります。
以下から該当する製品のオンボーディングガイドに進んでください。

Maximo Manage

設備・資産の台帳管理、作業指示書の発行・クローズ、在庫管理、予防保全計画など、資産のライフサイクル全体を一元管理する EAM（Enterprise Asset Management）アプリケーションです。製造業・公共インフラ・施設管理など幅広い業種で活用されています。

→ Maximo Manage オンボーディングガイド

Maximo Visual Inspection (MVI)

AI を活用した画像・映像による外観検査・品質管理アプリケーションです。ノーコードで独自の検査モデルをトレーニングし、製造ラインや設備の異常検知に活用できます。

→ Maximo Visual Inspection オンボーディングガイド

Maximo IT

IT 資産管理（ITAM）および ITSM（IT サービス管理）に対応したアプリケーションです。ハードウェア・ソフトウェア資産の可視化や、インシデント・変更管理のプロセス整備に活用できます。

→ Maximo IT オンボーディングガイド

Maximo Monitor

IoT センサーデータを収集・分析し、設備の状態監視・異常検知をリアルタイムで行うアプリケーションです。Maximo Manage と連携して予知保全の実現に活用されます。

→ Maximo Monitor オンボーディングガイド
