EAM とは

IBM Maximo Application Suite（MAS）は、EAM（Enterprise Asset Management / エンタープライズ資産管理） の製品として位置付けられています。
MAS を利用するにあたり、まずは EAM とは何か？について理解しましょう。

EAM（Enterprise Asset Management）とは

EAM とは、企業が保有する物理的な資産（設備・機器・インフラなど）のライフサイクル全体を一元管理するための仕組みや考え方です。

企業が保有する資産には、以下のようなものが含まれます。

  • 製造設備・生産ライン
  • 建物・施設・インフラ
  • 車両・重機
  • IT機器・ネットワーク機器

これらの資産は、導入 → 運用 → 保全 → 廃棄 というライフサイクルを持ちます。EAM はこのライフサイクル全体を通じて、資産の可用性向上・コスト最適化・リスク低減を実現することを目的としています。

なぜ EAM が必要なのか

資産管理を適切に行わないと、以下のような問題が発生します。

  • 予期せぬ設備故障による生産停止・サービス停止
  • 過剰な保守コスト（必要以上の点検・部品交換）
  • 資産の所在・状態の不透明さによる非効率な運用
  • コンプライアンス違反（点検記録の未整備など）

EAM を導入することで、これらの問題に対して以下のアプローチが可能になります。

  • 資産の台帳管理による所在・状態の可視化
  • 作業指示書による保全作業の標準化・記録
  • 予防保全計画による計画的なメンテナンス
  • データに基づく意思決定の高度化

MAS とは

IBM Maximo Application Suite（MAS）は、IBM が提供する EAM プラットフォームです。
資産管理・設備保全・運用最適化に必要な複数のアプリケーション（Function）を、単一のプラットフォーム上で統合的に提供します。

MAS の特徴

1. 統合ライセンス（AppPoint）

MAS では、従来製品（Maximo 7.6）のようにアプリケーションごとにライセンスを購入するのではなく、AppPoint と呼ばれる統合ライセンスを採用しています。
AppPoint を消費することで、各 Function を柔軟に利用できます。詳細は AppPoint ライセンスの考え方 を参照してください。

2. クラウドネイティブな設計

MAS は Red Hat OpenShift 上で動作するコンテナベースのアーキテクチャを採用しています。
IBM が管理する SaaS 形式での提供のほか、お客様環境の OpenShift 上へのインストール（Dedicated / On-Premises）も可能です。

3. 複数 Function の統合

MAS は単一製品ではなく、複数の Function で構成されます。お客様のニーズに合わせて必要な Function を選択・組み合わせて利用できます。

Function概要
Maximo Manage資産・作業指示・在庫の一元管理（EAM コア）
Maximo Visual Inspection (MVI)AI を活用した画像・映像による外観検査・品質管理
Maximo ITIT 資産管理（ITAM）・IT サービス管理（ITSM）
Maximo MonitorIoT センサーデータによる設備状態監視・異常検知

上記の他に、Maximo Manage と連携して使う上位 Function として Maximo Health（資産の健全性スコアリング）・Maximo Predict（AI による故障予測）・Maximo Assist（保全作業者向け AI ガイダンス）があります。これらは Maximo Manage の利用が安定してきた段階で導入を検討するものです。

すべての Function を利用する必要はありません。まずは Maximo Manage から利用を開始し、必要に応じて他の Function を追加していくアプローチが一般的です。
