利用開始前の確認事項

MAS Hub 初回ログイン | IBM Maximo Application Suite オンボーディング

MAS Hub への初回ログイン手順を確認しましょう。

このページは、MAS を利用するすべてのユーザーを対象としています。 初期管理者と一般ユーザーそれぞれの初回ログイン手順を説明します。

Step 1｜初期管理者タスク：MAS Hub への初回ログイン

MAS SaaS のプロビジョニングが完了すると、初期管理者として登録されたメールアドレスに ウェルカムレター が届きます。 ウェルカムレターに記載された URL にアクセスし、IBMid を使用して MAS Hub にログインしてください。

MAS SaaS の URL は以下の形式です。

https://home.<organization>.suite.maximo.com
<organization> の部分はご契約内容によって異なります。ウェルカムレターに記載の URL をご確認ください。

ログイン後、MAS Hub の管理画面が表示されます。続けて一般ユーザーの追加を行ってください。

Step 2｜全員：言語・地域の設定（オプション）

初回ログイン後、必要に応じて画面の表示言語とタイムゾーンを設定できます。

  1. 画面右上のプロフィールアイコンをクリックする

  1. 「プロファイルの編集」 をクリックする → 「プロファイルの管理」モーダルが開く
  2. 「言語と地域」 タブを選択する
  3. 「ロケール」「言語」「タイム・ゾーン」 を設定して 「保存」 をクリックする

ここでの設定はブラウザのデフォルト言語設定より優先されます。例えば、ブラウザが英語設定でも、ここで日本語を設定すると日本語で表示されます。この設定はあとからいつでも変更できます。

Step 3｜初期管理者タスク：ユーザーの追加

初期管理者は MAS Hub から管理者および一般ユーザーを追加し、認証方式と各 Function へのアクセス権を設定します。 メール通知が構成されている場合は、対象ユーザーにログイン情報が送信されます。

詳細な手順は ユーザーの追加と権限設定 を参照してください。

Step 4｜一般ユーザータスク：初回ログイン

初期管理者から案内された MAS SaaS の URL にアクセスし、環境に設定された認証方式でログインしてください。

一般ユーザーの認証方式は環境によって異なります。IBMid を使用する場合もあれば、初期管理者が設定した Local、LDAP、SAML、OIDC などを使用する場合もあります。ログイン方法が不明な場合は、初期管理者に確認してください。

ログイン後、MAS Hub のスイートナビゲーター画面が表示されます。 「アプリケーション」タブに利用可能な Function のタイルが並んでいることを確認してください。

ご契約の Function のみ「ご使用のアプリケーション」に表示されます。契約していない Function は「その他のアプリケーション」に鍵アイコン付きで表示されます。
Function が表示されていない場合は、初期管理者に各 Function へのアクセス権が付与されているか確認してもらってください。
