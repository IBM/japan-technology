利用開始前の確認事項

環境の確認 | IBM Maximo Application Suite オンボーディング

MAS を利用開始する前に確認すべき環境情報をまとめています。

このページは、MAS を利用するすべてのユーザーを対象としています。 利用開始前に以下の流れと確認事項をご確認ください。

利用開始までの流れ

MAS SaaS のご契約後、IBM が環境を準備し、初期管理者へウェルカムレターを送付します。 ウェルカムレターを受け取った後は、以下の流れで利用開始の準備を進めます。

ステップ実施者内容
0IBMご契約時の登録情報をもとに、MAS SaaS 環境を準備（プロビジョニング）する
1初期管理者ウェルカムレターを受け取り、環境 URL とログイン方法を確認する
2初期管理者IBMid を使用して MAS Hub へ初回ログインする
3初期管理者セキュリティグループを確認し、必要に応じて作成する
4初期管理者管理者および一般ユーザーを登録し、認証方式、アクセス種別、権限を設定する
5管理者・一般ユーザー環境に設定された認証方式で初回ログインする
6全員利用する Function のオンボーディングガイドへ進む
Step 0 の SaaS 基盤の準備は IBM が実施します。環境提供後のユーザー登録、権限設定、および各 Function の業務設定は、お客様側で実施します。このガイドでは、IBM に初期管理者として登録され、最初にウェルカムレターを受け取る方を 「初期管理者」 と表記します。初期設定の完了後は、初期管理者から必要な管理権限を付与された管理者も、セキュリティグループの管理やユーザー登録を実施できます。

IBMid の準備

MAS SaaS の初期管理者が最初にログインする際は、IBMid が必要です。

IBMid とは、IBM のサービス全般で使用するシングルサインオン用のアカウントです。 すでに IBMid をお持ちの場合はそのままご利用いただけます。

IBMid をお持ちでない場合は、IBMid の新規登録 から作成してください。

会社のメールアドレスで IBMid を作成することを推奨します。個人のメールアドレスで作成した場合、退職時などにアクセスできなくなる可能性があります。一般ユーザーのログイン方法は、環境に設定された認証方式によって異なります。初期管理者が LDAP、SAML、OIDC などを設定した場合、一般ユーザーが IBMid を使用しないことがあります。初期管理者から案内された認証方式でログインしてください。

推奨ブラウザの確認

MAS は以下のブラウザの最新版に対応しています。

ブラウザ備考
Google Chrome推奨
Microsoft Edge推奨
Mozilla Firefox対応
Apple Safari対応
Internet Explorer はサポートされていません。上記のブラウザをご利用ください。

上記は MAS 9.2 時点の情報です。お使いのバージョンでの最新情報は IBM Software Product Compatibility Reports でご確認ください。

ネットワークの確認

社内ネットワークにプロキシやファイアウォールが設定されている場合、MAS への接続がブロックされることがあります。
接続できない場合は、社内のネットワーク管理者に MAS の URL へのアクセス許可をご依頼ください。

MAS の接続先 URL は、ご契約時に IBM またはパートナーから提供されます。
