セキュリティグループの作成 | IBM Maximo Application Suite オンボーディング

ユーザーを追加する前に、セキュリティグループを作成しましょう。

このページは 管理者向け です。

MAS にユーザーを追加する前に、セキュリティグループを作成しておくことを推奨します。
先にセキュリティグループを用意しておくことで、ユーザー追加時にすぐに権限を割り当てられます。

セキュリティグループとは

セキュリティグループは、MAS 内のアプリケーション・データ・サイトへのアクセス権限をまとめたグループです。
ユーザーに個別に権限を設定するのではなく、セキュリティグループにユーザーを所属させることで権限を管理します。

MAS には最初からいくつかの定義済みグループ（MAXADMIN・USERMANAGEMENT など）が用意されています。
これらを使って初期設定を始めることも、独自のグループを作成することもできます。

セキュリティグループは Suite > Access and usage > Security groups から確認・作成できます。MAS 9.1 の場合は Suite > Security > Security groups を選択してください。

どのグループが必要か考える

ユーザーを追加する前に、社内にどのような役割のユーザーがいるかを整理しましょう。
公式ドキュメントでは、以下の5つのサンプルグループが用意されています。

サンプルグループ名想定する役割主なアクセス範囲
Administratorシステム管理者ユーザー管理・セキュリティ設定・システム全体の構成
Supervisor現場監督者作業指示・資産・スケジュール・承認など広範な操作
Technician現場技術者作業指示の実施・労働報告・サービスリクエスト
Requester依頼者サービスリクエストの作成・確認のみ
Inventory Clerk在庫管理担当在庫・資材の受払・在庫カウント
これらはあくまでサンプルです。実際の業務に合わせてカスタマイズしてください。また、1人のユーザーを複数のグループに所属させることで、権限を組み合わせることができます。

セキュリティグループの作成手順（概要）

  1. Suite > Access and usage > Security groups を開く
  2. 「グループの作成」 をクリック
  3. 「ID」タブ でグループ名と説明を入力し 「グループを作成」 をクリック

  1. 「アプリケーション」タブ で許可するアプリケーションと権限を設定

左ペインでアプリケーションを選択すると、中央ペインに権限の一覧が表示されます。付与したい権限にチェックを入れると、右ペインに追加されます。

  1. 「制約事項」タブ はスキップしてOK（初期設定では設定不要）

特定のアプリケーション（Manage 内の画面・機能単位で割り当てられたコード。例：CREATESR＝サービスリクエスト作成、ASSET＝資産管理など579件以上）に対してデータレベルのアクセス制限が必要な場合のみ設定します。マルチサイト運用や部門間のデータ分離が必要になった際に改めて設定してください。

  1. 「ユーザー」タブ でグループに所属させるユーザーを追加（後からでも可）
  2. 「グループを作成」 をクリックして保存
各アプリケーションをサイドナビゲーションに表示させるには、最低限「読み取り」権限が必要です。

詳細な手順およびサンプルグループの権限一覧は、IBM 公式ドキュメント を参照してください。

セキュリティグループ作成後の次のステップ

セキュリティグループが準備できたら、ユーザーを追加してグループに割り当てます。
ユーザーの追加と権限設定 に進んでください。
