利用開始前の確認事項

Suite License Manager でライセンス確認 | IBM Maximo Application Suite オンボーディング

SLM で AppPoint の消費状況を確認しましょう。

このページは 管理者向け です。

環境の設定が完了し、ユーザーが利用を開始したら、定期的に AppPoint の使用状況を確認することを推奨します。

使用状況ダッシュボードを開く

  1. Suite > Access and usage > AppPoints usage を選択する

  1. 右上のドロップダウンで期間を選択する
選択肢内容
今日当日の使用状況
昨日前日の使用状況
月次月を指定して確認（過去数ヶ月分を選択可能）
毎年年間の使用状況
定期的な確認には 「月次」 を選択することを推奨します。月次を選ぶと、確認したい年月をさらにドロップダウンで選択できます。

画面の見方

項目内容
すべてのインスタンスにおける現在の AppPoint の使用状況現時点での AppPoint 使用数
すべてのインスタンスにおける割り当て容量組織で契約済みの AppPoint 総数
この期間の総ピーク使用量選択した期間中のピーク時の使用量（全インスタンス合計）
総ピーク使用量のタイムスタンプピーク使用量が記録された日時
レポートの最終更新レポートの最終更新日時
ライセンスの有効期限契約ライセンスの有効期限
Peak usage vs previous months過去の月と比較したピーク使用量のグラフ
インスタンスごとのサブスクリプションピーク使用量インスタンス別のピーク使用量グラフ
AppPoint のピーク使用量の内訳アプリケーション別の AppPoint 使用量内訳
ピーク使用量とは、選択した期間の中で AppPoint の使用量が最も多かった瞬間の値です。Concurrent ユーザーはログイン中のみ AppPoint を消費するため、同時ログインが集中した時間帯の値が反映されます。

AppPoint が不足しそうな場合

Capacity に対して Peak usage が近づいてきたら、早めに追加購入を検討してください。

追加購入の方法：

  • 担当の IBM 営業・パートナーに直接ご連絡ください
  • IBM サポートにケースを開設することも可能です
AppPoint の追加購入には一定のリードタイムが必要です。残量が少なくなってきたら早めにご相談ください。Concurrent ユーザーは AppPoint が不足するとログインできなくなります。
