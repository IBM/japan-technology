利用開始前の確認事項

ユーザーの追加と権限設定 | IBM Maximo Application Suite オンボーディング

MAS Hub でユーザーを招待し、各 Function へのアクセス権限を付与する手順を確認しましょう。

このページは 管理者向け です。

はじめに

MAS のユーザー管理は以下の 2段階 で構成されています。

  1. MAS Hub でユーザーを追加する（本ページで説明）
  2. 各 Function 内でアクセス権限を設定する（各 Function のオンボーディングガイドで説明）

「MAS にログインできる」状態と「各 Function が使える」状態は別です。 MAS Hub でユーザーを追加しただけでは各 Function は利用できないため、必ず両方の設定が必要です。

ユーザーを追加する前に、セキュリティグループを作成しておくことを推奨します。先にセキュリティグループを用意しておくことで、ユーザー追加時にすぐに権限を割り当てられます。詳細は セキュリティグループの作成 を参照してください。

STEP 1: MAS Hub でユーザーを追加する

手順

  1. サイドナビゲーションメニューから 「Suite」 > 「Access and usage」 > 「Users」 を選択する
MAS 9.1 の場合は 「Suite」 > 「Security」 > 「Users」 を選択してください。
  1. 「ユーザーの作成」 をクリックする
  2. 「ID & 認証」 タブでユーザー情報を入力する

項目内容
User IDログイン時に使用する一意のID
表示名画面上に表示される名前
担当者 ID通常は 「ユーザー ID を使用して生成します」 をそのまま選択してOK。既存ユーザーに紐付ける場合のみ変更が必要
Primary email招待メールの送付先。Primary email type はデフォルトの「WORK」のままでOK
  1. 「設定」 セクションでロケールとタイムゾーンを設定する（任意）

MAS 9.2 では、Maximo Manage ユーザー向けの追加設定（デフォルトサイト・ストアルーム・修理設備・スーパーバイザーなど）もこのセクションで設定できます。Locale の選択について：ja（Japanese）と ja_JP（Japanese (Japan)）の2つが選択肢に表示されます。日付・数値フォーマットなど地域固有の設定も適用される ja_JP を選択することを推奨します。Language の選択について： Manage アプリ内で使用する言語を指定します。日本語パックがインストールされていない環境では EN（English）のみ表示されます。日本語パック（JA）が適用済みであれば JA を選択してください。
  1. 「認証」 セクションで認証方式を選択する

認証方式概要
Local（ローカル）MAS 内のパスワードで認証
LDAP社内 LDAP サーバーと連携
SAML / OIDCIdP（ID プロバイダー）と連携
デフォルトでは Local（ローカル）しか表示されていません。LDAP・SAML・OIDC を利用する場合は、事前に IBM サポートへのケースオープンが必要です。
ユーザー名について： ユーザーがログインに使用する情報です。通常は「ユーザー ID と同じ」を選択してください。「プライマリ E メールと同じ」を選択した場合はメールアドレスがログイン名になります。
パスワードについて： 「自動生成」を選択した場合、SMTP が設定済みであれば初期パスワードがウェルカムメールでユーザーに送付されます。SMTP が未設定の場合はメールが送付されずパスワードが不明になるため、「カスタム」を選択して管理者が直接パスワードを設定することを推奨します。SMTP の設定については、Suite 管理ページの構成セクションを参照してください。
  1. 「作成 & 継続アクセス」 または 「作成 & 終了」 を選択してユーザーを作成する
オプション内容
作成 & 継続アクセス作成後すぐにアクセス権とセキュリティグループを設定する
作成 & 終了ユーザーレコードのみ作成し、アクセス権は後で設定する
  1. 「アクセス & ライセンス」タブ でアクセスタイプを設定する

アクセスタイプ内容
Authorized（承認済み）ユーザー作成時に AppPoint を永続予約。常にログイン可能。管理者には必須
Concurrent（同時接続）ログイン中のみ AppPoint を消費。ログアウトで返却

詳細は AppPoint ライセンスの考え方 を参照してください。

  1. 「セキュリティグループ」 セクションで、作成済みのセキュリティグループを割り当てる
DEFLTREG（New User）と EVERYONE（All Maximo Users）の2グループはすべての新規ユーザーにデフォルトで自動付与されています。Manage の機能を使うには、これらに加えて必要なセキュリティグループを別途割り当ててください。
  1. 変更を保存する

ユーザーの保存後、登録したメールアドレスにログイン情報とアクセス URL が記載されたメールが自動送信されます。

管理者ユーザーを作成する場合は、アクセスタイプを必ず 「Authorized（承認済み）」 に設定してください。

STEP 2: 各 Function へのアクセスを付与する

MAS Hub でのユーザー追加後、利用する Function ごとに追加の権限設定が必要です。

Function参照先
Maximo ManageMaximo Manage — ユーザーとセキュリティグループ
Maximo MVIMaximo Visual Inspection — ユーザーアクセスの付与
Maximo ITMaximo IT オンボーディングガイド
Maximo MonitorMaximo Monitor オンボーディングガイド
各 Function の権限設定はそれぞれ独立しています。複数の Function を利用する場合は、Function ごとに設定が必要です。
