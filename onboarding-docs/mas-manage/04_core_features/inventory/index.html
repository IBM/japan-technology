主要機能ガイド

在庫（Inventory） | Maximo Manage オンボーディング

在庫品目の登録・払い出しなど、Inventory アプリケーションの基本操作を学びましょう。

在庫（Inventory） は、保全作業に使用する部品・資材を管理する機能です。
作業指示書と連携することで、使用した資材の記録や在庫残数の自動更新ができます。

在庫管理の基本概念

Manage の在庫管理には、以下の2つの主要な概念があります。

品目（Item）

品目 は、在庫として管理する部品・資材の「種類」を定義したマスターデータです。
品目マスターに登録することで、複数の倉庫をまたいで同じ品目を管理できます。

在庫（Inventory）

在庫 は、特定の倉庫（ストアルーム）における品目の実際の保有数量です。
同じ品目でも、倉庫ごとに別々の在庫レコードが作成されます。

品目の登録

  1. Go To メニューから 「Inventory」（在庫）> 「Item Master」（品目マスター） を開く
  2. 「New Item」（新規品目） をクリック
  3. 品目番号・説明・単位を入力
  4. 「保存」 をクリック
品目番号は一度登録すると変更できません。採番ルールを事前に決めておきましょう。

在庫の登録（ストアルームへの追加）

品目を特定のストアルームに在庫として登録します。

  1. Go To メニューから 「Inventory」（在庫）> 「Inventory」（在庫） を開く
  2. 「New Row」（新規行） をクリック
  3. 品目番号・ストアルーム・現在数量を入力
  4. 必要に応じて発注点・最大在庫数を設定
  5. 「保存」
設定項目内容
現在数量現在の在庫数
発注点この数量を下回ったら発注を検討
最大在庫数補充時の目標在庫数

在庫の払い出し

作業指示書に資材を使用した際、在庫から払い出すことで在庫数が自動更新されます。

作業指示書から払い出す場合

  1. 作業指示書の 「資材」タブ を開く
  2. 使用した品目・数量を入力
  3. 「在庫払い出し」 を実行

直接払い出す場合

  1. Go To メニューから 「Inventory」（在庫）> 「Inventory Usage」（在庫使用） を開く
  2. 払い出す品目・ストアルーム・数量を入力
  3. 保存

在庫の受入

部品・資材を入荷した際は、「受入」 アプリケーションで在庫数を更新します。

  1. Go To メニューから 「Inventory」（在庫）> 「Receiving」（受入） を開く
  2. 発注書番号または品目番号を入力
  3. 受入数量を入力して保存
発注書と紐づけて受入処理をすることで、発注から受入までのトレーサビリティが確保できます。
