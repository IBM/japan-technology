主要機能ガイド

作業指示書（Work Orders） | Maximo Manage オンボーディング

作業指示書の作成・承認・クローズまでの基本的なフローを学びましょう。

作業指示書（Work Order） は、保全・修理・点検などの作業を記録・管理するための基本ドキュメントです。
Manage の日常業務の中心となる機能です。

作業指示書とは

作業指示書は、「誰が・何を・いつ・どこで」行うかを記録する作業の台帳です。

作業指示書を使うことで、以下が実現できます。

  • 作業の依頼・計画・実施・完了までの一連のフローを管理
  • 作業に使用した労働時間・資材・コストの記録
  • 資産ごとの保全履歴の蓄積
  • 承認フローによる作業の統制

作業指示書のステータスフロー

作業指示書はステータスで進捗を管理します。ステータスの変更は 「Change Status」 ダイアログから行います。

主なステータスの一覧です。

コード画面表示（英語）内容
WAPPRWaiting on approval作成直後。承認待ちの状態
APPRApproved承認済み。作業の実施が可能
INPRGIn progress作業進行中
WPCONDWaiting on plant cond設備停止待ちなど、条件待ちの状態
WMATWaiting on material資材待ちの状態
WSCHWaiting to be scheduledスケジュール待ちの状態
DEFERDeferred延期された状態
COMPCompleted作業完了。コストの確定前
CLOSEClosedクローズ済み。変更不可
CANCanceledキャンセル済み
表示されるステータスの選択肢は、セキュリティグループの権限設定によって制御されます。環境によって一部表示されないステータスがある場合があります。

作業指示書の作成手順

  1. Go To メニューから 「Work Orders」（作業指示）> 「Work Orders」（作業指示） を開く
  2. 「New Work Order」（新規作業指示） をクリック
  3. 以下の基本情報を入力する
項目内容
説明作業の内容を簡潔に記載
資産作業対象の資産番号
ロケーション作業場所
作業タイプCM（修正保全）・PM（予防保全）など
優先度作業の緊急度
担当者作業を担当する人
計画開始日作業を開始する予定日
  1. 必要に応じて 「Work」（作業）タブ で作業手順・必要資材・労働計画を追加
  2. 「Save Work Order」（保存） して承認フローへ

労働・資材の記録

作業完了後、以下の実績を記録します。

労働の記録

「Labor」（労働）タブ から実際にかかった工数（人・時間）を記録します。

資材の記録

「Materials」（資材）タブ から使用した部品・資材を記録します。在庫から払い出すことで在庫数が自動更新されます。

サービス要求（Service Request）との違い

サービス要求作業指示書
作成者一般ユーザー（依頼者）保全担当者・管理者
目的作業の依頼・報告作業の計画・実施・記録
流れサービス要求 → 作業指示書に昇格直接作成
一般ユーザーからの依頼はサービス要求で受け付け、保全担当者が作業指示書に昇格させるフローが一般的です。
