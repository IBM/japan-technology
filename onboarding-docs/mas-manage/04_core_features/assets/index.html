主要機能ガイド

資産（Assets）の管理 | Maximo Manage オンボーディング

資産台帳の登録・参照・更新など、Assets アプリケーションの基本操作を学びましょう。

資産（Asset） は Maximo Manage の中心となるデータです。
設備・機器・車両・インフラなど、保全・管理の対象となるすべての物理的なアイテムを資産として登録・管理します。

資産とは

Manage における「資産」とは、台帳に登録して管理する対象物のことです。

資産を登録することで、以下のことが可能になります。

  • 資産の所在・状態・担当者を一元管理
  • 資産に紐づいた作業指示・保全履歴の追跡
  • 稼働時間・故障回数などの実績データの蓄積
  • 予防保全（PM）スケジュールの適用

資産の主な属性

Manage の画面は英語で表示される場合があります。以下は画面上の英語表示と日本語の対応表です。

資産の登録手順

  1. Go To メニューから 「Assets」（資産）> 「Assets」（資産） を開く
  2. 「New Asset」（新規資産） をクリック
  3. 資産番号・説明・サイト・ロケーションを入力
  4. 必要に応じてシリアル番号・品目番号・稼働日を入力
  5. 「Save Asset」（保存） をクリック
資産番号は自動採番にすることも、手動で入力することもできます。管理しやすい採番ルールを事前に決めておきましょう。

資産階層（Parent / Child）

Manage では、資産を 親子関係（階層） で管理できます。

例：

プラントA（親資産）
├── ポンプユニット（子資産）
│   ├── モーター（孫資産）
│   └── インペラー（孫資産）
└── バルブ（子資産）

階層で管理することで、上位資産への作業や故障の影響範囲を把握しやすくなります。

ロケーションとの関係

資産は ロケーション（Location） に紐づけて管理します。ロケーションは建物・フロア・部屋など、資産の設置場所を表す概念です。

資産とロケーションを紐づけることで、「どこに何があるか」を地図的に把握できます。

ロケーションは Go To メニューの 「Assets」（資産）> 「Locations」（ロケーション） から登録・管理できます。

資産・拠点ダッシュボード（MAS 9.2 以降）

Maximo Health をご利用のお客様は、資産やロケーションの詳細画面から 「資産・拠点ダッシュボード」 にアクセスできます。

健全性スコア・アラート・信頼性・ライフサイクルといった主要な運用データを一画面で確認でき、そこから直接作業指示書への移動などのアクションも実行できます。

資産・拠点ダッシュボードは Maximo Health のライセンスが必要です。Maximo Health をお持ちでない場合はこの機能は表示されません。
