EAM（Enterprise Asset Management）の中核アプリケーションである Maximo Manage を理解しましょう。

MAS 共通ガイドで説明した通り、MAS は複数の Function で構成されています。その中核となるのが Maximo Manage です。

Maximo Manage とは

Maximo Manage は、MAS の中核となる EAM（Enterprise Asset Management）アプリケーションです。

設備・資産の台帳管理から、作業指示書の発行・クローズ、在庫管理、予防保全計画まで、資産のライフサイクル全体を一元管理できます。すべての資産タイプ・状態・ロケーション、それらをサポートする作業プロセスを包括的に把握することで、計画的な資産管理・コンプライアンス対応・意思決定の高度化を実現します。

MAS 共通ガイドをまだ読んでいない場合は、先に MAS とは をご確認ください。EAM の概念や AppPoint ライセンスの考え方が理解できます。

Maximo Manage の主な機能

機能領域内容
資産管理資産台帳の作成・管理、資産の階層構造・ロケーション管理
作業管理作業指示書の発行・実施・クローズ、労働・資材の記録
予防保全定期点検・PM（Preventive Maintenance）スケジュールの管理
在庫管理部品・資材の入出庫、在庫カウント、発注管理
購買管理発注書・契約の管理、サプライヤー管理
セキュリティユーザー・セキュリティグループによるアクセス制御

アドオン・業種別ソリューション

Maximo Manage は標準機能に加えて、業務や業種に応じたアドオンや業種別ソリューションを追加できます。

主なアドオン

アドオン概要
Maximo Mobileスマートフォン・タブレットで作業指示や点検を実施（App Store / Google Play から入手）
Maximo SpatialGIS（地図情報）と連携した資産・作業の空間管理
Maximo Health, Safety and Environment安全衛生・環境管理への対応
Maximo Asset Configuration Manager航空・防衛向けの構成管理

主な業種別ソリューション

ソリューション対象業種
Maximo Aviation航空業
Maximo Utilities電力・ガス・水道などのユーティリティ
Maximo Nuclear原子力
Maximo Transportation交通・輸送
Maximo Civil Infrastructure土木インフラ
アドオンや業種別ソリューションの利用には、別途ライセンスが必要な場合があります。詳細は担当の IBM 営業またはパートナーにご確認ください。

外部システムとの連携

Maximo Manage は、ERP などの外部システムとのコネクターも提供しています。

  • SAP との連携（Maximo Connector for SAP Applications）
  • Oracle との連携（Maximo Connector for Oracle Applications）
  • Workday との連携（Maximo Connector for Workday Applications）
  • TRIRIGA との連携（施設管理システムとの統合）
  • Envizi との連携（サステナビリティ管理）

他の MAS Function との関係

Maximo Manage は単独でも強力な EAM を実現しますが、他の MAS Function と組み合わせることでさらに高度な運用が可能になります。

連携 FunctionManage との関係
Maximo HealthManage の資産データをもとに健全性スコアを算出
Maximo Predictセンサーデータと Manage の保全履歴から故障を予測
Maximo MonitorIoT センサーで設備の異常を検知し、Manage に作業指示を自動生成
Maximo Assist作業者に AI が手順ガイダンスを提供
まずは Maximo Manage の基本機能を使いこなすことが最初のゴールです。他の Function との連携は、Manage の運用が安定してから検討しましょう。
