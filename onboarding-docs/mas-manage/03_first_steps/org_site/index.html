Organization / Site の理解と確認 | Maximo Manage オンボーディング

Maximo Manage の運用単位となる Organization と Site の概念を理解し、自社環境を確認しましょう。

このページは 管理者向け です。

Maximo Manage では、Organization（組織） と Site（サイト） が運用の基本単位となります。資産・在庫・作業指示などすべてのデータはいずれかのサイトに紐づいて管理されます。

SaaS 環境や Maximo 7.6 などの旧バージョンから移行されたお客様の場合、Organization と Site は導入時点で設定済みのことがほとんどです。まずは自社環境にどの Organization・Site が設定されているかを確認しましょう。

Organization（組織）とは

Organization は、会社・企業単位の管理グループです。

財務・通貨・会計年度など、会社全体に共通する設定を Organization レベルで管理します。

設定項目内容
通貨発注書・契約などで使用する通貨
会計期間会計年度の開始月
品目番号の採番ルール在庫品目の番号付けルール
多くの場合、Organization は会社単位で1つ作成します。複数の子会社・グループ会社を管理する場合は、Organization を複数作成することもあります。

Site（サイト）とは

Site は、物理的な拠点・場所の単位です。工場・事業所・ビルなど、実際に資産が存在する場所に対応します。

資産・作業指示・在庫は、必ずいずれかの Site に所属します。ユーザーは自分がアクセスできる Site のデータのみ操作できます。

設定項目内容
サイト IDサイトを識別する一意のコード（例：TOKYO, OSAKA）
説明サイトの名称・概要
Organization所属する Organization
Site は Organization の配下に作成します。1つの Organization に複数の Site を持てます。

Organization と Site の関係

Organization（会社全体）
├── Site A（東京工場）
├── Site B（大阪事業所）
└── Site C（名古屋センター）

実際の運用では、以下のようなイメージです。

OrganizationSite
株式会社〇〇東京本社、大阪工場、福岡営業所

設定の確認・作成手順

Organization と Site の確認・作成は、Administration（管理）> Organizations（組織） から行います。

現在の設定を確認する

  1. Go To メニューから 「Administration」（管理）> 「Organizations」（組織） を開く
  2. 一覧に表示される Organization と、その配下の Site を確認する

新規に作成する場合

Organization の作成

  1. Go To メニューから 「Administration」（管理）> 「Organizations」（組織） を開く
  2. 「New Organization」（新規組織） をクリック
  3. 組織 ID・説明・通貨などの基本情報を入力
  4. 「保存」 をクリック

Site の作成

  1. 作成した Organization のレコードを開く
  2. 「Sites」（サイト）タブ を選択
  3. 「New Row」（新規行） をクリックしてサイト情報を入力
  4. サイト ID・説明を入力して 「Save」（保存）
Organization と Site は、一度データ（資産・作業指示など）が登録されると変更・削除が困難になります。運用開始前に、社内の拠点構成をよく検討した上で設定してください。

設定のポイント

シンプルに始める

最初から複雑な構成にする必要はありません。まずは実際の拠点に対応した Site を1〜2つ作成し、運用しながら必要に応じて追加するアプローチが無難です。

サイト ID は短く・わかりやすく

サイト ID は入力の機会が多いため、短くて意味がわかるコードにしましょう。
例：TOKYO、OSAKA、FACTORY1 など

詳細は公式ドキュメントを参照

Organization / Site の詳細な設定項目については、IBM 公式ドキュメント を参照してください。
