はじめの設定と画面の見方

画面ナビゲーション（Go To メニュー） | Maximo Manage オンボーディング

Maximo Manage の基本的な画面操作と Go To メニューの使い方を学びましょう。

MAS Hub から Maximo Manage を起動すると、Manage の画面が表示されます。
まずは画面の基本的な構成とナビゲーション方法を理解しましょう。

Maximo Manage へのアクセス

MAS Hub のトップ画面に表示されている 「Maximo Manage」 のタイルをクリックすると、Manage の画面に遷移します。

Manage のタイルが表示されていない場合は、管理者に Manage へのアクセス権が付与されているか確認してもらってください。

直接アクセスする場合は、以下の形式の URL を使用します。

https://<organization>.manage.maximo.com/maximo

画面の基本構成

Maximo Manage の画面は、以下の3つのエリアで構成されています。

エリア場所内容
トップバー画面最上部Bulletins・Reports・AI アシスタント・ヘルプ・プロファイル
サイドバー画面左端（常時表示）アイコンのみ表示。クリックで各機能へ直接移動
Go To メニューサイドバー最上部の ≡ を押して展開モジュール・アプリケーション一覧
メインエリア画面中央各アプリケーションの操作画面 / Start Center

Go To メニューの使い方

Maximo Manage では、すべての機能（アプリケーション）に Go To メニュー（ナビゲーションメニュー）からアクセスします。

Go To メニューは Maximo の公式用語です。IBM の公式ドキュメントやサポートへの問い合わせ時にも使われるので、覚えておきましょう。

開き方

画面左端のサイドバーにアイコンが常時表示されています。 最上部の ≡（ハンバーガーアイコン） をクリックするとメニューが展開し、アプリケーション名が表示されます。

メニューの構成

Go To メニューはモジュール（業務領域）ごとにグループ化されています。ご契約の内容によって表示されるモジュール数は異なります。以下は主要なモジュールのグループです。

Go To メニューの表示言語は、MAS Hub のプロファイル設定に関わらず英語で表示される場合があります。
モジュール（英語表示）日本語主なアプリケーション例
Assets資産資産、ロケーション、計量器
Work Orders作業指示作業指示、サービス要求、活動、計画
Preventive Maintenance予防保全予防保全、測定値
Inventory在庫在庫、品目マスター、受入
Procurement購買発注書、要求書、契約
Administration管理組織、サイト、人、セキュリティグループ

フォーカスナビゲーション（MAS 9.2 以降）

MAS 9.2 以降では、フォーカスナビゲーション機能で Go To メニューに表示するアプリケーションを絞り込めます。よく使う機能だけを表示させることで、操作効率が上がります。

設定手順：

  1. サイドナビゲーションメニューの 「フォーカス設定」アイコン をクリック
  2. 「ご使用のアプリケーション」 セクションで表示したいアプリケーションにチェックを入れる
  3. 選択した項目が右側の 「ご利用のフォーカス・ナビゲーション」 セクションに追加される
  4. 「保存」 をクリック

フォーカスナビゲーションを解除したい場合は、「フォーカス」トグルをオフにするとアクセス権のある全アプリケーションが表示されます。

検索バーからのアクセス

画面上部の検索バーにアプリケーション名を直接入力しても素早くアクセスできます。正確な名前がわからない場合はキーワードの一部を入力するだけでも候補が表示されます。

アプリケーション画面の基本操作

各アプリケーション画面には共通の操作ボタンがあります。

ボタン操作
新規新しいレコードを作成
保存変更を保存
検索条件を指定してレコードを検索
フィルター一覧表示のフィルタリング
アクション承認・変更・削除などのステータス変更操作

プロファイルの設定

ログインユーザーの個人設定は、トップバー右上のユーザーアイコンから確認・変更できます。

設定項目内容
デフォルトサイト操作対象のサイトをあらかじめ設定しておける
タイムゾーン作業指示の日時表示に影響
言語画面の表示言語
デフォルトサイトを自分が担当するサイトに設定しておくと、毎回の絞り込みが不要になり便利です。

ヘルプの参照

画面右上の ？（ヘルプアイコン） から、現在の画面に関連する公式ドキュメントへアクセスできます。操作に迷ったらまずここを確認してみてください。
