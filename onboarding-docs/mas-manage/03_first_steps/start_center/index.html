はじめの設定と画面の見方

Start Center の見方 | Maximo Manage オンボーディング

ログイン後に表示される Start Center の構成と基本的なカスタマイズ方法を学びましょう。

Maximo Manage にログインすると、Start Center（スタートセンター） または 運用ダッシュボード が表示されます。
Start Center は、業務状況の確認や日々の作業への入口となるダッシュボード画面です。

運用ダッシュボード（Operational Dashboard）が設定されている環境では、ログイン直後に運用ダッシュボードが開く場合があります。その場合は左サイドバーの 「Start Center」アイコン をクリックすると Start Center に移動できます。

Start Center の画面構成

Start Center は複数のタブで構成されています。タブはセキュリティグループごとに割り当てられており、所属するセキュリティグループに応じて表示されるタブが異なります。

各タブには ポートレット（ウィジェット） が配置されています。主なポートレットの種類は以下の通りです。

ポートレット内容例
Favorite Applicationsよく使うアプリケーションへのクイックリンクLabor Reporting、Work Order Tracking など
Quick Insertレコードの新規作成ショートカットAdd Labor、Insert Work Order など
Bulletin Board管理者からのお知らせ掲示板システムメンテナンス通知など
Result Set指定条件でレコードを一覧表示自分の未完了作業指示など
KPI数値指標をグラフや数字で表示月次作業指示件数など

ポートレットのカスタマイズについて

ポートレットの追加・変更・レイアウト編集は、セキュリティグループの設定によって可否が異なります。

操作条件
自分の Start Center のレイアウト変更（列配置・順序）管理者が許可している場合、一般ユーザーも変更可能
テンプレートの作成・変更（全ユーザーへの適用）管理者のみ
ポートレットの追加・変更ボタンが表示されない場合は、管理者側の設定で制限されている可能性があります。管理者にご確認ください。

管理者権限があるユーザーは、Go To メニューの 「Administration」 > 「Start Center Templates」 からテンプレートの作成・変更が可能です。

複数タブの使い方

複数のセキュリティグループに所属しているユーザーには、グループごとのタブが表示されます。
タブをクリックして切り替えることで、役割ごとに異なる情報を確認できます。

まずはデフォルトの Start Center を使い始め、運用が安定してきたら管理者に依頼してテンプレートをカスタマイズしてもらうアプローチが無難です。

運用ダッシュボード（MAS 9.2 以降）

MAS 9.2 以降では、Start Center に加えて 「運用ダッシュボード（Operational Dashboard）」 も利用できます。
運用ダッシュボードは Start Center のよりモダンな後継画面で、KPI のモニタリングや期限が近いタスクの確認、他アプリケーションへのアクセスをより直感的に行えます。

運用ダッシュボードは Start Center と並行して利用できます。どちらを主に使うかはチームの運用方針に合わせて決めてください。
