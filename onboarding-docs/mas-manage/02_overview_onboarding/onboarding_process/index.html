オンボーディングの流れ

オンボーディングの流れ | Maximo Manage オンボーディング

Maximo Manage を活用できるようになるまでのステップを確認しましょう。

はじめに

本ガイドは、Maximo Manage を初めて利用する方が、業務で活用できるようになるまでのステップをご案内するオンボーディングガイドです。

MAS Hub へのログインやユーザー追加は MAS 共通オンボーディングガイド で完了している前提で進めます。まだの場合は先に共通ガイドをご確認ください。

このガイドを最後まで進めると、バラバラだった資産・作業・在庫の情報が一か所に集まり、現場と管理部門がリアルタイムに同じ情報を見て動ける状態になります。それが Maximo Manage の本質的な価値です。

オンボーディングのスコープ

このガイドでは、以下を オンボーディング完了 の目安としています。

  • Maximo Manage にログインし、画面の構成を理解できている
  • 利用する組織・サイトを理解している（管理者）
  • セキュリティグループとユーザー権限の設定が完了している（管理者）
  • 資産管理業務の基本的な流れを理解している
  • 作業管理業務の基本的な流れを理解している
  • 在庫管理業務の基本的な流れを理解している
  • レポートで運用状況を確認できる

Maximo Mobile やアドオン・上位 Function（Health / Predict）との連携は、Manage の運用が安定した後のネクストステップとして検討してください。

STEP 1｜Maximo Manage へのアクセス確認・画面の見方

MAS Hub から Maximo Manage にアクセスし、基本的な画面の構成を把握します。

💡 ここでの感動ポイント
Start Center を開いた瞬間、自分の業務に関係する作業指示・アラート・KPI が一画面に集まっているのに気づきます。「今日やること」がここだけでわかる、それがスタートセンターの価値です。

このステップのゴール

  • Maximo Manage にログインできる
  • ナビゲーションメニューの構成を理解している
  • スタートセンターの見方がわかる

→ ナビゲーションと画面構成
→ スタートセンターの設定

STEP 2｜組織・サイトの理解と確認（管理者）

Maximo Manage の運用単位となる「組織（Organization）」と「サイト（Site）」の概念を理解し、自社環境の設定を確認します。 SaaS 環境や既存バージョンからの移行環境では、導入時点で設定済みであることが多いです。

💡 なぜ重要か
組織・サイトは Manage のすべての業務データの「住所」です。資産・作業・在庫はすべてサイトに紐づいて管理されます。ここを理解しておくと、データの整理・検索・集計がぐっとわかりやすくなります。

このステップのゴール

  • 組織・サイトの概念と役割を理解している
  • 自社で利用する組織・サイトを把握している

→ 組織とサイトの設定

STEP 3｜ユーザー管理とセキュリティグループの設定（管理者）

Maximo Manage のユーザー管理の仕組みを理解し、セキュリティグループを使ってアクセス権限を設定します。 MAS Hub でのユーザー追加（MAS共通ガイド）とは別に、Manage 内での権限設定が必要です。

💡 なぜ重要か
権限設定が適切に完了すると、「現場担当者は作業指示だけ見られる」「管理者は全機能を操作できる」という役割分担が自動で機能します。人に頼らなくてもアクセスを制御できる状態です。

このステップのゴール

  • MAS User・Manage User・Person の関係を理解している
  • Manage のセキュリティグループの考え方を理解している
  • ユーザーに適切な権限が付与されている

→ ユーザー管理とセキュリティグループの設定

STEP 4｜コア機能の基本操作

Manage の代表的な業務機能である資産管理・作業管理・在庫管理の基本操作を習得します。

実際に利用する機能はお客様の業務要件や導入範囲によって異なります。PM（予防保全）・購買・Service Request・Job Plan など、本ガイドで扱わない機能については IBM Documentation を参照してください。

💡 ここでの感動ポイント
作業指示書を発行し、現場担当者がステータスを「完了」に変えると、その瞬間に管理部門の画面にも反映されます。「紙やメールで連絡していたものがリアルタイムに同期される」——これが Manage で最初に感じる変化です。

このステップのゴール

  • 資産台帳に資産を登録・管理できる
  • 作業指示を発行・実施・クローズできる
  • 在庫の基本的な入出庫操作ができる

→ 資産管理
→ 作業管理
→ 在庫管理

STEP 5｜レポートの活用

標準レポートを使って、資産・作業の状況をレポートとして出力します。

💡 ここでの感動ポイント
「今月の作業件数は？」「未完了の作業指示は何件？」——これまで手動で集計していたものが、ボタン一つで出てきます。データが蓄積されるほどレポートの精度と価値が上がっていきます。

このステップのゴール

  • 標準レポートを実行できる
  • レポート結果を業務に活用できる

→ 標準レポートの活用

オンボーディング完了後

基本的な運用が軌道に乗ったら、以下の活用をご検討ください。

活用ステップ内容
Maximo Mobile現場作業者がモバイルで作業指示を受け取り・報告
予防保全（PM）の高度活用定期点検スケジュールの自動生成・Job Plan との連携
レポート・ダッシュボードのカスタマイズ自社の管理指標に合わせた KPI・レポートを整備
Maximo Monitor との連携IoT センサーデータによる設備状態監視
Maximo Health / Predict資産の健全性スコアリング・AI による故障予測
Integration FrameworkERP・外部システムとのデータ連携

詳細は IBM Documentation および各製品ガイドをご参照ください。
