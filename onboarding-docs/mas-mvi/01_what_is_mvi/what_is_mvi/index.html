Maximo Visual Inspection とは

Maximo Visual Inspection とは | Maximo Visual Inspection オンボーディング

AI を活用した画像・映像による外観検査・品質管理アプリケーションである MVI を理解しましょう。

MAS 共通ガイドで説明した通り、MAS は複数の Function で構成されています。その中で画像・映像を使った AI 検査を担うのが Maximo Visual Inspection（MVI） です。

Maximo Visual Inspection とは

MVI は、AI ベースの視覚検査モデルを作成・トレーニングし、資産や製品の欠陥・異常を自動検知するアプリケーションです。

従来の目視検査に比べて、以下のメリットがあります。

  • ノーコードで AI モデルを作れる — プログラミング知識不要
  • 検査の自動化・省力化 — 人の目による検査のバラつきをなくせる
  • リアルタイム検知 — カメラ映像からリアルタイムに異常を検出
  • 品質管理の高度化 — データに基づく品質トレンドの把握
MAS 共通ガイドをまだ読んでいない場合は、先に MAS とは をご確認ください。AppPoint ライセンスの考え方などが理解できます。

MVI の主な活用シーン

シーン内容
製造ラインの外観検査製品の傷・汚れ・欠けなどの不良品検出
設備の異常検知設備の外観変化・漏れ・変色などの早期発見
インフラ点検橋梁・配管・電柱などのひび割れ・劣化検出
品質管理組み立て工程での部品の有無・取り付け確認

ユーザーロール

MVI には2種類のユーザーロールがあります。

ロール内容
管理者MVI のデプロイ・アクティブ化・ユーザー管理・設定全般
プレミアムアプリケーションユーザーデータセット作成・ラベル付け・モデルトレーニング・検査の実行
MVI の利用には Premium ユーザーライセンスが必要です。AppPoint ライセンスの詳細は AppPoint ライセンスの考え方 をご参照ください。
