AIモデルを作る

モデルのデプロイと推論 | Maximo Visual Inspection オンボーディング

トレーニング済みモデルをデプロイし、推論（検査）を実行しましょう。

トレーニングが完了したモデルは、デプロイすることで実際の検査（推論）に使用できるようになります。

デプロイの手順

トレーニング完了後のモデル詳細画面から、そのままデプロイに進むことができます。

  1. モデル詳細画面右上の 「モデルのデプロイ」 をクリック

「モデルのデプロイ」 ダイアログが表示されます。

  1. 「デプロイ済みモデル名」 を確認する（モデル名が自動入力されています）
  2. 「デプロイ」 をクリック

「デプロイ」をクリックすると 「MVI デプロイ済みモデル」 一覧ページに移動し、画面右側に「デプロイ進行中」の通知が表示されます。ステータスが 「準備完了」（緑チェック）に変わればデプロイ完了です。

環境によってはすぐに「準備完了」になる場合もあります。ステータスが「開始中」のまましばらく待っていれば自動的に更新されます。

ダイアログのオプションについて

デフォルトのまま「デプロイ」で問題ありません。必要に応じて以下のオプションを使用できます。

オプション内容
トレーニング済みのモデルのデプロイおよびエクスポートデプロイと同時にモデルファイルをエクスポートしたい場合にチェック
拡張デプロイメント（トグル）On にすると「推論結果の保存先データ・セット」を指定できる。推論結果を自動保存して後から確認したい場合に使用

モデルのテスト

デプロイ済みモデルの詳細ページには 「モデルのテスト」 セクションがあり、本番環境で使用する前に画像を使って動作確認できます。

テストの手順

  1. 「デプロイ済みモデル」一覧で、ステータスが 「準備完了」 になったモデルの名前をクリックして開く

  1. 「モデルのテスト」 セクションの 「ファイルのアップロード」 エリアに、テスト用の画像をドラッグ＆ドロップ（またはクリックしてファイルを選択）
    • 対応形式：.jpg / .png / .dcm（DICOM は自動的に PNG に変換されます）
    • 最大ファイルサイズ：2 GB（1 回につき 1 ファイルずつ）
  2. 必要に応じて 「信頼度しきい値」 を調整する（後述）
  3. アップロードが完了すると自動的に推論が実行され、結果が表示される
まずはラベル付けに使った画像でテストして、期待通りの分類結果が得られるか確認しましょう。

信頼度しきい値について

信頼度しきい値（デフォルト：0.1）は、結果として返す検出の最低信頼度を設定します。

設定値挙動
低い（例：0.1）信頼度が低い結果も含めてすべて表示される
高い（例：0.8）確信度の高い結果のみ表示される（誤検出が減る）

初めてテストする場合はデフォルト（0.1）のまま実行し、結果を見ながら調整するのがおすすめです。

テスト結果の見方（画像分類モデルの場合）

画像分類モデルで画像をテストすると、「結果」セクションに以下の情報が表示されます。

項目内容
ヒートマップモデルが分類の根拠にした画像の領域を色で強調表示（赤＝最も関連性が高い箇所）
カテゴリー／信頼性テーブル各カテゴリーの信頼度スコアが高い順に表示される（例：dirty: 0.884 / clean: 0.115）
信頼度しきい値スライダー結果画面でもスライダーで調整可能（0.1〜1.0）
ヒート・マップの不透明度スライダーでヒートマップの濃さを調整できる（0〜100、デフォルト：50）
ヒート・マップのダウンロードヒートマップ画像をダウンロードできる
ヒートマップは正方形に圧縮されるため、元の画像が歪んで見える場合がありますが、モデルの判断根拠は正しく表示されています。 信頼度スコアが低い場合は、対象クラスの学習データを追加して再トレーニングを検討してください。

モデルの検証

ラベル付きデータセットを使ってモデルの精度を数値で評価できます。検証の実行はデプロイ済みモデルの画面から、結果の確認は MVI Models の画面から行います。

検証の実行

  1. デプロイ済みモデルの詳細ページ右上の 「検証」 をクリック
  2. 「検証」ダイアログが表示される

  1. 「データ・セットの選択」 ドロップダウンから、検証に使用するデータセットを選択
  2. 「検証」 をクリック → 画面右上に「モデル検証を開始しました」「モデル検証が完了しました」の通知が表示される
検証に使うデータセットは、モデルが学習していない未学習の画像を使うと、本来の汎化性能を測れます。 まず機能を試すだけなら、トレーニングに使ったデータセットをそのまま選択しても問題ありません。

検証結果の確認

検証結果は、デプロイ済みモデルの画面ではなく 「MVI Models」 から確認します。

  1. 左サイドバーの 「MVI Models」 をクリック

  1. 対象のモデルを選択してモデル詳細画面を開く
  2. 画面下部の 「検証」 テーブルに、実行済みの検証結果（データ・セット名／作成日／適合率／再現率）が一覧表示される

  1. データ・セット名のリンク をクリックすると「モデルの検証」結果ページが開く

検証結果の見方

指標内容
適合率（Precision）「陽性」と予測したうち、実際に陽性だった割合
再現率（Recall）実際の陽性のうち、正しく陽性と予測できた割合
正確度（Accuracy）全体のうち正しく分類できた割合
F1スコア適合率と再現率の調和平均（バランスの指標）

画面下部の「画像の詳細」では、各画像に対する予測結果（アキュタル／予測値／信頼性）を1枚ずつ確認できます。

モデルの検証は、ある程度使い込んだ後に精度を数値で確認したいときに使います。まずは「モデルのテスト」で実際の画像を使った動作確認から始めましょう。

デプロイ済みモデルの管理

操作手順
デプロイ解除「デプロイ済みモデル」 > モデルを選択 > 「デプロイ解除」
再デプロイ同じモデルを再度「モデルのデプロイ」から実行
デプロイ解除してもトレーニング済みモデル自体は削除されません。「モデル」ページに残り、いつでも再デプロイできます。
