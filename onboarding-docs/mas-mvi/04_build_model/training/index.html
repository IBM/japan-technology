AIモデルを作る

モデルのトレーニングと評価 | Maximo Visual Inspection オンボーディング

ラベル付きデータセットをもとに AI モデルをトレーニングし、精度を評価しましょう。

ラベル付きデータセットが準備できたら、いよいよ AI モデルのトレーニングです。 MVI では、数ステップの設定だけでモデルの学習を開始できます。

このステップのゴールは「学習を完了させること」ではなく、**「精度を評価して、デプロイできる水準か判断すること」**です。

トレーニングの手順

  1. トレーニングに使うデータセットを開く
  2. 右上の 「モデルのトレーニング」 をクリック
  3. トレーニング・タイプ を選択する

トレーニング・タイプ内容向いているケース
イメージ分類画像全体を分類するモデルを作成。画像がカテゴリーのどれに該当するかを判定する良品・不良品の判定など、画像全体を分類したい場合
オブジェクト検出画像または動画内のオブジェクトを検出してタグ付け。境界ボックスで位置を示す欠陥の位置も特定したい場合
アクション検出動画内のアクションを検出してタグ付け。時間・空間の両方に配置されたアクションを対象とする動画内の特定の動作を検出したい場合
はじめての場合は 「イメージ分類」 から試してみるのがおすすめです。比較的短時間でトレーニングが完了します。
  1. モデル最適化タイプ を確認する（通常はデフォルトのままで問題ありません）
  2. 右上の 「モデルのトレーニング」 をクリックして開始
高度なトレーニング設定（基本モデルの選択・ハイパーパラメーターの調整）が必要な場合は、右上の 「拡張設定」 トグルを On にしてください。詳細はこのページ下部の「拡張設定」セクションを参照してください。
トレーニングを途中で止めたい場合は、「トレーニングの停止」 をクリックします。

トレーニング中の画面

「モデルのトレーニング」をクリックすると、モデルの詳細画面に移動し、トレーニングの進行状況が表示されます。

  • プログレスバーと残り時間でトレーニングの進捗を確認できます
  • 「トレーニング・オプション」 セクションに、設定したパラメーター値が表示されます
  • 「損失対反復」 グラフがリアルタイムで更新されます（損失値が下がるほど学習が進んでいる状態）
  • トレーニング中はページを離れて他の操作をしても問題ありません
トレーニングを停止したい場合は、赤い 「トレーニングの停止」 ボタンをクリックします。

トレーニング結果の確認・評価

トレーニングが完了すると、モデルの詳細画面に精度指標とモデル情報が表示されます。

画面上部には 「モデルのデプロイ」 と 「モデルのエクスポート」 ボタンが表示され、次のアクションに進めます。

表示される精度指標

指標内容
正確度（Accuracy）全予測のうち正解した割合。画像全体の分類精度
適合率（Precision）「このカテゴリー」と判定したもののうち、実際にそのカテゴリーだった割合
再現率（Recall）実際にそのカテゴリーだったもののうち、正しく検出できた割合
損失対反復グラフ学習の進行を示すグラフ。損失値が下がり安定していれば良好な学習ができている
イメージ分類では 正確度・適合率・再現率 が主な指標です。オブジェクト検出では mAP（Mean Average Precision） も表示されます。

また、「ダウンロード可能なモデル形式」 セクションからモデルファイル（Core ML など）をダウンロードすることもできます。

再学習が必要か判断する

状況対処
精度指標が期待水準を満たしている→ 右上の 「モデルのデプロイ」 へ進む
精度は低いが傾向が見える→ ラベルの見直し・データ追加後に再トレーニング
まったく検出できていない→ ラベル付け方法・トレーニングタイプを見直す
精度が低い場合は、ラベル付きデータを追加して再トレーニングしましょう。一般的に、1クラスあたり最低でも 50〜100 枚程度の画像があると精度が安定しやすくなります。

拡張設定（上級者向け）

画面右上の 「拡張設定」 トグルを On にすると、以下の詳細設定が表示されます。

基本モデル

既存モデルを起点にトレーニングする「転移学習」の設定です。基本モデルを指定することで、学習の収束が速くなり、必要な反復回数を減らすことができます。

  • イメージ分類 / オブジェクト検出 で使用可能
  • MVI に組み込み済みのモデル（一般・花・ランドスケープ・中華料理・アクション・シーン・車両）から選択できるほか、以前にトレーニング・インポートしたモデルも使用可能
  • イメージ分類（GoogLeNet）でトレーニングする場合は、基本モデルの選択が必要（未選択時は「一般」が自動使用される）
「システム・デフォルト（GoogLeNet）」 は非推奨マークが付いています。特別な理由がなければ、基本モデルの一覧から適切なものを選択してください。

モデルのハイパーパラメーター

トレーニングを細かく制御するための上級者向け設定です。各パラメーターの有効なトレーニング・タイプも記載しています。

パラメーターデフォルト値設定範囲説明対象タイプ
最大反復1500100-1000000データがアルゴリズムを通過する最大回数。多いほど精度が上がる傾向があるが、ある時点で頭打ちになるイメージ分類 / オブジェクト検出
テスト反復1001-1000完了前にデータがアルゴリズムを通過する回数イメージ分類
テスト間隔201-1000何回の反復ごとにテストを行うか。各テストがグラフ上の1点になるイメージ分類
トレーニング区分80%50-100データセットのうちトレーニングに使う割合（残りは検証用）イメージ分類 / オブジェクト検出
テスト区分20%0-50データセットのうちテストに使う割合イメージ分類 / オブジェクト検出
学習速度0.001(0-0.01]ネットワークの重みをどの程度調整するかを決定。大きすぎると学習が不安定になるため上級者以外は変更不要イメージ分類 / オブジェクト検出
重み減衰0.0005(0-0.5]過学習を防ぐ正則化パラメーターイメージ分類 / オブジェクト検出
エポック——データセット全体がアルゴリズムを通過する回数アクション検出のみ
運動量——エラー曲線の最小値を探す際のステップサイズを増やし、局所最小に留まるのを防ぐオブジェクト検出のみ
