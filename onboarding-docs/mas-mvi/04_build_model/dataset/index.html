AIモデルを作る

データセットの作成 | Maximo Visual Inspection オンボーディング

AI モデルのトレーニングに使う画像・動画のデータセットを作成しましょう。

データセット は、AI モデルをトレーニングするための画像・動画の集まりです。 良品・不良品の画像をデータセットに登録することで、AI が「何が欠陥か」を学習できるようになります。

データセットの作成方法は以下の 2通り があります。

方法1：空のデータセットを新規作成する

  1. MVI のトップ画面で 「データ・セットの作成」 をクリック、または青い 「開始」 ボタンをクリック

  1. 「データ・セットの作成」 ダイアログが表示されます。名前 を入力し、タイプ を選択して 「作成」 をクリック

データセットの種類

タイプ内容
トレーニング画像・動画内のオブジェクトにラベルを付けてモデルをトレーニングするためのデータセット。YOLO v3 や Faster R-CNN などのモデルに対応。
ビジュアル・プロンプトオブジェクト検出のユースケースに適したモデルを構成。いくつかの画像にラベルを付けてから精度をテスト。トレーニング不要。
検査検査結果を保存して確認するためのデータセット。結果はモデルのパフォーマンス向上に活用可能。
  1. データセット一覧に作成したデータセットが追加されます
  2. 作成したデータセットをクリックして開くと、ファイルのアップロード 画面が表示されます
  3. 「ここにファイルをドラッグ・アンド・ドロップするか、クリックしてアップロード」 から画像・動画を追加します

対応ファイル形式

種別対応形式
画像.jpg、.png、.dcm など
動画.mp4、.webm、.ogg など
最大ファイルサイズは 2 GB です。

方法2：.zip ファイルからインポートする

以前に MVI からエクスポートした .zip ファイルがある場合は、データセット一覧画面左側の 「ファイルのアップロード」 エリアからインポートできます。

  1. MVI データセット一覧画面左側の 「ここにファイルをドラッグ・アンド・ドロップするか、クリックしてアップロードします」 から .zip ファイルをアップロード
  2. データセット一覧にインポートされたデータセットが追加されます
  3. クリックして開くと、エクスポート時のファイルが既に追加された状態で表示されます

良いデータセットを作るためのポイント

AI モデルの精度は、データセットの質と量に大きく左右されます。

量について

  • 検査対象1クラスにつき、最低 50〜100枚以上 の画像を用意することを推奨します
  • 枚数が多いほどモデルの精度が上がります

質について

  • 良品・不良品のバランスが取れた画像を用意する
  • 実際の検査環境（照明・角度・距離）に近い条件で撮影した画像を使う
  • 様々な角度・条件のバリエーションを含める
画像が少なすぎると、モデルの精度が低くなります。まずは手持ちの画像でトレーニングし、精度が不十分な場合はデータを追加して再トレーニングするアプローチがおすすめです。
