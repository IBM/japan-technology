AIモデルを作る

オブジェクトのラベル付け | Maximo Visual Inspection オンボーディング

データセット内の画像・動画に検査対象のラベルを付けて、AI の教師データを作りましょう。

ラベル付け（アノテーション） は、画像・動画内の検査対象に「これが欠陥だ」「これが正常だ」という情報を付与する作業です。
このラベルが AI モデルの学習データ（教師データ）になります。

ラベル付けを行うには、事前にデータセットに画像・動画がアップロードされている必要があります。

まず確認：どのモデルを作りたいですか？

ラベル付けの方法は、作りたいモデルのタイプによって異なります。作業を始める前に確認しておきましょう。

ラベル付けの方法何を学習させるか対応するモデルタイプ
オブジェクトのラベル付け（バウンディングボックス）画像内の物体の位置と種類物体検出（Object Detection）
カテゴリー分類画像全体の分類（例：clean / dirty）画像分類（Image Classification）
モデルタイプの詳細は IBM 公式ドキュメント「Model types」 を参照してください。

物体検出モデル用：オブジェクトのラベル付け

画像にチェックを入れて青いメニューバーを表示させるのが基本操作です。

「ファイルの選択 ∨」→「すべて」 を使うと全画像を一括選択できます。複数選択した状態でラベル付け画面に入ると、選択した全画像をまとめてラベル付けできます。1枚ずつ確認しながら進めたい場合は1枚ずつ選択してください。

ラベル（オブジェクト・タイプ）の作成

ラベル付けを始める前に、データセット内で使う「ラベル（オブジェクト・タイプ）」を先に作成します。

  1. ファイル一覧から任意の画像を1枚選択してチェックを入れる
  2. 青いメニューバーの 「ラベル ∨」 をクリックして 「オブジェクト」 を選択する

  1. 「オブジェクトのラベル付け」 画面に遷移したら、右上の 「オブジェクト・タイプの追加 ＋」 をクリック

  1. ラベル名（オブジェクト・タイプ名）を入力して 「追加」 をクリック。複数追加する場合は繰り返す
  2. すべて追加したら 「保存」 をクリック

ここで作成したラベルはデータセット全体で共有されます。一度作成しておけば、他の画像のラベル付け時にも同じラベルが使えます。
ラベル名は英語の短い単語が管理しやすいです（例：clean（正常）、dirty（異常））。日本語も使えますが、システム連携を考慮すると英語を推奨します。
ラベルを編集・削除するには、ラベル付け画面右パネルの該当オブジェクト・タイプの設定アイコンをクリックします。ラベルを削除すると、そのラベルを使用しているすべてのアノテーションも削除されます。

画像へのラベル付け（バウンディングボックスの描画）

ラベルを作成したら、そのまま同じ画面でオブジェクトの位置を描画します。

  1. 右パネルの 「オブジェクト」 リストからラベルを選択
  2. 画像右側の黒いツールバーから描画ツールを選択してオブジェクトの周囲を囲む
ツール用途
ボックス描画（1つ目のアイコン）四角形で囲む（一般的な用途）
多角形描画（2つ目のアイコン）多角形で囲む（複雑な形状に）

  1. 右パネルのオブジェクトリストにアノテーションが追加されたことを確認（例：clean (1) の下に A1 clean が表示される）
  2. 複数画像を選択していた場合は、画面左側のサムネイル一覧から次の画像をクリックして切り替え、繰り返す

画像分類モデル用：カテゴリー名で画像を分類

オブジェクトのラベル付けが「画像の中のどこに何があるか」を学習させるのに対し、カテゴリー分類は「画像全体が何か」を学習させるものです。

画像全体を良品・不良品などのカテゴリーに分類する手順は以下のとおりです。

  1. 対象のデータセットのファイル一覧から分類する画像にチェックを入れる
  2. 青いメニューバーの 「カテゴリーの割り当て」 をクリック
  3. 「カテゴリーの作成または選択」 欄から該当カテゴリーを選択して 「割り当て」 をクリック

カテゴリーがまだ作成されていない場合は、テキスト欄に直接カテゴリー名を入力することで新規作成できます。
カテゴリーの割り当て自体は制約なく行えますが、画像分類モデルのトレーニングを行うには、データセットに 最低2つのカテゴリー があり、各カテゴリーに 最低5枚の画像 が必要です。また、トレーニング用データセットに動画は含めないでください。

動画内のオブジェクトにラベル付け

  1. 対象のデータセットを開き、ラベル付けする動画を選択
  2. 「オブジェクトのラベル付け」 をクリック
  3. フレームをキャプチャする
方法操作
手動キャプチャ動画を再生 → 一時停止アイコンでフレームを止めて 「フレームのキャプチャ」 をクリック
自動キャプチャ「自動キャプチャ」 をクリックし、フレーム間の秒数を入力
  1. カルーセルからフレームを選択し、「オブジェクト」 パネルで対象オブジェクト名を選択
  2. 描画ツールでオブジェクトの周囲にボックスまたはポリゴンを描く

動画内のアクションにラベル付け

  1. 対象のデータセットを開き、ラベル付けする動画を選択
  2. 「アクションのラベル付け」 をクリック
  3. 動画コントロールバーを使ってアクション開始フレームに移動
  4. 「開始時間」 フィールドで 「追加」 アイコンをクリック
  5. アクション終了フレームに移動して 「終了時間」 フィールドで 「追加」 アイコンをクリック
  6. 「アクション名」 リストから該当するアクションを選択して 「アクションの作成」 をクリック
動画コントロールバーの +1 / -1 を使うと、フレームを1秒単位で前後に移動できます。

自動ラベル付け（効率化）

すでにデプロイ済みのモデルがある場合は、自動ラベル付け を使って効率化できます。

  1. データセットを開いて 「自動ラベル」 をクリック
  2. 使用するデプロイ済みモデルを選択
  3. 自動でラベルが付与される
  4. 誤ったラベルを手動で修正して精度を上げる
最初は手動でラベル付けしてモデルを作り、そのモデルで次のデータセットを自動ラベル付けする、という繰り返しでどんどん効率化できます。
