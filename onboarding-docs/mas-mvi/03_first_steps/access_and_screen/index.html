はじめの確認

MVI へのアクセスと画面の見方 | Maximo Visual Inspection オンボーディング

MAS Hub から MVI にアクセスし、基本的な画面構成を理解しましょう。

MAS Hub から Maximo Visual Inspection（MVI）にアクセスし、画面の構成を把握しましょう。

MVI へのアクセス

MAS Hub のトップ画面に表示されている 「Maximo Visual Inspection」 のタイルをクリックすると、MVI の画面に遷移します。

MVI のタイルが表示されていない場合は、管理者に MVI へのアクセス権（Premium ユーザー）が付与されているか確認してもらってください。

推奨ブラウザ

MVI を使用するには、以下のブラウザを使用してください。

ブラウザバージョン
Google Chrome60 以降
Firefox Quantum59.0 以降
Internet Explorer および Edge レガシーは非対応です。必ず上記のブラウザをご使用ください。

MVI ウェルカム画面

MVI に初めてアクセスすると、以下の4ステップが表示されたウェルカム画面が開きます。

ステップ内容
データ・セットの作成検査用の画像・動画を管理するデータセットを作成する
データの作成データセットに画像・動画をアップロードし、ラベル付けを行う
モデルのトレーニングデータセットをもとに AI モデルを学習させる
モデルのデプロイトレーニング済みモデルを検査に使用できる状態にする

「開始」 ボタンをクリックすると MVI の操作を始められます。

画面の基本構成（左サイドナビ）

MVI の画面に遷移すると、左サイドナビの 「Visual Inspection」 セクションに以下のメニューが表示されます。

メニュー内容
MVI Datasets検査用の画像・動画を管理するエリア
MVI Modelsトレーニングした AI モデルの一覧・管理
MVI Deployed Models検査に使用できる状態のモデル一覧
MVI Projects複数のデータセット・モデルをまとめて管理するプロジェクト
MVI Services検査サービスの設定・管理
MVI Edge Managementエッジデバイスへのモデル配備・管理
表示されるメニュー項目はユーザーの権限によって異なります。MVI Projects / MVI Services / MVI Edge Management は管理者権限を持つユーザーにのみ表示されます。

この流れに沿って、次のステップから順番に進めていきましょう。

画面右上の 「？」（ヘルプ） から、各機能の公式ドキュメントにアクセスできます。
