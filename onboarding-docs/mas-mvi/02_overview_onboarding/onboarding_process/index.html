オンボーディングの流れ

オンボーディングの流れ | Maximo Visual Inspection オンボーディング

Maximo Visual Inspection を活用できるようになるまでのステップを確認しましょう。

はじめに

本ガイドは、Maximo Visual Inspection（MVI）を初めて利用する方が、AI 検査モデルを作成・デプロイして実際に検査を実行できるようになるまでのステップをご案内します。

MAS Hub へのログインやユーザー追加は MAS 共通オンボーディングガイド で完了している前提で進めます。

このガイドを最後まで進めると、自分で集めた画像データから AI モデルを作り、実際に不良品や異常箇所を自動検出できる状態になります。専門的な機械学習の知識がなくても、MVI の画面上だけで完結します。

オンボーディングのスコープ

このガイドでは、以下を オンボーディング完了 の目安としています。

  • MVI にアクセスし、画面の構成を理解できている
  • データセットに画像・動画をアップロードできる
  • 検査対象にラベル付けができる
  • AI モデルのトレーニングを実行し、精度を確認できる
  • トレーニング済みモデルをデプロイし、推論を実行できる

カメラ・エッジデバイスとの連携や REST API の活用は、基本操作が安定した後のネクストステップとして検討してください。

STEP 1｜MVI へのアクセス確認・画面の見方

MAS Hub から MVI にアクセスし、基本的な画面構成を把握します。

💡 なぜここから始めるか
MVI の画面は「データセット → モデル → デプロイ済みモデル」という AI 開発の流れそのままに設計されています。最初に全体像を把握しておくと、以降のステップが迷わず進められます。

このステップのゴール

  • MVI にログインできる
  • 画面の構成（データセット・モデル・デプロイ済みモデル）を理解している

→ MVI へのアクセスと画面の見方

STEP 2｜データセットの作成

AI モデルの精度は、学習に利用するデータセットの品質に大きく依存します。 まずは十分な数の画像・動画を準備し、データセットを作成しましょう。

💡 なぜ重要か
AI は「見せた画像」から学びます。良品・不良品の両方を多く・バリエーション豊かに揃えるほど、モデルの精度が上がります。ここへの投資がそのまま検査精度に直結します。

このステップのゴール

  • データセットを作成し、画像・動画をアップロードできる

→ データセットの作成

STEP 3｜ラベル付け

データセット内の画像・動画に、検査対象のオブジェクトやカテゴリをラベル付けします。
このラベルが AI モデルの「教師データ」になります。

💡 ここでの感動ポイント
バウンディングボックスで「ここが傷」「ここが正常」と囲んでいく作業は、AI に教えているという実感が得られる瞬間です。自分のラベルが、後のモデルの判断基準になります。

このステップのゴール

  • 画像・動画内の検査対象にラベルを付けられる

→ オブジェクトのラベル付け

STEP 4｜モデルのトレーニングと評価

ラベル付きデータセットをもとに AI モデルを学習させ、精度を評価します。 学習の完了だけがゴールではなく、評価して改善を判断することがこのステップの核心です。

💡 ここでの感動ポイント
トレーニングが完了し、Accuracy（精度）の数値が出た瞬間——「自分のデータが AI を動かした」と実感できます。精度が低ければデータを追加して再挑戦、高ければ次のステップへ。このサイクルが MVI の面白さです。

このステップのゴール

  • モデルのトレーニングを実行できる
  • Accuracy や評価結果を確認できる
  • 再学習が必要か判断できる

→ モデルのトレーニング

STEP 5｜モデルのデプロイと推論

トレーニング済みモデルをデプロイし、実際に検査（推論）を実行します。

💡 ここでの感動ポイント
画像をアップロードした瞬間に、AI が検査対象の位置を自動で検出して枠を表示します。「自分で作った AI が、実際に動いている」——これがオンボーディングのゴールであり、MVI を使い始めた人が最初に感じる感動の瞬間です。

このステップのゴール

  • モデルをデプロイできる
  • 推論（Inference）を実行できる
  • 検査結果を確認できる

→ モデルのデプロイ

オンボーディング完了後

基本的なモデル作成ができるようになったら、以下の活用をご検討ください。

活用領域概要
データセットの継続的な改善精度向上のため、データ収集・追加を繰り返す
モデルの再学習と精度向上不正解例の分析をもとに再トレーニングを実施
カメラとのリアルタイム連携IP カメラや USB カメラと接続してライブ検査を実現
エッジデバイスへのデプロイネットワーク非依存の環境で検査を稼働させる
REST API を利用したシステム連携外部システムから推論 API を呼び出して自動化
Maximo Manage との連携検査結果を資産管理・作業指示書に反映
Visual Inspection Assistant の活用生成 AI アシスタントによる検査プロセスの強化
