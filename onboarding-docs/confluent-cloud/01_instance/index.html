Confluent Cloud

1. 契約とアカウント

契約経路の確認から、サインアップ、支払い方法の登録、ユーザーの追加、アクセス権限の設定までを行います。
最終更新: 2026/8/13

この領域では、IBM Confluent Cloud を利用開始するための契約面の確認と、Organization（組織）のセットアップを行います。

IBM Confluent Cloud のリソースは、次の階層で構成されています。この階層がアクセス制御と課金の単位になるため、最初に理解しておくことをおすすめします。

Organization（組織：契約・課金の単位）
 └─ Environment（環境：dev / staging / prod などの論理的な分離単位）
     ├─ Kafka Cluster（クラスター）
     │   ├─ Topic
     │   └─ Connector / ksqlDB Cluster
     ├─ Schema Registry（環境単位）
     └─ Flink Compute Pool
