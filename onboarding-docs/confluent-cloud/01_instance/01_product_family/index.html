製品ファミリーと本ガイドの対象

IBM Confluent の製品ファミリーを整理し、本ガイドが対象とする IBM Confluent Cloud の位置づけを説明します。
最終更新: 2026/8/12

IBM は Confluent 関連製品を5製品として提供しています。いずれも 2026年3月17日に一般提供が開始されました。本ガイドが対象とするのは IBM Confluent Cloud のみです。

製品名PID形態
IBM Confluent Cloud（本ガイドの対象）5900-C3Eフルマネージド SaaS
IBM Confluent Platform5900-C3Dセルフマネージド（8.2.x 系）
IBM Confluent Platform for Z and LinuxONE—セルフマネージド（IBM Z / LinuxONE 向け）
IBM Confluent Private Cloud—プライベート環境にクラウドネイティブな自動化・運用を提供
IBM WarpStream—BYOC 型。データがお客様の VPC から出ない構成

サポートライフサイクルの違い

IBM Confluent Cloud は XaaS 区分の Cloud Service です。技術サポートは Cloud Service に含まれており、契約終了時またはサービス撤回時にサポートも終了します。Extended Support および Sustained Support は提供されません。

一方、セルフマネージドの IBM Confluent Platform は Support Cycle-Other（SC-O）が適用され、基本サポート期間は2年です。Extended Support は提供されず、サポートの移行は12か月前に通知されます。

参考：IBM Confluent Cloud 製品ライフサイクル（英語）

【重要】旧製品との混同にご注意ください

Confluent Platform for IBM Cloud Pak for Integration（PID 5900-AEU）は、Confluent 買収以前から提供されていた IBM Cloud Pak for Integration 向けの製品です。7.0.x は 2024年8月9日にマーケットから撤退し、2025年4月30日にサポートを終了しています。

現行の IBM Confluent 製品ファミリーとは別の製品ですので、既存環境からの移行を検討される場合は、対象製品をご確認ください。

IBM 製品との連携

IBM Confluent Cloud は、IBM の既存のイベント基盤製品と補完関係にあります。IBM MQ および IBM webMethods Hybrid Integration がトランザクショナルメッセージングと統合・オーケストレーションを担い、Confluent が大規模なイベントストリーミングを担う位置づけです。

このほか、Tableflow を通じた IBM watsonx.data との連携、IBM Data Gate for Confluent による IBM Z データの連携が公式に発表されています。
