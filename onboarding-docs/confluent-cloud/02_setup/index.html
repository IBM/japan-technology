2. 初期設定

環境の作成からクラスタータイプ・リージョンの選択、ネットワークとセキュリティ、コストのガードレール設定までを行います。
最終更新: 2026/8/13

この領域では、実際にデータを流すための環境とクラスターを構築します。

【重要】この領域には、あとから変更できない設定が含まれます

初期設定のうち、次の項目は原則としてあとから変更できません。作業を始める前に、要件を確定させることをおすすめします。

項目制約
クラスタータイプBasic から Standard へのアップグレードのみ可能です。それ以外の変更（ダウングレードを含む）はできません
Stream Governance パッケージEssentials から Advanced へのアップグレードのみ可能です。Advanced から戻すには環境の削除が必要です
ネットワーク構成プライベートネットワークは Enterprise / Dedicated クラスターが前提のため、クラスタータイプの選択と連動します
