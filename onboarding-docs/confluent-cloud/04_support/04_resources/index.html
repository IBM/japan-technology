【重要】日本語版ドキュメントは内容が古くなっています

Confluent のドキュメントには日本語版（docs.confluent.io/ja-jp/）が用意されていますが、日本語版のページには「このページの日本語コンテンツは古くなっている可能性があります」という注意書きが表示され、英語版へのリンクが併記されます。

実際に日本語版の内容は英語版から大きく遅れており、本ガイドの記載と食い違う箇所があります。たとえば「ネットワークの概要」の日本語版では、クラスタータイプがベーシック / スタンダード / 専用の3種類として説明され、プライベートネットワークの対象は専用クラスターのみとされています。現行の英語版では、クラスタータイプは5種類で、Enterprise クラスターは常にプライベートネットワーク構成です。

そのため本ガイドでは、Confluent ドキュメントへのリンクはすべて英語版とし、リンクラベルに （英語） を付記しています。 日本語版を参照される場合は英語版と併読し、記載が食い違う場合は英語版を正としてください。

AI ツールからの接続

Confluent はオープンソースの MCP（Model Context Protocol）サーバーを公式にサポートしています。MCP クライアントから自然言語で、Kafka、Apache Flink、Tableflow を含む Confluent Cloud のリアルタイムデータへ安全にアクセスし、管理できます。

マネージド MCP サーバーおよび Agent Skills についてもドキュメントが提供されています。
