サポート窓口と問い合わせ方法

技術サポートの窓口、提供言語、対応時間、エスカレーション手順を説明します。
最終更新: 2026/8/12

【重要】技術サポートの窓口は Confluent Support Portal です

IBM 経由で IBM Confluent Cloud を契約された場合も、技術サポートの問い合わせ窓口は IBM Support ではなく Confluent Support Portal です。

項目内容
サポートポータルhttps://support.confluent.io
アカウントの作成Confluent Cloud Console からサポートポータルにアクセスして作成します
サポートユーザーの管理Confluent 側のセルフサービス手順に従って管理します
機能要望（Enhancement Request）IBM Ideas Portal（https://ideas.ibm.com/）へ登録します

技術的な問い合わせは Confluent Support Portal、機能要望は IBM Ideas Portal、という使い分けになります。

Cloud Console からは、ヘルプアイコン → Support Plans で開くページの上部にある Support Portal ボタンからサポートポータルへ遷移できます。

サポートポータルのトップページでは、質問の検索、ナレッジベースのカテゴリー別参照（Confluent Cloud / Confluent Platform など）、Submit a request からの起票、My Support Requests での自分のケースの確認ができます。ページ上部には Confluent Cloud のサービス稼働状況（例：All Systems Operational）も常時表示されるため、障害が疑われる際の確認にも使えます。なお、ポータルのロゴは「CONFLUENT — an IBM Company」表記です。

【重要】サポートの提供言語は US English のみです

IBM Confluent の製品サポート情報では、対応言語（Supported Language）が US English と明記されています。日本語でのサポートは提供されていません。

日本語での支援が必要な場合は、次のような体制を別途ご検討ください。

  • IBM の担当営業またはテクニカルセールスへの相談
  • 日本語サポートを提供するパートナー経由での支援体制の確保

導入の検討段階で、社内の運用体制が英語での問い合わせに対応できるかをご確認ください。

参考：Product Support Details for IBM Confluent（英語）

対応時間

IBM の標準サポート時間は、お客様の国およびタイムゾーンの現地営業時間に従います。

項目内容
営業時間アジアおよび欧州の一部では 9:00〜18:00 が例示されています
対象曜日月曜日から金曜日（国民の祝日および法定休日を除く）
オフシフト時間24×7 対応が含まれるオファリングでは、通常営業時間外がオフシフト時間として扱われます

営業時間外に起票され、24×7 対応の対象とならないケースについては、翌営業日の応答となります。

Step 1: 起票前に情報を準備する

起票時に必要となる情報は、Confluent のサポート記事「Essential Data - What to include when opening a Support Case」にまとめられています。事前に必要な情報を揃えておくことで、初回応答から解決までの時間を短縮できます。

【参考】コネクターの障害は起票前に一次切り分けができます

フルマネージドコネクターの障害については、Confluent Cloud Console 上で障害内容の要約と修正手順の提案が得られます。起票前にご確認ください。詳細は コネクターで既存システムと接続する をご確認ください。

Step 2: エスカレーションする

対応状況にご懸念がある場合は、Confluent のエスカレーション手順に従ってケースに注意を促すことができます。手順はサポートポータルのヘルプ記事に記載されています。

サービス稼働状況の確認

障害が疑われる場合は、まず Confluent のサービスステータスページで、サービス全体の稼働状況と障害情報をご確認ください。
