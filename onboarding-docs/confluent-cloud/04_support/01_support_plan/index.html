4. サポートと運用

サポートプランを選択する | IBM Confluent Cloud オンボーディング

Confluent Cloud の有償サポートプラン3種類の違いと、選択時の注意点を説明します。

Step 1: プランを比較する

IBM Confluent Cloud には3段階の有償サポートプランがあります。

プラン位置づけ
Free新規 Organization の既定プランです。課金とサービス稼働に関する問い合わせ、および Knowledge Base の利用のみが対象で、技術的な問い合わせはできません
Developer非本番用途向けです。Confluent がフルマネージドで提供するコンポーネントのみが対象です。対応は月〜金の営業時間で、初回応答は8営業時間以内です
Business本番環境向けです。24×7 対応で、セルフマネージドコンポーネントもサポート対象に含まれます。重大な業務影響（P1）の初回応答は60分以内です
Premier本番環境向けです。Confluent Cloud のコミット契約が前提となります。24×7 対応に加え、ビデオチャット、CSTA による支援が含まれ、P1 の初回応答は30分以内です

【重要】既定の Free プランでは技術サポートを受けられません

新規に作成した Organization のサポートプランは Free です。技術的な問い合わせを行うには、Developer 以上の有償プランへの加入が必要です。本番稼働の開始前に、必ずプランの選択を済ませてください。

なお、Developer / Business の料金は、月額の固定額と月間利用額に応じた比率のいずれか大きい方が適用される体系です。具体的な金額と料率は Support Plans 画面でご確認ください。

Developer プランの対象範囲にご注意ください

Developer プランは、Confluent がフルマネージドで提供するコンポーネントのみが対象です。次の「セルフマネージドコンポーネント」は対象外となります。

  • フルマネージドの一覧に含まれないコネクター、および Confluent Cloud 外で稼働するコネクター
  • スタンドアロンの ksqlDB
  • セルフマネージドの Schema Registry
  • セルフマネージドの Kafka Streams
  • REST Proxy
  • Control Center
  • Broker、KRaft Controller

本番環境では Business 以上のプランをご検討ください。

Premier プランの制約

Premier プランへの申し込みは Confluent Cloud のコミット契約が前提です。また、既存のコミット期間中に Premier へアップグレードすることはできません。

Step 2: プランを確認・変更する

  1. Confluent Cloud Console 右上のヘルプアイコンを選択します
  2. Support Plans を選択します
  3. 現在のプランが表示されます

プランの変更はこの画面から行います。Premier のみ Contact us からの申し込みとなります。

【重要】Confluent Advanced Support は Confluent Cloud の対象外です

IBM Support には「Confluent Advanced Support」という上位サポートの説明ページがありますが、その対象製品は IBM Confluent Platform と IBM Confluent Private Cloud のみです。IBM Confluent Cloud は対象に含まれません。

Confluent Advanced Support の内容は、Severity 1 の初期応答30分（Severity 2〜4 は1営業時間）、同一 Severity 内での優先処理、合意した場合の Severity 2 の 24×7 対応、一定以上の年間支出で割り当てられる CSTA（Customer Success Technical Architect）、およびサポート期間を標準2年から3年へ延長する Extended Lifecycle です。

セルフマネージド製品向けの内容ですので、Confluent Cloud のお客様にご説明する際は混同しないようご注意ください。
