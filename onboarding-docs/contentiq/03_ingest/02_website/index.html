コンテンツの取り込み

Web サイトからの取り込み

公開・社内 Web サイトをクロールして取り込む
最終更新: 2026/9/10

概要

Web サイト上のドキュメント（オンラインの規約、ガイドライン、FAQ 等）をクローラーで取り込みます。サイト全体のクロールと、URL を個別指定する手動モードがあります。

手順

Website Connect は 4 ステップのウィザードで進みます。

  1. 左サイドバーの Connections → Website Connect を開きます。
  2. Step 1: Enter Website URL — 取り込みモードを選び、URL を入力して Continue をクリックします。
    • Automatic — 指定 URL を起点にサイト全体を再帰的にクロールし、公開ページをすべて取り込みます
    • Manual — 取り込むページの URL を個別に指定します（v1.2.1 以降）。URL を入力して + で追加していくか、Import CSV で URL 一覧を一括読み込みします。追加済みの件数は「Valid: n URL(s) ready.」と表示されます
    • URL 入力後、到達性の確認結果（Valid domain / reachable）が表示されます
  3. Step 2: Choose Agent Type — Use Existing Agent または Create New Agent を選び、Continue をクリックします。
  4. Step 3: Select an Existing Agent — wxO のエージェント一覧から対象を選び、Continue をクリックします。一覧は検索ボックスで絞り込めます。
  5. Step 4: Confirm Ingestion Settings — Agent Name と URL を確認し、Finish & Connect をクリックすると取り込みが始まります。
    • Notify Email Upon Completion — 完了時のメール通知（複数宛先も指定可）
    • Enable Table Extraction — ページ内の表を抽出して取り込む

取り込みの進捗は Ingest Analytics で確認します。

自動処理される内容

公式ユーザーガイドによれば、以下が自動で行われます。

  • バックオフ・リトライ付きの並列クロール
  • 重複排除とチャンキング
  • 自動バージョニングとスケジュール再取り込み

ベストプラクティス

  • サイトマップ、またはリンクをまとめたハブページを起点にすると網羅性が高まります。
  • robots.txt や認証ポリシーがクロールを許可していることを確認してください。
  • 恒久的な文書には安定した URL を使ってください。
  • JavaScript で描画されるページはパースに失敗する場合があります。静的レンダリングのパス、または PDF / HTML へのエクスポートを検討してください。
  • 特定ページのみを取り込む場合は、Step 1 で Manual を選び、URL を個別に指定します。対象ページが多い場合は Import CSV で一括指定できます。CSV は 1 列で、ヘッダー行を urls とし、2 行目以降に 1 行 1 URL を記載します。ダイアログの Download Sample CSV からテンプレートを取得できます。
"urls"
"https://example.com/page1"
"https://example.com/page2"

スケジュール再取り込み

Scheduling から、Web サイトの再取り込みを daily / weekly / monthly で設定できます。Web サイトの場合は常にフル再取り込みになります。
