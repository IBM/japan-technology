クラウド・ストレージからの取り込み

OneDrive、SharePoint、Box、IBM Cloud Object Storage などからの取り込み
最終更新: 2026/9/18

対応ソース

検証状況
本ページのうち、OneDrive の接続手順と Scheduling の設定は実機（v1.4.3）で確認済みです。SharePoint / Box / Google Drive / Azure Blob / IBM Cloud Object Storage の対応状況と手順は公式ドキュメントの記載に基づいており、実機では未検証です。Settings → Connections には Microsoft、Google Drive、Box、IBM Cloud Object Storage の接続状態が表示され、未接続のサービスは Not Connected と表示されます。接続手続きを行うと有効化され、切断（Disconnect）もこの画面から行います。

公式ドキュメントで確認できる対応ソースは以下のとおりです。

OneDrive の手順

OneDrive Connect も 4 ステップのウィザードで進みます。

  1. Connections → OneDrive Connect を開きます。
  2. Microsoft アカウントで OAuth 認証します（初回のみ。テナントの同意が必要な場合があります）。
  3. Step 1: Choose Files from OneDrive — 取り込むファイルまたはフォルダーにチェックを入れ、Next をクリックします。
    • Home タブは自分の OneDrive、Shared with me タブは共有されたアイテムを表示します
    • フォルダーは展開して中のファイルを個別に選ぶことも、フォルダーごと選ぶこともできます
    • 検索ボックスでファイル・フォルダーを絞り込めます
    • Personal Vault は UNSUPPORTED と表示され、取り込み対象にできません
  4. Step 2 以降 — Document Upload と同じ構成です（実機確認済み）。Step 2: Choose Agent Type で Use Existing Agent または Create New Agent を選び、Step 3 で既存エージェントの選択（または新規エージェントの名前入力）、Step 4: Confirm Ingestion Settings で Notify Email / Enable Table Extraction を確認し、Finish & Connect で取り込みを開始します。
  5. 進捗を Ingest Analytics で確認します。

SharePoint、Box、Google Drive も同様の流れです。

スケジュール取り込み

左サイドバーの Scheduling で、接続済みソースの定期再取り込みを設定します。画面上部に「n/m Scheduled ingests configured」と、プラン名・残りスロット数が表示されます。

項目内容
Agent取り込み先のエージェント
Include source対象ソース（Website、OneDrive、SharePoint 等）。接続済みのソースのみ選択可
Website URL To Reingestソースが Website の場合の対象 URL
Folders for auto ingestソースがクラウド・ストレージの場合の対象フォルダー（複数選択可）。同じ枝の親フォルダーと子フォルダーは同時に選択できません
Auto ingest behaviour取り込み動作。Website は Full reingest 固定。クラウド・ストレージでは以下から選択できます。
Full reingest — 既存コンテンツを削除してから全件再取り込み
Only reingest changed documents — 変更された文書のみ再取り込み
Only ingest new documents — 新規文書のみ取り込み
Ingest changed and new documents — 変更・新規の文書を取り込み（通常運用の推奨）
Auto Ingest FrequencyDaily / every_x_days / weekly / monthly
Run at (time)実行時刻（分単位で指定可）
Time zoneタイムゾーン（既定は UTC。日本時間で運用する場合は Asia/Tokyo を選択）

設定後、Save Configuration をクリックします。

注意
Full reingest では、対象ソースの既存コンテンツがすべて削除されてから再取り込みが実行されます。再取り込み中は該当ソースの回答が一時的に欠落する可能性があるため、利用の少ない時間帯に設定してください。
スケジュール数の上限はプランによります。API リファレンスでは Starter / Essentials / Standard: 5、Premium: 10 とされていますが、実機（Starter、トライアル）では 1 スロットでした。上限はプランや提供形態により異なるため、利用環境の Scheduling 画面で確認してください。
文書アップロード（Document Upload）で取り込んだファイルはスケジュール対象外です。

SharePoint 権限の扱い

SharePoint のファイル権限は取り込み時にチャンクへ書き込まれ、Entra SSO 付きで展開したエージェントの検索時 RBAC に使われます。SharePoint 側で権限を変更した場合は、該当文書を再取り込みしてください。詳細は セキュリティと RBAC を参照してください。
