コンテンツの取り込み

取り込み状況の確認（Ingest Analytics）

取り込みパイプラインの健全性を確認する
最終更新: 2026/9/18

表示される指標

左サイドバーの Ingest Analytics を開くと、取り込み実行（run）の一覧が表示されます。各実行を開くと、以下の詳細（Ingestion Analytics）を確認できます。

実行の概要

項目内容
Author / Agent / Source Type / Source Location / Run Date実行者、対象エージェント、ソース種別（Website Crawl 等）、ソースの場所、実行日時
Total Pages Scraped取り込んだページ・文書数と成功率
Processing Time処理時間
Embedding Coverageチャンクのうち埋め込みに成功した割合
Duplicate Content重複コンテンツの割合
Average Chunk Length平均チャンク長（トークン数）
Chunk Overlap Ratioチャンクのオーバーラップ比

詳細パネル

パネル内容
Structured Data Overview構造化データ（CSV / Excel 等）の処理結果。処理ファイル数、作成テーブル数、行数、列数。PDF 内の表は Enable Table Extraction を有効にしてもここには計上されません（実機確認済み）
Milvus Vector Storeベクトル・ストアの状態。コレクション・サイズ、エンティティ数、埋め込み成功数、総チャンク数
Content Fetch Failures取得失敗の種別と件数（404、403、Unreachable、Timeouts、SSL errors、Rate Limits）
Ingestion Stage Failures処理段階ごとの失敗数（Chunking、Embedding、Parsing、Storage）
File Type Breakdownファイル種別ごとの文書数
Ingested Files取り込んだファイル・ページの一覧（Unstructured / Structured で絞り込み可）

右上の Export Content は、取り込んだページ・文書の一覧を CSV（ingested-content-<日時>.csv、列は Content Number と Page/Document）で出力します。本文やチャンクの内容は含まれません（実機確認済み）。

参考
実機検証（2026-09-08）では、日本語の公開ドキュメント・サイト 13 ページを Website Crawl で取り込み、成功率 100%、埋め込みカバレッジ 100%、失敗 0 件、平均チャンク長 605 トークンでした。日本語コンテンツが問題なく取り込めることの確認例として記録しています。
同じ文書を同じエージェントに再取り込みした場合、Total Documents Uploaded や Success Rate が累積した値で表示されることがあります（v1.4.3）。取り込み結果そのものには影響しません。

失敗の種別と対処

公式ユーザーガイドの Analytics & Monitoring（英語） に基づきます。

種別例対処
Content Fetch Failures404、403、タイムアウト、SSL、レート制限URL の修正、クローラーの許可リスト追加
Preprocessing / Chunking Failures構造欠落、ブロック長、エンコーディング異常文書の見出し構造を整える
Parsing Errors破損ファイル、非対応形式、JS 描画ページ別形式（テキスト付き PDF / HTML）へエクスポート
Embedding / Storage Errors埋め込みタイムアウト、チャンクサイズ超過、ベクトルストア挿入失敗チャンクサイズを下げる、バッチを分割

対処後は再取り込みを実行し、鮮度維持のためスケジュール再取り込みを設定してください。

取り込み実行中の表示

取り込みが実行中の状態で Connections を開くと、Active Ingestion Detected のモーダルが表示されます。

  • View Status — 実行中の取り込みのステータスページを開きます
  • Cancel Run — 実行中の取り込みを直ちに中止します

ステータスページ

ステータスページでは、取り込みパイプラインの進行状況を段階ごとに確認できます。

段階内容表示される件数
1. Scraping（Website）/ Document Processing（文書アップロード）ページの取得 / 文書のテキスト抽出Scraped Links / Processed Documents
2. Chunkingチャンク分割Chunked Documents
3. Vectorizing埋め込みの生成Vectorized Chunks
4. Database Uploadベクトル・ストアへの格納Uploaded Vectors
5. Upload wxO ToolwxO エージェントへの反映Tool Updates

上部には Pages Scraped（文書アップロードでは Documents Ingested）、Total Time、Broken Links、Unreachable Pages の集計と、残り時間の目安が表示されます。下部の Scraped Links で取得済み URL とステータス（PROCESSED LINK 等）を、PDFs Detected でクロール中に検出した PDF を確認できます。文書アップロードの場合は Processed Documents Details に文書ごとの状態が表示され、見出し下に対象エージェントの AGENT ID（Copy ボタン付き）が表示されます。

操作ボタンは以下のとおりです。

  • Pause Run — 取り込みを一時停止
  • Cancel Ingestion — 取り込みを中止
  • Open Chat Playground — 対象エージェントの Chat Playground を開く

注意
Cancel Run（モーダル）を押すと直ちに中止処理が始まり、「Cancelling… This may take up to 5 minutes.」と表示されます（取り消しはできません。実機確認済み）。状況を確認したいだけの場合は View Status を選んでください。ステータスページの Cancel Ingestion も同様に扱ってください。
取り込み中は同じエージェントに対する別の取り込みを開始できません（Headless API では 409 が返ります）。
パイプラインの最終段階 Upload wxO Tool で、ContentIQ のツールが wxO エージェントに登録されます（wxO エージェントへのナレッジ付与 参照）。上部の表示が Completed になっても Step 5 が In Progress のままのことがあるため、wxO 側でツールを確認する前に Step 5 が Complete（Tool Updates が 1 以上）になるまで待ってください。
