デプロイ

Widget 埋め込みとデプロイ

ContentIQ エージェントを Web ページやポータルに展開する
最終更新: 2026/9/18

Deployed agents（展開済みエージェントの一覧）

左サイドバーの Deploy Agent を開くと、展開済みエージェントの一覧（Deployed agents）が表示されます。

  • External タブ — 外部チャット（ContentIQ がホストするチャット・ページ）として展開したエージェント。種別バッジは EXTERNAL または EXTERNAL SSO
  • Widget タブ — Web ページに埋め込む Widget として展開したエージェント
  • 各エージェントには、エージェント ID、展開日時、外部チャットの URL（https://<ContentIQ のホスト>/external/deploy/chat/index.html?chat_id=<ID>）、Copy、Settings が表示されます
  • 右上の Deploy Agent から新規展開のウィザードを開始します

Deploy Agent ウィザード

Step 1: Select Deployment Type で展開方式を選びます。

方式内容
External AgentContentIQ がホストするチャット・ページとして公開し、URL を配布する。自インスタンスのホスト配下で動作
Widget任意の Web ページに埋め込むスクリプト（iframe 方式）を生成する。5 ステップ

Widget の場合

  1. Step 2: Select an agent — 展開するエージェントをドロップダウンから選択します。検索ボックスで絞り込めます。

  1. Step 3: Configure Allowed Origins — Widget を設置するドメインを + で追加します（https://*.example.com でサブドメインを一括許可）。Enable SSO で Microsoft サインインを要求できます。Use legacy inline embed は iframe を使わない旧方式で、SSO との併用は非推奨です。

  1. Step 4: Customize widget — ヘッダー・アイコン色、ブランド色、背景（単色 / グラデーション / 透過 / パターン）、ヘッダー・タイトル、ウェルカム・メッセージ、Widget アイコン、吹き出しの色をライブ・プレビューを見ながら設定します。

  1. Step 5: Copy and paste the code — 生成されたスニペットをコピーし、設置先ページの </body> 直前に貼り付けます。
<script defer src="https://contentiq-widget.pages.dev/loader.js" data-agent="<エージェント ID>" ...></script>

注意
Widget のローダー（loader.js）と iframe は、symplistic.ai の配信サービス https://contentiq-widget.pages.dev から提供されます（自己ホスト版でも同様）。設置先サイトの CSP には frame-src https://contentiq-widget.pages.dev の許可が必要です。自環境内で完結させたい場合は External Agent 方式を選んでください。
公式ガイドにある「Embed Agent」「Form Push」の記述は、実機（v1.4.3）では上記のウィザードに統合されています。

External Agent の場合

External Agent は 3 ステップで展開します。

  1. Step 2: Select an agent — 展開するエージェントを選択します。Enable SSO にチェックすると、チャット・ページで Microsoft サインインが要求されます（バッジは EXTERNAL SSO）。

  1. Step 3: Customize external chat — 背景（単色 / グラデーション / パターン）、ヘッダー・タイトル、Header Logo（URL またはファイル）、ウェルカム・メッセージ、吹き出しの色をプレビューを見ながら設定し、Finish をクリックします。

  1. Agent Deployed Successfully! のダイアログに Deployment URL が表示されます。Open Chat でチャット・ページを開いて動作を確認し、URL を利用者に配布します。展開済みのエージェントは Deployed agents の External タブに表示されます。

External Agent のチャット・ページは自インスタンスのホスト配下（/external/deploy/chat/index.html?chat_id=…）で提供されるため、自環境内で完結します。

Microsoft Entra SSO の適用

外部チャットや Widget に Microsoft サインインを要求できます。サインイン後、ContentIQ は利用者の Entra グループを読み取り、検索時の RBAC に使用します（公式ユーザーガイド SSO for Deployed External & Widget Agents（英語））。

検証状況
Entra 側の設定手順は公式ユーザーガイドの記載に基づいており、本ガイド作成時の検証環境では Entra との SSO 疎通確認は行っていません。ContentIQ 側の設定画面（SSO Configuration の Step 1・2）は実機で確認済みです。SSO を導入する際は、Entra の管理者と協力して事前に疎通確認を行ってください。

Entra 側の設定

  1. アプリ登録を作成または選択します。
  2. Authentication にリダイレクト URI を追加します。
    • 自己ホスト版: ContentIQ の SSO Configuration（Step 2）に表示される Redirect URI を Copy して登録します（自インスタンスの URL から自動生成されます）
    • SaaS: 公式ガイド記載の以下の URI（SaaS 環境の設定画面に表示される値を優先してください）
      • Admin SSO: https://contentiq.symplistic.ai/auth/sso_callback.html
      • External chat: https://contentiq.symplistic.ai/external/deploy/sso_callback.html
      • Widget iframe: https://contentiq-widget.pages.dev/sso_callback.html
  3. クライアント・シークレットを作成します。
  4. Microsoft Graph の委任アクセス許可（openid, profile, email, offline_access, User.Read, GroupMember.Read.All）を追加し、管理者の同意を付与します。

ContentIQ 側の設定

  1. 左サイドバーの Administrative Settings を開きます（ページ・タイトルは Admin Settings）。
  2. SSO Configuration タブで Start Configuration をクリックします。

  1. Step 1: Application Details で、Entra のアプリ登録から Application (client) ID と Directory (tenant) ID を入力し、Next をクリックします。

  1. Step 2: Authentication & Domain Settings で以下を入力し、Save SSO Configuration をクリックします。
    • Client Secret — Entra のアプリ登録で作成したシークレット（空欄のままにすると既存の値を維持）
    • Redirect URI — 自動生成された値を Copy し、Entra のアプリ登録に登録します
    • Allowed Email Domains — SSO でのログインを許可するメール・ドメイン（カンマ区切り）

  1. Deploy Agent ウィザードで外部チャットまたは Widget として展開する際に、Enable SSO をオンにします。SSO 付きのスニペットには data-sso="true" が含まれます（公式ガイドの記載による）。

SSO 設定はテナント全体に適用されます。SSO でサインインした新規ユーザーは、組織の共有資格情報（wxO、Milvus 等）を自動的に継承します（Tenant-wide WxO credential sync 参照）。

注意
アクセス判定は回答生成時に行われます。取得されたチャンクのアクセス・ロールが利用者の Entra グループと一致しない場合、「アクセス権なし」のメッセージが返ります。
Entra のグループ変更が反映されるまで最大 1 分程度かかります。
SharePoint 側で権限を変更した場合は該当文書の再取り込みが必要です。
