トラブルシューティング

よくある問題と対処
最終更新: 2026/9/11

公式ユーザーガイドの Troubleshooting（英語） に基づきます。

症状確認・対処
Ingest Analytics に「Failed to fetch」ネットワーク / ファイアウォール、API 資格情報を確認。ページを再読み込み
403 / 404 / タイムアウトが多いクロール対象のドメインとパスを確認。クローラーを許可リストに追加。安定した URL を使用して再試行
パース失敗、JS 描画ページのエラー静的レンダリングのパスを使う。テキスト付き PDF / HTML にエクスポート
埋め込みタイムアウト、サイズ上限チャンクサイズを下げる。大きなバッチを分割。埋め込みサービスのクォータを確認
Hallucination Rate が高い権威あるソースを追加。引用を有効化。エージェントの根拠制御設定を見直す
応答が遅い取得コンテキストを減らす。頻出コンテンツをキャッシュ。並列度とリージョン近接性を確認
OneDrive 認証失敗OAuth で再認証。テナント同意とフォルダー権限を確認
SSO 付き Widget で「アクセス権なし」取得チャンクのロールと利用者の Entra グループが一致しているか確認。SharePoint 権限変更後は再取り込み
Headless Chat API が 500（Internal server error）を返す回答生成は wxO エージェントの実行を経由するため、wxO 接続が有効でない場合に発生します（実機で wxO インスタンス失効時に再現、復旧後に解消）。Settings → watsonx Orchestrate の資格情報と wxO インスタンスの有効性を確認
API が 429 を返すプランのレート制限を超過。リクエスト頻度を調整
スケジュール・トリガーが 409 を返す同じエージェントで取り込みが実行中。完了を待つ
スケジュール・トリガーが 501 を返すdocument ソースはスケジュール非対応。クラウド・ストレージ経由に変更

問い合わせ先: symplistic.ai サポート（メール）。詳細は User Guide: Support & Resources（英語） を参照してください。
