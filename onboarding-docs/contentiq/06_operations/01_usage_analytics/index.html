運用

利用分析（Usage Analytics）

採用状況と回答品質を監視する
最終更新: 2026/9/18

画面構成（エージェント別ページ）

左サイドバーの Usage Analytics を開くと Usage Agents List（エージェント名、説明、Agent ID、最終更新日時、モデル）が表示され、View Analytics で個別の分析ページに移ります。

実機（v1.4.3）で確認できたエージェント別ページの構成は以下のとおりです。

セクション内容
上部カードAgent（名前と Agent ID）、Scope、Reporting Window（当月）、Feedback Activity
Questions per Month当月の質問数（前月比）と月次推移グラフ
Sources of Questions質問の流入元。Playground（Chat Playground）、Deployed agent（外部チャット）、Widget（埋め込み）、Orchestrate（wxO エージェントからのツール呼び出し）の 4 区分
Conversation Health全期間の指標。Avg Questions / Session、Avg Session Length、Average Response Latency（Min / Max 付き）
Feedback Breakdown回答へのフィードバック。Helpful / Not Helpful / Unrated の内訳、Feedback Rate、Tracked Answers
Unanswered Questionsエージェントが回答できなかった質問の一覧。ナレッジ・ギャップの特定に使います

wxO 経由の利用は Sources of Questions の Orchestrate として計測され、Average Response Latency には wxO からのツール呼び出しの応答時間が反映されます。

Administrative Analytics（テナント全体）

左サイドバーの Administrative Analytics では、テナント全体の Tenant Analytics を確認できます。

カード内容
Planサブスクリプション階層（例: Starter）
Deployed AgentsWidget / API として公開済みのエージェント数
Messages (This Month)当月のメッセージ数とプラン上限（実機の Starter では 75,000 / 月）
Messages (All Time)累計メッセージ数
Conversations累計スレッド数
Content Footprintベクトル・ストレージ使用量とプラン上限（実機の Starter では 5.0 GB）
Messages per month月次推移（直近 12 か月）
Tenant Usersテナント内のアカウントとロール

プランの上限（メッセージ数、ストレージ）はここで確認できます。上限に近づいた場合の挙動については IBM 担当またはパートナー担当にお問い合わせください。

検証環境で確認できた指標の範囲

公式ユーザーガイドの Analytics & Monitoring（英語） に記載されている以下の指標は、v1.4.3 の検証環境（エージェント別ページ、Usage Agents List、Administrative Analytics）では確認できませんでした。利用する環境のバージョンで提供状況を確認してください。

  • Answer Success Rate、Fallback Rate
  • Hallucination Rate、Citation Accuracy
  • Query Completion Rate
  • よく参照されるコンテンツ種別、トピック・クラスタ、使用言語、参照元ソース

注意
Hallucination Rate や Citation Accuracy を運用時の品質指標として計画している場合は、利用環境で提供されているかを事前に確かめてください。提供されていない場合は、Conversations のエクスポートと手動検証で引用精度を評価します。

改善のプレイブック

公式ユーザーガイドが示す対応です。

症状対応
Helpful Answer Rate が低い不足文書の追加、チャンキングの見直し、事例の追加
Unanswered Questions が多いカバレッジの拡大（不足文書の追加）、検索のチューニング、同義語の追加
根拠のない回答が見られるソースの検証、エージェントの指示で根拠制御を強化、引用の強制
Average Response Latency が高いコンテキスト量の削減、FAQ のキャッシュ、並列度の見直し

評価・運用への活用

  • Average Response Latency は応答時間の指標としてそのまま使えます（実機では wxO 経由で約 33 秒）
  • Unanswered Questions はナレッジ不足の検出に使えます
  • Feedback Breakdown は、利用者やレビュー担当者が Helpful / Not Helpful を付ける運用にすれば、回答の妥当性の簡易計測になります
  • 引用精度は、Conversations のエクスポートと手動検証で評価します（Citation Accuracy の提供状況は利用環境で確認）
