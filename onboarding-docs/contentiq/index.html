What is symplistic.ContentIQ?

symplistic.ContentIQ は、symplistic.ai が IBM watsonx Orchestrate（以下 wxO）と連携する形で提供する、RAG（検索拡張生成）型のナレッジ・プラットフォームです。Web サイト、文書ファイル、OneDrive / SharePoint / Box などのクラウド・ストレージからコンテンツを取り込み、wxO のエージェントに出典引用付きの根拠回答を提供します。

主な特徴は以下のとおりです。

  • 既存の wxO エージェントにナレッジを付与、または ContentIQ から新規 wxO エージェントを作成できる
  • 日本語コンテンツの取り込み時に日本語埋め込みが自動適用される（v1.2.1 以降）
  • スケジュール再取り込み（差分モード）により、ナレッジの鮮度を運用的に維持できる
  • 取り込み状況（Ingest Analytics）と利用状況（Usage Analytics）を分析ダッシュボードで監視できる
  • Headless API / MCP により、wxO フローや外部システムから呼び出せる

詳細は ContentIQ 製品ページ（英語） および ContentIQ Documentation（英語） をご覧ください。

wxO については watsonx Orchestrate オンボーディングガイド を参照してください。

Onboarding Process

ContentIQ のオンボーディングプロセスは、以下の領域に分かれています。

  1. 前提条件 — wxO インスタンスと API キーの準備、ContentIQ アカウントの取得
  2. 初期設定 — ContentIQ へのログインと wxO 接続情報の登録
  3. コンテンツの取り込み — 文書アップロード、Web サイト、クラウド・ストレージからの取り込みと状況確認
  4. エージェント — wxO エージェントへのナレッジ付与と Chat Playground での検証
  5. デプロイ — Widget 埋め込み、Headless API からの利用
  6. 運用 — 利用分析、セキュリティ・RBAC、トラブルシューティング
  7. ユースケース例 — 規約ナレッジによる文書チェック・エージェントの構築
