初期設定

ログインと wxO 接続設定

ContentIQ への初回ログインと wxO API キーの登録
最終更新: 2026/9/18

ログイン

  1. ContentIQ の URL にアクセスします。SaaS の場合は https://contentiq.symplistic.ai/、自己ホスト版（OpenShift 等）の場合は管理者から案内された URL です。
  2. 以下のいずれかでログインします。
    • Username と Password を入力して Login をクリック（symplistic.ai から発行されたアカウント）
    • Sign in with SSO をクリック（組織の Microsoft Entra ID。管理者が SSO を設定済みの場合）

アカウントをまだ持っていない場合は、ログイン画面の Request access to ContentIQ から申請できます。

wxO 接続情報の登録

  1. 左サイドバー下部の Settings を開きます。
  2. Settings 内のタブから watsonx Orchestrate を選択します。
  3. 以下を入力します。
    • Orchestrate API URL — wxO の設定画面で控えた サービス・インスタンスURL（前ページ 参照）
    • Orchestrate API Key — wxO で生成した API キー
  4. Update Credentials をクリックします。

Tenant ID は ContentIQ のテナント識別子で、自動的に表示されます（編集不要）。

ポイント
API キーは暗号化して保存されます。組織のポリシーに従って定期的にローテーションしてください。
Tenant-wide WxO credential sync を有効にすると、テナント管理者が wxO 資格情報を更新した際に、同じテナントの全ユーザーへ反映されます（取り込み実行中のユーザーは完了後に切り替わります）。無効（Per-user credentials）の場合、各ユーザーは自分で更新するまで現在の資格情報を使い続けます。
Delete all agents on this instance は、この wxO インスタンス上のエージェントをすべて削除する操作です。誤って押さないよう注意してください。

Settings のタブ構成

タブ内容
GeneralAccount（User、Email、Plan）、Change password、Preferences（取り込み完了時のメール通知の ON / OFF と通知先アドレス）
Tenant AdministrationActive Tenant の切り替え（このアカウントに保存されたテナント ID から選択）
watsonx OrchestratewxO 接続情報（本ページ）
ContentIQ APIContentIQ 自身の API キー（Headless API 参照）
ConnectionsThird-Party Connections。Microsoft（OneDrive / SharePoint）、Google Drive、Box、IBM Cloud Object Storage の接続状態と Connect / Disconnect。未接続のサービスは Not Connected と表示され、接続手続きを行うと有効化されます
Vector StoreMilvus の Server URI と Authentication Token、接続状態。顧客管理の Milvus に差し替える場合に使用（Revert to Default で既定に戻す）
Object StoreStorage Provider の選択（Default / Azure Blob Storage）

ポイント
取り込み完了のメール通知は 2 か所で設定できます。General → Preferences の「Notify via email when ingest completes」はユーザー個人の既定設定で、Notification email address に通知先を入力して Save changes します（Account の Email とは独立）。取り込みウィザードの Notify Email Upon Completion は、その取り込みに限った通知先（複数指定可）です。通知メールは no-reply@symplistic.ai から、件名「ContentIQ: Document ingestion completed」で届き、本文にエージェント名とダッシュボードへのリンクが含まれます（実機確認済み。送信元が symplistic.ai ドメインのため、社内メールの許可リストへの登録が必要な場合があります）。
Vector Store / Object Store を顧客管理のストアに変更した場合、そのストアのセキュリティ統制は顧客責任になります（セキュリティと RBAC 参照）。

5 分クイックスタート

公式ガイドが示す最短の流れは以下のとおりです。以降のページで各ステップを説明します。

  1. Settings → watsonx Orchestrate で wxO API URL・API キーを登録
  2. Connections からソースを追加（Website / Document / OneDrive など）
  3. Agent Type を選択（既存 wxO エージェント or 新規作成）
  4. 取り込みを開始し、Ingest Analytics で進捗を確認
  5. Chat Playground で動作確認
  6. Embed（スニペット）または Deploy Agent で展開
  7. Usage Analytics で効果を確認
