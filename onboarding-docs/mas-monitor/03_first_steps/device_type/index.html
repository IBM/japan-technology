はじめの設定

デバイスタイプとデバイスの登録 | Maximo Monitor オンボーディング

監視対象の設備をデバイスとして Monitor に登録する手順を確認しましょう。

デバイスタイプとデバイスの関係

Monitor では、センサーを取り付けた機器を デバイス として管理します。
デバイスは必ず デバイスタイプ（分類）に紐付けて登録します。

概念説明例
デバイスタイプデバイスをグループ化するカテゴリポンプ、モーター、ボイラー
デバイス個々の物理機器ポンプA、ポンプB

デバイスタイプに対してメトリクスやダッシュボードの設定を行うため、デバイスタイプを先に作成することが重要です。

STEP 1｜デバイスタイプの作成

  1. Monitor の 「Setup（セットアップ）」 メニューを開く
  2. 「Device types（デバイスタイプ）」 タブを選択する
  3. 「Add device type」 をクリックする

テンプレートを選択する画面が表示されます。

Add a custom device type（カスタムデバイスタイプ）

選択肢内容推奨
Device library templateデバイスライブラリのデバイスをベースに作成。メトリクス・ディメンションが事前定義済み上級者向け
Empty template完全にゼロから作るカスタムデバイスタイプ。メトリクス・ディメンションを自分で定義するこちらから始める

Add a sample device type（サンプルデバイスタイプ）

Industrial boiler・Industrial robot などのサンプルが選べます。サンプルデータとダッシュボードが付属しているため、Monitor の機能をすぐに試してみたい場合に最適です。まず Monitor の動作感を掴んでから自社デバイスの設定に進む、という使い方もできます。

  1. 「Empty template」 を選択して 「Next」 をクリックする
  2. 以下の情報を入力する
項目内容
Device type name管理しやすい名前（例：Pump）。後から変更できないため注意
Description任意（例：「工場内ポンプ」）
  1. 「Create（作成）」 をクリック

「Create」をクリックするとデバイスタイプの詳細画面が開きます。

作成直後は 「Metrics」タブ が開き、まだメトリクスがない場合は 「You don't have any metrics yet」 と表示されます。まずはこの画面からメトリクスを追加し、データ受信の準備を進めます。

タブ構成は以下の通りです。

タブ内容
Dataデバイスタイプに紐づくデータの概要を確認する
Overviewデバイスタイプの概要情報を確認する
Data Ingestionデータの受信設定を確認する
Metricsセンサーから収集するデータ項目を定義する。まずここから設定を始める
Calculated metrics生メトリクスをもとに計算・集計した複合指標を定義する
Dashboardsこのデバイスタイプ用のダッシュボードを作成・管理する
Templatesテンプレートを確認・管理する
Dimensionsデバイスの属性情報（シリアル番号・設置場所など）を定義する
このページではデバイスタイプを作成し、次ページの メトリクスの設定とデータ確認 で Metrics タブからメトリクスを追加する手順 に進みます。

ディメンションの追加（任意）

ディメンションは、デバイスに共通する属性情報（シリアル番号・設置場所・メーカーなど）です。メトリクス設定やデバイス登録が終わった後に、必要に応じて追加します。

  1. 「Dimensions」タブ を開く
  2. 「Add dimension」 をクリック
  3. ディメンション名（例：Serial number）・データ型を入力して 「Save」
ディメンションの値はデバイスごとに異なる場合（シリアル番号など）はデフォルト値を空にしておきます。全デバイスで共通する値（メーカー名など）はデフォルト値に設定しておくと便利です。

STEP 2｜デバイスの追加

デバイスタイプを作成したら、個々の機器（デバイス）を登録します。

  1. デバイス一覧画面（Setup > Devices）で 「Add device」 をクリックする

  1. 追加方法を選ぶ画面が表示される

選択肢内容推奨
Use device libraryメーカー製の既製デバイスを追加。メトリクス・ディメンションが事前定義済み。Gateway type / Gateway の設定が必要上級者向け
Add custom device自社設備など独自デバイスを追加。メトリクスを自分で定義するこちらから始める
Use device library を選ぶと、画面下部で Gateway type と Gateway の設定が必要になります。初回オンボーディングでは設定が複雑になりやすいため、まずは Add custom device で進めることを推奨します。Gateway 自体の役割は、このページ後半の Gateway について を参照してください。Use device library の詳細は IBM Documentation — Device library を参照してください。
  1. 「Add custom device」 を選択して 「Continue」 をクリックする
  2. 以下の情報を入力する
項目内容
Device IDデバイスを識別する一意の ID（英数字・ハイフン・アンダースコアのみ。最大 36 文字）
Token typeAuto-generated（自動生成）を推奨
Device type登録先のデバイスタイプを選択。新規作成する場合は名前を入力して Enter
  1. 「Add」 をクリック

登録完了後に表示される Authentication token は必ずコピーして保存してください。画面にも 「This token is not recoverable」 と表示される通り、後から再確認できません。物理デバイス（センサー）側の接続設定に必要です。
Device ID は後から変更できません。センサー側と一致する命名規則で設定してください。

Gateway について

複数のデバイスからデータを一括して Monitor に送信するには Gateway を使用します。 Gateway は Monitor 9.0 以降、IoT ツールではなく Monitor の「セットアップ」画面から直接作成・管理できます。

Gateway の詳細設定（MQTT 接続など）は、IT 担当者または IBM 担当者と連携して実施してください。オンボーディングの段階では、まずデバイスタイプとデバイスの登録・メトリクスの確認を優先しましょう。

階層への組み込み

デバイスを登録したら、階層（拠点・システム・ロケーション）に紐付けることで、設備の全体像を Monitor 上でミラーリングできます。
階層は CSV ファイルからインポートすることも可能です。詳細は IBM Documentation を参照してください。
