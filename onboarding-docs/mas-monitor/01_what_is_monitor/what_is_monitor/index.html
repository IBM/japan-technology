Maximo Monitor とは

Maximo Monitor とは | Maximo Monitor オンボーディング

IoT センサーデータによる設備状態監視・異常検知アプリケーション Maximo Monitor を理解しましょう。

MAS 共通ガイドで説明した通り、MAS は複数の Function で構成されています。その中で設備の状態監視・異常検知を担うのが Maximo Monitor です。

Maximo Monitor とは

Maximo Monitor は、IoT センサーデータをリアルタイムに収集・分析し、設備の状態監視・異常検知・アラート通知を行うアプリケーションです。

現場に設置したセンサーから温度・振動・圧力などのデータを継続的に取得し、ダッシュボードで見える化するとともに、異常なデータを自動検知してアラートを発報します。

MAS 共通ガイドをまだ読んでいない場合は、先に MAS とは をご確認ください。AppPoint ライセンスの考え方などが理解できます。

Maximo Monitor でできること

機能内容
ダッシュボード現在・過去のトレンドデータをカスタマイズ可能なダッシュボードで可視化
メトリクス管理センサーの生データや計算式で導出した独自メトリクスを定義・管理
異常検知AIを用いて外れ値・欠落・フラットライン（固着異常）を自動検出
アラート設定したしきい値や条件を超えたときに通知を発報
階層管理拠点・システム・設備・デバイスの階層構造でデータを整理
Manage 連携アラートから Maximo Manage のサービス要求を直接起票

主な活用シーン

シーン内容
設備の状態監視モーター・ポンプ・コンプレッサーなどの稼働状況をリアルタイムで把握
異常の早期検知しきい値超過や AI 異常検知でトラブルを未然に防ぐ
予知保全への活用蓄積されたセンサーデータを Maximo Predict（AI 故障予測）に連携
KPI のモニタリングOEE（設備総合効率）などの指標をリアルタイムで可視化

Monitor の基本概念

Monitor を使い始める前に、以下の概念を理解しておきましょう。

用語説明
デバイスセンサーを取り付けた物理的な機器。Monitor 上に登録して管理する
デバイスタイプデバイスをグループ化する分類。例：「ポンプ」「モーター」など
メトリクスデバイスから収集されるデータ項目。温度・振動・圧力など
ゲートウェイ複数デバイスのデータを集約して Monitor に送信する中継機器
階層組織・拠点・システム・ロケーション・資産を階層的に表現した構造
ダッシュボードデバイスタイプや階層のデータをカード・グラフで表示する画面

他の MAS Function との関係

連携 FunctionMonitor との関係
