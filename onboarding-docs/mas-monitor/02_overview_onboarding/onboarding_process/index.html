オンボーディングの流れ

オンボーディングの流れ | Maximo Monitor オンボーディング

Maximo Monitor を活用できるようになるまでのステップを確認しましょう。

はじめに

本ガイドは、Maximo Monitor を初めて利用する方が、センサーデータを Monitor に取り込み、ダッシュボードでデータを可視化してアラートを受信できるようになるまでのステップをご案内します。

MAS Hub へのログインやユーザー追加は MAS 共通オンボーディングガイド で完了している前提で進めます。

このガイドを最後まで進めると、現場の設備が「しゃべりはじめる」感覚が得られます。センサーのデータがリアルタイムでダッシュボードに流れ込み、異常が起きた瞬間にアラートが届く——現場に行かなくても設備の状態が手元でわかる状態になります。

オンボーディングのスコープ

このガイドでは、以下を オンボーディング完了 の目安としています。

  • Monitor にアクセスし、画面の構成を理解できている
  • デバイスタイプとデバイスを登録できる
  • メトリクスを定義してデータを確認できる
  • ダッシュボードを作成してデータを可視化できる
  • アラートを設定して通知を受け取れる

IoT ゲートウェイの詳細設定・外部システム連携・Predict との高度な連携は、基本操作が安定した後のネクストステップとして検討してください。

STEP 1｜Monitor へのアクセス確認・画面の見方

MAS Hub から Monitor にアクセスし、基本的な画面構成を把握します。

💡 なぜここから始めるか
Monitor の画面は「セットアップ → モニター → アラート」という監視構築の流れに沿って設計されています。最初に全体像を把握しておくと、以降のステップが迷わず進められます。

このステップのゴール

  • Monitor にログインできる
  • 画面構成（セットアップ・モニター・アラート）を理解している

→ Monitor へのアクセス確認・画面の見方

STEP 2｜デバイスタイプとデバイスの登録

監視対象の設備をデバイスとして Monitor に登録します。 デバイスは必ずデバイスタイプ（分類）に紐付けて管理します。

💡 なぜ重要か
デバイスタイプは「同じ種類の設備をまとめて管理するための型」です。一度作れば、同じ種類の設備を何台追加しても同じメトリクス・ダッシュボードの設定が引き継がれます。最初の設計がそのまま運用のしやすさに直結します。

このステップのゴール

  • デバイスタイプを作成できる
  • デバイスを登録できる

→ デバイスタイプとデバイスの登録

STEP 3｜メトリクスの設定とデータ確認

センサーから送られてくるデータ項目（メトリクス）を定義し、実際にデータが届いているかを確認します。

Monitor の導入初期で最も多いつまずきは「データが届かない」です。メトリクス定義後は必ずデータ受信を確認してから次のステップに進みましょう。

💡 ここでの感動ポイント
設定が完了し、センサーデータが初めて Monitor に届いた瞬間——数値が画面に現れ、「設備がつながった」と実感できます。現場の機械が発するデータが、クラウド上のダッシュボードにリアルタイムで流れてくる体験です。

このステップのゴール

  • 生メトリクス（センサーの生データ）を定義できる
  • データが Monitor に届いていることを確認できる
  • デバイスの最新データを確認できる

→ メトリクスの設定とデータ確認

STEP 4｜ダッシュボードの作成

デバイスのデータをグラフ・カードで可視化するダッシュボードを作成します。

💡 ここでの感動ポイント
グラフや数値カードを配置し、リアルタイムで動くダッシュボードが完成したとき——「現場に行かなくても設備の状態が手元でわかる」という変化が起きます。複数設備をまとめて監視できるようになると、管理の視野が一気に広がります。

このステップのゴール

  • ダッシュボードを作成できる
  • デバイスの状態をリアルタイムに可視化できる

→ ダッシュボードの作成

STEP 5｜アラートの設定

しきい値を超えたときや異常を検知したときに通知を受け取るアラートを設定します。

💡 ここでの感動ポイント
アラートを設定して最初に通知が届いたとき——「常に監視していなくても、異常が起きたら教えてくれる」安心感が得られます。「見張り続ける」から「知らせてもらう」への転換、これが Monitor の本質的な価値です。

このステップのゴール

  • しきい値アラートを作成できる
  • アラートテーブルで発報を確認できる

→ アラートの設定

オンボーディング完了後

基本的な監視環境が構築できたら、以下の活用をご検討ください。

活用領域概要
複数設備の統合監視サマリーダッシュボードで拠点・ライン単位の全体監視を実現
IoT ゲートウェイとの連携エッジ環境でのデータ収集・ネットワーク障害時の継続収集
外部システムとのデータ連携SCADA・PLC など既存システムからのデータ取り込み
Maximo Manage との連携アラートから作業指示・サービス要求を自動起票
Maximo Health / Predict の活用蓄積データを用いた AI 故障予測・予兆保全の実現
高度なアラートルールと分析計算済みメトリクスを活用した複合条件アラートの設計

詳細は IBM Documentation および各製品ガイドをご参照ください。
