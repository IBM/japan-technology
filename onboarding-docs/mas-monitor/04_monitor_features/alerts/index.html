Monitor の主な機能

アラートの設定 | Maximo Monitor オンボーディング

しきい値超過や異常検知時に通知を受け取るアラートを設定しましょう。

アラートとは

アラートは、定義した条件が満たされたときに Monitor が発報する通知です。 設備のデータが正常範囲を外れたときや、異常が検知されたときにアラートが表示されます。

アラートは Monitor のアラートテーブル で確認・対応でき、Maximo Manage と連携している場合はサービス要求の自動起票も可能です。

アラートの仕組み

Monitor のアラートは、Calculated metrics（計算済みメトリクス）にアラート関数を適用することで設定します。 「アラート」という独立した設定画面はなく、計算済みメトリクスの延長線上にある機能です。

利用できる主なアラート関数は以下の通りです。

関数内容
AlertHighValueメトリクスが上限値を超えたときに発報
AlertLowValueメトリクスが下限値を下回ったときに発報
AlertOutOfRange上限・下限の両方を設定し、範囲外で発報
AlertExpression自由な式（例：df['temperature']>100）で条件を定義して発報
AlertByOccurrencesCount条件が指定した回数以上、指定した時間枠内で発生したときに発報
NoDataAlertデバイスが指定した期間データを送信しなくなったときに発報

しきい値アラートの設定手順（AlertHighValue の例）

  1. 「Setup」 メニューを開き、「Device types」 タブを選択する
  2. 以下のいずれかの方法でデバイスタイプの編集画面を開く
    • デバイスタイプ名の横にある 「⋮」 をクリックし、「Edit」 を選択する
    • デバイスタイプ名をクリックして選択した状態で、右上の 「Edit（鉛筆アイコン）」 をクリックする
  3. 「Calculated metrics」タブ を開く
  4. 「Add calculated metric +」 をクリックする

  1. 関数一覧から 「AlertHighValue」 を選択し、「Select」 をクリックする

① Scope（対象デバイスの範囲）

選択肢内容
All devices of this typeこのデバイスタイプ全台に適用（推奨）
All devices that match an expression式で絞り込んだデバイスに適用
All devices that match dimensions filtersディメンション条件で絞り込んだデバイスに適用

オンボーディング段階では 「All devices of this type」 のまま 「Next」 をクリックする。

② Input（監視対象としきい値の設定）

項目内容例
input_item監視するメトリクスをドロップダウンで選択temperature
upper_thresholdアラートを発報する上限値80
Severityアラートの重大度（必須）High / Medium / Low
Statusデフォルトの New のままでOK—

入力したら 「Next」 をクリックする。

③ Output（アラート名の設定）

項目内容
Nameアラートの出力名。英数字・ハイフン・アンダースコアのみ・36文字以内（例：temperature_high_alert）
Store in databaseチェックONのまま。アラート履歴がDBに保存され、アラートテーブルで確認できる
Auto scheduleOn のまま

「Create」 をクリックしてアラートを作成する。

アラートは実際にデータが届き、しきい値を超えた時点で初めて発報されます。データ連携がまだの場合は設定だけ済ませておき、データが届いた段階で動作を確認しましょう。

アラートの確認と対応

発報されたアラートを確認するには、ダッシュボードに「Alert table」カードを追加する必要があります。

Alert table カードの追加手順

  1. 対象デバイスのダッシュボード編集画面を開く（ダッシュボードの作成 を参照）
  2. 右側の 「Gallery」 から 「Alert table」 を選択してダッシュボードに追加する
  3. 「Save and close」 をクリックする

ダッシュボードに Alert table カードが追加されると、アラートが発報されたときに一覧として表示されます。

アラートへの対応

操作内容
Acknowledgeアラートを認識済みにする
Resolveアラートを解決済みにする
Manage への連携Maximo Manage のサービス要求としてアラートを起票（要連携設定）
Maximo Manage との連携設定は管理者が事前に行う必要があります。設定方法は IBM Documentation を参照してください。
