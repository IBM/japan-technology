Monitor の主な機能

ダッシュボードの作成 | Maximo Monitor オンボーディング

デバイスのデータをグラフ・カードで可視化するダッシュボードを作成しましょう。

ダッシュボードの種類

Monitor では複数種類のダッシュボードを作成できます。

種類内容
デバイスダッシュボード特定のデバイス1台のデータを表示
サマリーダッシュボードデバイスタイプ全体のデータを集約表示
階層ダッシュボード階層（拠点・システム・ロケーション）単位でのデータを集約表示

オンボーディング段階では、まずデバイスダッシュボードから作成することを推奨します。サマリーダッシュボード・階層ダッシュボードは、デバイスダッシュボードに慣れてから取り組みましょう。

デバイスダッシュボードの作成手順

  1. Monitor の 「Monitor」 ページを開き、「Devices」 をクリックする
  2. デバイス一覧から対象のデバイスをクリックする
  3. 「Dashboards」タブ を開き、「Add dashboard +」 をクリックする
  4. 「Create dashboard」 ダイアログが開く
    • Dashboard title にダッシュボード名を入力する
    • 「Do you want to create a dashboard for all the devices or the current device?」の選択で 「Current device」 を選ぶ
  5. 「Configure dashboard」 をクリックする
  6. 右側の 「Gallery」 からカードを選んでダッシュボードに追加する
  7. 「Save and close」 をクリックする
All devices と Current device の違い
選択肢作成されるダッシュボード向いているケース
Current device今選んでいるデバイス専用のダッシュボード特定の設備1台のデータを詳しく確認したい場合
All devicesそのデバイスタイプ全体に共通のダッシュボード同じ種類の設備すべてに同じ構成を適用したい場合
オンボーディング段階ではまず 「Current device」 で動作を確認することを推奨します。

主なカードの種類

カード（Gallery 表記）内容用途
Time series line時系列データを折れ線グラフで表示トレンドの把握
Simple barデータを棒グラフで表示期間ごとの比較
Stacked bar複数系列を積み上げ棒グラフで表示構成比の比較
Value/KPIメトリクスの現在値を数値で表示温度・圧力の現在値確認
Data table複数デバイスのメトリクスをテーブルで比較機器一覧の比較
Image設備の画像にセンサー値をオーバーレイ表示設備の直感的な状態確認
Alert table発報中のアラートを一覧表示異常状況の監視
Third-party content外部コンテンツを埋め込み表示外部システムとの連携
まず Time series line と Value/KPI を組み合わせたシンプルなダッシュボードを1つ作成して動作を確認しましょう。設備のレイアウト・KPI に合わせて徐々に充実させていくアプローチが効果的です。

Monitor の最初の成功体験

環境によって、目指す到達点が異なります。

データ連携がある場合

実際のデバイスまたは API からデータが届いている場合は、Gallery から Time series line などのカードを追加した時点でグラフに値が表示されます。値が表示されることを確認できたら成功です。

値が表示されない場合は、前のページ（メトリクスの設定とデータ確認）で定義した Metric 名・Event 名と、送信しているデータの名前が一致しているかを確認してください。

データ連携がない場合

デバイスやAPIがまだ準備できていない場合は、JSON ファイルをインポートしてサンプルダッシュボードを作成するところまでを目標にしましょう。

  1. ダッシュボード編集画面のツールバーにある 「Import」 ボタンをクリックする
  2. 以下の内容を .json ファイルとして保存し、インポートする
{
  "title": "Sample Sensor Dashboard",
  "cards": [
    {
      "id": "card_temperature",
      "size": "LARGE",
      "title": "Temperature（時系列）",
      "type": "TIMESERIES",
      "content": {
        "series": [{ "dataSourceId": "temperature_ID", "label": "Temperature" }]
      },
      "dataSource": {
        "attributes": [{ "attribute": "temperature", "id": "temperature_ID" }],
        "range": { "count": -24, "interval": "hour" }
      }
    },
    {
      "id": "card_humidity",
      "size": "LARGE",
      "title": "Humidity（時系列）",
      "type": "TIMESERIES",
      "content": {
        "series": [{ "dataSourceId": "humidity_ID", "label": "Humidity" }]
      },
      "dataSource": {
        "attributes": [{ "attribute": "humidity", "id": "humidity_ID" }],
        "range": { "count": -24, "interval": "hour" }
      }
    }
  ]
}
  1. インポートが完了すると以下のような画面が表示され、カードが配置される

  1. 「Save and close」 をクリックする

ダッシュボードの構成が作成できたら成功です。 データが届いた段階で自動的に値が表示されるようになります。

詳細は IBM Documentation — Creating device dashboards を参照してください。
