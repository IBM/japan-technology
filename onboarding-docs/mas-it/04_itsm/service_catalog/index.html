ITサービス管理（ITSM）

サービスカタログの活用 | Maximo IT オンボーディング

エンドユーザーがセルフサービスでサービスを申請できるサービスカタログの基本を学びましょう。

サービスカタログ は、エンドユーザーが IT サービスをセルフサービスで申請・取得できる仕組みです。
ユーザーはカタログからサービスを選んで申請するだけで、承認・履行フローが自動で進みます。

サービスカタログの構成要素

要素内容
サービスオファリングユーザーが申請できるサービスの定義（例：PC 新規申請・パスワードリセット）
カタログオファリングをグループ化して整理・公開する単位
分類オファリングをカテゴリ分けして検索しやすくする
属性申請時にユーザーが入力する項目（例：希望機種・納品先）
承認ワークフロー申請を承認・却下するフロー

オファリングの種類

種類内容
ナレッジ記事情報を提供するだけ（申請不要）
サービスリクエストユーザーが入力項目を記入して申請。承認・履行フローが起動

管理者：オファリングの作成

  1. Go To メニューから 「Service Request Catalog」（サービス要求カタログ）> 「Service Offerings」（サービスオファリング） を開く
  2. 「New Offering」（新規オファリング） をクリック
  3. ガイド付きウィザードに沿って以下を設定する
    • オファリング名・説明・分類
    • 申請時の入力項目（属性）
    • 承認ワークフロー
    • 公開するカタログ
  4. 「公開」 してエンドユーザーが利用できる状態にする
「サービスオファリング」アプリケーションは、以前の「オファリング」アプリケーションより簡素化されたガイド付きインターフェースです。IT 部門以外のビジネスユーザーでもオファリングを作成できます。

エンドユーザー：サービスの申請

エンドユーザーは セルフサービス 画面からサービスを申請します。

  1. MAS Hub から 「Self Service」（セルフサービス） にアクセス
  2. サービスカタログから申請したいサービスを選ぶ
  3. 必要事項を入力して 「申請」 をクリック
  4. 承認・履行の状況はセルフサービス画面から確認できる

サービス要求の承認・履行

管理者・担当者は、申請されたサービス要求を確認・承認・履行します。

  1. Go To メニューから 「Service Desk」（サービスデスク）> 「Service Requests」（サービス要求） を開く
  2. 対象のサービス要求を開く
  3. 承認または対応内容を記録してクローズ
