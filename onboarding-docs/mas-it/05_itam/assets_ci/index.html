IT資産管理（ITAM）

IT 資産・CI の管理 | Maximo IT オンボーディング

IT 資産と構成アイテム（CI）の基本概念と管理方法を学びましょう。

Maximo IT の IT 資産管理（ITAM）では、IT 資産と構成アイテム（CI） の2つの概念を中心に管理します。

IT 資産とは

IT 資産 は、組織が所有・管理するハードウェア・ソフトウェアの物理的なアイテムです。
PC・サーバー・ネットワーク機器・ソフトウェアライセンスなどが含まれます。

IT 資産を登録・管理することで、以下が実現できます。

  • IT 資産の所在・状態・担当者の一元管理
  • 調達から廃棄までのライフサイクル管理
  • ソフトウェアライセンスのコンプライアンス確保
  • コストの可視化・最適化

構成アイテム（CI）とは

構成アイテム（CI） は、IT サービスを提供するために管理が必要なコンポーネントです。
サーバー・アプリケーション・ネットワーク機器・データベースなど、IT サービスを構成するすべての要素が対象です。

CI を管理することで、以下が可能になります。

  • IT 環境の論理モデルの可視化
  • CI 間の関係性（依存関係）の把握
  • 変更管理での影響分析への活用
  • インシデント・問題との紐付けによる根本原因分析
IT 資産と CI は重複することがありますが、目的が異なります。IT 資産 は財務・調達の観点、CI はサービス継続性・変更管理の観点で管理します。

IT 資産の登録

  1. Go To メニューから 「Assets」（資産）> 「Assets」（資産） を開く
  2. 「New Asset」（新規資産） をクリック
  3. 資産番号・説明・タイプ（IT資産）・ロケーションを入力
  4. 保存

CI の管理

CI は 「IT Infrastructure」（IT インフラストラクチャー） モジュールで管理します。

アプリケーション内容
認証済み CI管理対象の CI を登録・属性・関係を管理
現状の CI検出ツールが収集した読み取り専用のデータ
CI コレクション複数の CI をグループ化して管理

CI の関係性の設定

CI 間の依存関係を登録することで、変更時の影響分析に活用できます。

例：「アプリケーションサーバー → データベースサーバー → ストレージ」のような依存関係を CI として定義する。

ソフトウェアライセンス管理

ソフトウェアの購入ライセンス数と実際の導入数を照合することで、ライセンスコンプライアンスを確保します。

アプリケーション内容
ライセンスソフトウェアライセンスの資格・数量を管理
導入済みソフトウェア検出ツールからインポートした実際の導入数
差分検出購入ライセンス数と導入数のギャップを確認
ライセンス違反は監査時に大きなリスクとなります。定期的に差分検出を実行してライセンスコンプライアンスを確認しましょう。
