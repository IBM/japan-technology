オンボーディングの流れ

オンボーディングの流れ | Maximo IT オンボーディング

Maximo IT を活用できるようになるまでのステップを確認しましょう。

はじめに

本ガイドは、Maximo IT を初めて利用する方が、ITSM・ITAM の基本操作を習得して業務で活用できるようになるまでのステップをご案内します。

MAS Hub へのログインやユーザー追加は MAS 共通オンボーディングガイド で完了している前提で進めます。

このガイドを最後まで進めると、「誰が・何を・いつまでに対応するか」がシステムで管理される状態になります。メールや口頭で回っていたインシデント対応・IT 資産の把握が、一つの画面で完結します。

オンボーディングのスコープ

このガイドでは、以下を オンボーディング完了 の目安としています。

  • Maximo IT にアクセスし、画面の構成を理解できている
  • 組織・サイト・サービスカタログの概念を理解している（管理者）
  • インシデント・サービス要求・変更の基本操作ができる（ITSM）
  • IT 資産・構成アイテム（CI）の基本操作と両者の違いを理解している（ITAM）

リリース管理・SLA 詳細設定・外部システム連携などは、基本運用が安定した後のネクストステップとして検討してください。

STEP 1｜Maximo IT へのアクセス確認・画面の見方

MAS Hub から Maximo IT にアクセスし、基本的な画面構成とセキュリティグループの設定を確認します。

💡 なぜここから始めるか
Service Desk の画面を最初に見ると、「インシデント・変更・資産がすべて一つの画面で管理されている」という全体像が掴めます。個別機能の前に全体像を把握しておくことで、以降の操作が腑に落ちやすくなります。

このステップのゴール

  • Maximo IT にログインできる
  • ナビゲーション（Go To メニュー）の構成を理解している
  • Service Desk 画面の構成を理解している

→ ユーザーアクセスの付与

STEP 2｜組織・サイト・サービスカタログの理解と初期設定（管理者）

運用単位となる組織・サイトの概念を理解し、サービスカタログの初期設定を行います。

移行・SaaS 環境では既に設定済みの場合があります。その場合は設定内容の確認のみで構いません。

💡 なぜ重要か
サービスカタログは「ユーザーが自分で IT サービスを申請できる入口」です。ここが整備されると、ヘルプデスクへの電話・メールが減り、ユーザー側も担当者側も手間が大幅に減ります。

このステップのゴール

  • 組織・サイトの概念と設定内容を理解している
  • サービスカタログの基本設定を確認できる

→ 環境のクイック構成

STEP 3｜ITSM の基本操作

サービスデスクの中核となるインシデント管理・サービス要求・変更管理を習得します。

💡 ここでの感動ポイント
インシデントを登録した瞬間に SLA カウントダウンが始まり、担当者に自動通知が届きます。「誰かが対応してくれているのか不明」という状態がなくなり、進捗が常に可視化されます。「追いかけなくてよくなった」という声が多いポイントです。

このステップのゴール

  • インシデントを起票・対応・クローズできる
  • サービス要求を受付・対応できる
  • 変更要求を作成・承認・実施できる

→ インシデント・サービス要求の管理 → 変更管理 → サービスカタログの活用

STEP 4｜ITAM の基本操作

IT 資産・構成アイテム（CI）の管理を習得します。

IT 資産（Asset）と構成アイテム（CI）は似ていますが役割が異なります。Asset は「物理的・財務的な管理対象」、CI は「IT サービスを構成する論理的な要素」です。詳しくは各ページで解説しています。

💡 ここでの感動ポイント
CI を登録してインシデントに紐づけると、「どの機器で何回障害が起きたか」が自動で記録されます。障害が多い機器が一目でわかり、「なんとなく古い PC を交換した」から「データに基づいて優先順位を決めた」に変わります。

このステップのゴール

  • IT 資産を登録・管理できる
  • 構成アイテム（CI）の役割を理解している
  • Asset と CI の違いを理解している

→ IT 資産・CI の管理

オンボーディング完了後

基本操作ができるようになったら、以下の活用をご検討ください。

活用領域概要
SLA 管理対応期限・優先度に応じた SLA の設計と監視
Release Management変更管理と連携したリリース計画の運用
Workflow カスタマイズ承認フローや通知ルールの自社プロセスへの適合
外部認証連携LDAP / SAML との連携によるシングルサインオン
Discovery 連携ネットワーク探索ツールと連携した CI の自動登録
CMDB の高度活用依存関係マップによる影響範囲分析
レポート・ダッシュボードインシデント傾向・SLA 達成率の可視化
