Maximo IT とは

Maximo IT とは | Maximo IT オンボーディング

ITIL準拠のITサービス管理（ITSM）とIT資産管理（ITAM）を提供する Maximo IT を理解しましょう。

MAS 共通ガイドで説明した通り、MAS は複数の Function で構成されています。IT 部門向けのサービス管理・資産管理を担うのが Maximo IT です。

Maximo IT とは

Maximo IT は、IT サービス管理（ITSM）と IT 資産管理（ITAM）を統合した MAS のアプリケーションです。

ITIL（IT Infrastructure Library）のベストプラクティスに準拠したプロセスを活用して、複雑化する IT 環境の管理を支援します。

Maximo IT は MAS の独立した Function として利用できます。また、Maximo Manage のアドオンとしてデプロイすることで、IT 管理と設備資産管理を統合することも可能です。

Maximo IT でできること

IT サービス管理（ITSM）

機能内容
インシデント管理サービスの障害・低下を記録・追跡・解決
問題管理インシデントの根本原因を特定・解決
サービス要求管理ユーザーからのサービス依頼を受付・対応
変更管理IT 環境への変更を計画・評価・承認・実施
リリース管理変更のリリースを計画・管理
サービスカタログユーザーがセルフサービスでサービスを申請
SLA 管理サービスレベル契約の定義・モニタリング

IT 資産管理（ITAM）

機能内容
IT 資産管理ハードウェア資産の台帳管理・ライフサイクル追跡
構成アイテム（CI）管理IT インフラのコンポーネントを論理モデルで管理
ソフトウェアライセンス管理ソフトウェアの利用権・ライセンスコンプライアンス管理
ソフトウェア資産管理（SAM）未使用ライセンスの削減・コスト最適化

ユーザーペルソナ

Maximo IT には以下の主要なユーザーペルソナがあります。

ペルソナ役割
管理者システム設定・ユーザー管理・全体の構成
サービスデスクエージェントインシデント・サービス要求の対応・解決
変更マネージャー変更要求の評価・承認・スケジュール管理
資産マネージャーIT 資産・ソフトウェアライセンスの管理
エンドユーザーセルフサービスからのインシデント報告・サービス申請

画面の操作方法

Maximo IT の UI は Maximo Manage と共通です。Go To メニュー（≡）からモジュール・アプリケーションにアクセスします。
画面の基本操作については Manage — 画面ナビゲーション を参照してください。

IBM Control Desk（ICD）からご移行のお客様へ

ICD をご利用だったお客様は、データ・ワークフロー・カスタマイズが Maximo IT に移行済みの状態からスタートします。
基本的な操作方法は ICD と共通していますが、MAS の新しい画面デザインや機能拡張については本ガイドおよび IBM 公式ドキュメント を参照してください。

MAS 共通ガイドをまだ読んでいない場合は、先に MAS とは をご確認ください。AppPoint ライセンスの考え方などが理解できます。
