Maximo IT オンボーディングガイド | ITSM・初期導入手順

ITIL準拠のITサービス管理（ITSM）とIT資産管理（ITAM）を統合したMaximo ITの初期導入、サービスカタログ構成、インシデント管理手順を日本語で解説。ITサービス運用を高度化したい技術者向けオンボーディングガイド。
最終更新: 2026/9/15

IBM Maximo IT をご利用いただきありがとうございます。
本ガイドは、Maximo IT の利用開始をスムーズに進めていただくためのオンボーディングガイドです。

Maximo IT は、ITIL のベストプラクティスに基づく IT サービス管理（ITSM）と IT 資産管理（ITAM）を統合したアプリケーションです。
インシデント・問題・変更・リリース管理などの ITSM プロセスと、IT 資産・ソフトウェアライセンス管理を一つのプラットフォームで実現します。

本ガイドをご利用の前に、MAS 共通オンボーディングガイド の「MAS とは」および「利用開始前の確認事項」を完了されていることを推奨します。
