はじめの設定

Maximo IT へのアクセス確認・画面の見方 | Maximo IT オンボーディング

Maximo IT にアクセスし、基本的な画面構成を把握しましょう。

Maximo IT へのアクセス

MAS Hub から Maximo IT のタイルをクリックすることで、Maximo IT にアクセスできます。

アクセスできない場合は、MAS Hub でのライセンス割当とセキュリティグループの設定が完了しているか確認してください。詳しくは MAS 共通ガイド — ユーザーの追加と権限設定 を参照してください。

画面構成の見方

Maximo IT の画面は Maximo Manage と同じナビゲーション構造を持っています。

要素説明
左端サイドバーアイコンのみ表示。≡ をクリックすると Go To メニューが展開
Go To メニューアプリケーション一覧。ITSM・ITAM の各アプリにアクセス
Service Desk（サービスデスク）インシデント・サービス要求・変更管理のハブ画面
トップバーレポート・ヘルプ・プロファイル設定

Service Desk 画面

ログイン後は Service Desk（サービスデスク） 画面が開きます。 ここから未対応のインシデント・サービス要求・変更要求を一覧で確認できます。

セキュリティグループの設定（管理者向け）

このセクションは 管理者向け です。

MAS Hub でユーザーを追加しただけでは、Maximo IT の各アプリケーションは利用できません。 Maximo IT 内でのセキュリティグループ設定が別途必要です。

MAS Hub でのユーザー追加手順は MAS 共通ガイド — ユーザーの追加と権限設定 を参照してください。このページでは Maximo IT 内の権限設定について説明します。

Maximo IT のセキュリティグループ

Maximo IT のセキュリティグループは、Maximo Manage と同様に アプリケーション権限・サイト権限 を管理します。
ユーザーの役割（サービスデスクエージェント・変更マネージャー・資産管理担当など）に応じたグループを設定してください。

主なセキュリティグループの例：

グループ想定する役割主なアクセス範囲
MAXADMINシステム管理者全アプリケーション・全操作
サービスデスクエージェントインシデント・SR 対応担当サービスデスク・変更・サービス要求カタログ
変更マネージャー変更の評価・承認担当変更・リリース・計画・スケジューリング
資産マネージャーIT 資産・ライセンス管理担当資産・IT インフラ・ソフトウェアカタログ
エンドユーザーセルフサービス利用者セルフサービス・サービス要求カタログのみ

セキュリティグループの設定手順

  1. Go To メニューから 「Security」（セキュリティ）> 「Security Groups」（セキュリティグループ） を開く
  2. 新規グループを作成、またはサンプルグループを複製する
  3. 「アプリケーション」タブ でアプリケーション権限を設定する
  4. 「ユーザー」タブ でユーザーを追加する
Maximo Manage のセキュリティグループと同じ仕組みです。詳しくは Manage — ユーザーとセキュリティグループ を参照してください。
