はじめの設定

環境のクイック構成 | Maximo IT オンボーディング

クイック構成アプリケーションを使って、Maximo IT の初期設定を素早く完了しましょう。

このページは 管理者向け です。

Maximo IT には、利用開始時に必要な初期設定を一括で行える 「クイック構成」 アプリケーションが用意されています。
通貨コード・組織・サイト・サービスカタログ・作業タイプを一連のステップで設定できます。

クイック構成でできること

設定項目内容
通貨コード組織で使用する通貨を定義
組織・サイトの設定会社・拠点単位の管理グループを作成
サービスカタログの設定エンドユーザー向けサービスカタログの初期構成
作業タイプの作成変更要求に関連する作業のレベルを定義

クイック構成の手順

  1. Go To メニューから 「管理」 > 「クイック構成」 を開く
  2. 画面の指示に従って各項目を順番に設定する

1. 通貨コードの設定

組織で使用する通貨コードを設定します。デフォルトの通貨コードが用意されていますが、必要に応じて追加できます。

2. 組織・サイトの設定

Maximo IT の運用単位となる 組織（Organization） と サイト（Site） を設定します。

組織・サイトの概念は Maximo Manage と共通です。詳しくは Manage — Organization / Site の概念 を参照してください。
組織・サイトは一度データが登録されると変更・削除が困難になります。運用開始前に拠点構成をよく検討した上で設定してください。

3. サービスカタログの設定

エンドユーザーがセルフサービスで利用するサービスカタログの初期設定を行います。
組織・サイト・セット・販売元を関連付けます。

4. 作業タイプの作成

変更要求に関連する作業のレベル（例：標準変更・緊急変更など）を定義します。
組織ごとに1つ以上の作業タイプの作成が必要です。
